# RushFinder 0964 — رفع خطای 403 مدل GPT Image گیسو

در نسخه 0963، درخواست ساخت تصویر با شناسه کوتاه `gpt-image-2.6-flare` یا `gpt-image-2.6-sunburst` به گیسو فرستاده می‌شد. بنا بر مستندات اختصاصی گیسو، شناسه‌های صحیح این دو مدل در API عبارت‌اند از:

- `openrouter/openai/gpt-image-2.6-flare`
- `openrouter/openai/gpt-image-2.6-sunburst`

این اصلاحیه **فقط** `infographic.html` و `api/avalai-image.js` را اصلاح می‌کند؛ هیچ API یا متغیر تازه‌ای در Vercel لازم ندارد و به بخش تدوین دست نمی‌زند.

## نصب

1. همین ZIP را داخل ریشهٔ مخزن GitHub پروژه RushFinder استخراج کنید (کنار `infographic.html`). هنگام استخراج پوشه `api` را حفظ کنید و فایل‌های هم‌نام را جایگزین کنید.
2. فایل `PUBLISH-0964-GISOO-MODELS.cmd` را اجرا کنید.
3. در Vercel منتظر وضعیت `Ready` بمانید. سپس سایت را با `Ctrl+F5` باز کنید.
4. در صفحه اینفو، کد مدیر را وارد کنید و «بررسی اتصال گیسو» را بزنید. توجه: این دکمه فقط اتصال و فهرست مدل‌ها را بررسی می‌کند، نه مجوز ساخت هر مدل.
5. در صورت تأیید اینکه کلید و پروژه شما به مدل مجازند، یک تصویر تستی با `Flare` و کیفیت `Low` بسازید؛ این مرحله هزینه دارد.

## اگر هنوز خطای 403 می‌بینید

در مستندات گیسو، `model_not_allowed` یعنی کلید یا پروژه اجازه استفاده از مدل را ندارد. در پنل گیسو `https://gisoo.pro/app/api` پروژه و کلید مورد استفاده را بررسی کنید؛ بخش مدل‌های مجاز / `allowed_models` باید شامل شناسهٔ کامل مدل انتخابی باشد، یا محدودیتی برای این مدل تعیین نشده باشد. اگر این تنظیم را نمی‌بینید، با پشتیبانی گیسو مکاتبه کنید و متن خطا و شناسه مدل را بدهید. کلید مخفی API را به کسی ارسال نکنید.

این اصلاحیه **مجوز مدل گیسو را تغییر نمی‌دهد** و نمی‌تواند تضمین کند که کلید شما به مدل دسترسی دارد. یک خطای ردشدهٔ 403 معمولاً هزینهٔ تولید تصویر ندارد، اما از ارسال مکرر درخواست پولی خودداری کنید.

## تنظیمات Vercel که از قبل دارید

- `GISOO_API_KEY` — کلید گیسو (محرمانه)
- `RF_INFO_ACCESS_CODE` — رمز مدیریتی سایت، جدا از API
- `GISOO_BASE_URL` — اختیاری؛ اگر قرار داده‌اید فقط `https://gisoo.pro/api/v1` یا `https://ir.gisoo.pro/api/v1`

## آزمون‌های محلی

کد JavaScript از نظر نحو بررسی شد و پاسخ شبیه‌سازی‌شده برای هر دو مدل و خطای 403 آزمایش شد. **درخواست پولی واقعی با API گیسوی شما انجام نشده است.**
