# RushFinder 0956 — رفع خطای انتشار Vercel

## علت احتمالی تاییدشده در کد
نسخه‌های قبلی RushFinder دارای **۱۲ فایل تابع داخل `api/`** بودند. اصلاحیه 0954 فایل `api/hermes.js` را اضافه کرد و تعداد را به ۱۳ رساند. Vercel Hobby در پروژه‌هایی که مستقیماً از `api/` استفاده می‌کنند، سقف ۱۲ تابع دارد. **تصویر Vercel متن دقیق خطا را نشان نمی‌دهد**؛ اگر بعد از اصلاح هنوز Error هست، لازم است Build Logs دیده شود.

## این بسته چه کار می‌کند؟
- کد موجود `api/chat.js` را **حفظ** می‌کند و تنها مسیر `?mode=hermes` را به آن اضافه می‌کند؛ Groq/Claude/Gemini دست نمی‌خورند.
- رابط صفحه تدوین به جای `/api/hermes` از `/api/chat?mode=hermes` استفاده می‌کند.
- منطق Hermes به فایل `lib/hermes-handler.cjs` منتقل می‌شود (**نه تابع Vercel جداگانه**).
- فایل `api/hermes.js` را حذف می‌کند و پروژه را به سقف ۱۲ تابع برمی‌گرداند.
- شماره نسخه فایل JS و iframe سایت را به 0956 تغییر می‌دهد تا کش مرورگر به‌روزرسانی شود.
- همه چیزهایی که در نسخه 0955 از صفحه حذف کرده‌اید، **همان‌طور باقی می‌ماند**.

## نصب
1. ZIP را داخل همان پوشه اصلی Git پروژه RushFinder استخراج کنید، جایی که `index.html` و `api/chat.js` هستند.
2. روی `PUBLISH-0956-VERCEL-FIX.cmd` دوبار کلیک کنید.
3. در Vercel → Deployments آخرین اجرا را چک کنید. اگر **Ready** بود، صفحه را با `Ctrl+F5` باز کنید.
4. بدون اتصال سیستم همکار، آدرس `https://rushfinder.vercel.app/api/chat?mode=hermes` باید JSON بدهد: `{"ok":true,"configured":false,"online":false}`. اگر متغیرهای Hermes تنظیم شده باشند، `configured` ممکن است true باشد.

**مهم:** این پچ اتصال واقعی Hermes همکار را خودکار راه‌اندازی نمی‌کند، و تغییرات محرمانه یا کلیدهای API را منتشر نمی‌کند. برنامه `hermes-bridge` و کلیدهای Vercel بعداً باید تنظیم شوند. پیام خطای واقعی اگر بعد از این پچ باقی ماند، از صفحه Deployment → Build Logs ارسال شود.

**پشتیبان:** اسکریپت از فایل‌های تغییر داده‌شده نسخه `.before-0956.bak` در پوشه محلی می‌سازد؛ این فایل‌ها را در GitHub Push نمی‌کند.
