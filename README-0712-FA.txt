RushFinder Web 0712 — Full-Bleed Gemini + قالب‌های اصلی دست‌نخورده

این نسخه کامل از روی 0711 ساخته شده است.

اصلاح: تصویر تولیدی Gemini اکنون با روش Cover تمام بوم مربع یا استوری را می‌پوشاند و در یک پنل کوچک وسط بوم محدود نمی‌شود.
فقط تیتر مستقل در محدوده امن دور از لوگوی گوشه راست قرار دارد. قالب PNG اصلی در بالاترین لایه بدون تغییر رسم می‌شود.
در پرامپت نیز از Gemini درخواست می‌شود که کارت‌ها و نمودارها کل صفحه را پر کنند و لوگو یا تیتر اصلی را خود مدل نسازد.

هر شش قالب اصلی (خبر فوری، اخبار مشهد و جریان؛ مربع و استوری) بدون تغییر حتی یک بایت نگه داشته شده‌اند.
فایل اتصال API چابکان هیچ تغییری نکرده است.

نکته مهم: اگر مدل Gemini خودش یک تصویر با حاشیه سفید بسازد، Cover به‌تنهایی نمی‌تواند سفیدی داخل خود تصویر را حذف کند؛ پرامپت برای Full-Bleed اصلاح شده و باید با یک تصویر واقعی تست شود.
قبل از انتشار اصلی بکاپ را حفظ کنید و Preview را تست کنید. کلید API داخل GitHub قرار نگیرد.
