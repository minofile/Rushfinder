RushFinder Web 0814 — رفع خطای 404 تگ کانال + کارت‌های جدید

علت خطای HTTP 404:
گزینه «تگ کانال» در سایت فعال شده اما موتور ae-auto-server.js قبلی، مسیر
/ae-api/channel-create را نمی‌شناسد. باز بودن After Effects کافی نیست.

فایل‌های ضروری برای نصب (هر ۴ مورد):
۱) index.html — طرح جدید کارت‌ها و بررسی قابلیت تگ کانال
۲) news-tag.html — همان تغییرات برای صفحه مستقل
۳) ae-auto-server.js — مسیر رندر تگ کانال (بدون تغییر رندر خبرنگار)
۴) assets/news-tag/fori-channel-tag.png — لوگوی دقیق ارسال‌شده

مراحل نصب:
۱. از فایل‌های قبلی پشتیبان بگیرید.
۲. هر چهار فایل را در پوشه اصلی GitHub/Rushfinder قرار دهید؛ پوشه assets/news-tag را هم حفظ کنید.
۳. GitHub Desktop: Commit و Push، سپس منتظر انتشار Vercel شوید.
۴. در ویندوز موتور قبلی RushFinder را متوقف کنید؛ اگر از پنجره CMD اجرا شده Ctrl+C بزنید.
   باز بودن After Effects به معنی آپدیت‌شدن موتور نیست.
۵. Start-RushFinder.cmd را دوباره از همین پوشه پروژه اجرا کنید.
۶. در مرورگر، http://127.0.0.1:18826/ae-api/check را باز کنید.
   باید علاوه بر version: "0813" عبارت "channelTag": true را ببینید.
   اگر این فیلد دیده نمی‌شود، فرایند قدیمی Node هنوز پورت 18826 را اشغال کرده است.
۷. سایت را با Ctrl+Shift+R تازه کنید و مدل «تگ کانال» را بسازید.

توجه: نسخه موتور همچنان 0813 و پورت 18826 است.
هیچ تغییری در کد رندر AE برای تگ نام خبرنگار یا قالب AEP انجام نشده.
«تگ نام و سمت» همچنان غیرفعال است.
لوگوی کانال به صورت تصویر با FFmpeg روی MP4 قرار می‌گیرد؛ برای تگ کانال رندر AE لازم نیست.
فایل‌های این بسته هنوز روی ویندوز شما نصب نشده‌اند؛ بدون جایگزینی موتور خطای 404 رفع نخواهد شد.
