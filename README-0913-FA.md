# RushFinder SmartEdit 0913 — اصلاح جست‌وجوی راش و فونت وزیر

نسخه 0913 فقط فایل‌های مرتبط با تدوین هوشمند را تغییر می‌دهد. باقی بخش‌های سایت باید بدون تغییر بمانند.

- **جست‌وجوی کوتاه چندموضوعی**: متن فارسی به مفاهیم کوتاه مثل Gaza، Lebanon، Israel، Knesset تبدیل می‌شود. این ترجمه کامل یا تشخیص معنایی AI نیست؛ یک واژه‌نامه موضوعی است.
- **اصلاح فیلتر Commons**: ویدئوهای دارای مجوز معتبر و تا ۵۰ مگابایت به‌جای محدودیت ۳۵ مگابایت بررسی می‌شوند؛ برای عبارت دوکلمه‌ای، تک‌واژه هم امتحان می‌شود.
- **فونت وزیر**: از فایل‌های وزیر موجود در پوشه `fonts` سایت تو استفاده می‌کند؛ این بسته فونت جدیدی اضافه نمی‌کند.
- **چیدمان جمع‌وجور**: ارتفاع هدر، پانل‌ها و تایم‌لاین کمتر شده است.
- **نریشن همچنان محور زمان‌بندی است** و متن خبر روی فیلم نوشته نمی‌شود.

## انتشار روی GitHub / Vercel
فقط فایل‌های داخل این بسته را با حفظ ساختار پوشه در مخزن اصلی RushFinder جایگزین کن. فایل‌های دیگری را حذف نکن. پوشه `fonts` نسخه فعلی سایت باید موجود بماند.

## تست محلی
اگر پروژه کامل 0912 روی کامپیوتر داری، فایل‌های بسته را در همان پوشه کپی کن و `RUN-0913-LOCAL.cmd` را اجرا کن. این اجرای آزمایشی به Startup ویندوز دست نمی‌زند.

## محدودیت‌ها
جست‌وجوی آنلاین اینترنت می‌خواهد. ممکن است برای موضوعی فیلم دارای مجوز و قابل‌دانلود در Commons موجود نباشد، یا مرورگر اجازه دریافت برخی ویدئوها را ندهد. افزودن فیلم یوتیوب/آپارات هنوز خودکار نیست. از انتشار راش آرشیوی به‌عنوان تصویر تأییدشده رویداد خودداری کن. بدون بررسی واقعی روی Vercel، دریافت زنده تضمین نمی‌شود.
