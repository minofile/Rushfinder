RushFinder Web 0817 — اصلاح قطعی به‌روزرسانی اندازه تگ کانال
================================================================

در این نسخه فقط مسیر تگ کانال خبرفوری و شناسایی نسخه واقعی موتور اصلاح شده است.
- عرض تصویر کانال خبرفوری: ۸ درصد از عرض ویدیوی ورودی (قبلاً ۱۲ درصد).
- محل قرارگیری: پایین راست، همان موقعیت قبلی.
- موتور رندر نام خبرنگار / After Effects / AEP و پورت 18826 تغییر نکرده‌اند.
- API موتور همچنان version=0813 است تا تگ نام خبرنگار سازگار بماند.
- شناسه دقیق موتور جدید: engineBuild=0817-channel-8pct.
- خروجی /ae-api/check اکنون channelTagWidthPercent=8 را هم نمایش می‌دهد.

چرا نسخه‌های قبل روی سیستم شما تغییر نکردند؟
استارتر قبلی فقط نسخه API 0813 و پوشه پروژه را بررسی می‌کرد و موتور Node.js
قدیمی را با وجود جایگزینی فایل به همان حالت در حال اجرا نگه می‌داشت.
استارتر 0817 اکنون شناسه ساخت موتور را بررسی می‌کند؛ فقط اگر مطمئن شود
موتور قدیمی متعلق به همین پوشه Rushfinder است، آن را می‌بندد و نسخه جدید را اجرا می‌کند.
موتورهای متعلق به پوشه‌های دیگر یا برنامه‌های دیگر را متوقف نمی‌کند.
در صورت نداشتن مجوز بستن موتور، خطای واضح نشان می‌دهد تا دستی بسته شود.

نصب کامل روی Windows / GitHub:
۱) از پوشه اصلی Rushfinder نسخه پشتیبان بگیرید؛ پوشه مخفی .git را حذف نکنید.
۲) همه فایل‌های داخل این ZIP را به پوشه زیر کپی و جایگزین کنید:
   C:\Users\m_rajabi\Documents\GitHub\Rushfinder
۳) GitHub Desktop: Commit و Push Origin.
۴) فایل Start-RushFinder.cmd را از همین پوشه اجرا کنید. استارتر 0817 در صورت
   شناسایی موتور قدیمی همین پوشه، آن را به‌صورت کنترل‌شده بازراه‌اندازی می‌کند.
۵) در آدرس http://127.0.0.1:18826/ae-api/check حتماً دو فیلد زیر را بررسی کنید:
   "engineBuild":"0817-channel-8pct"
   "channelTagWidthPercent":8
   اگر این‌ها دیده نشدند، هنوز موتور قدیمی اجراست؛ بدون این دو علامت، خروجی جدید را تست نکنید.
۶) در صفحه تگ کانال، ویدیوی ورودی را دوباره انتخاب کنید و دکمه «ساخت فیلم» را بزنید.
   خروجی‌های MP4 قبلی تغییر اندازه نمی‌دهند؛ باید یک رندر جدید بسازید.
