# RushFinder 0922 — اصلاح فونت وزیر صفحه تدوین

این بسته فقط `smart-edit.html` را اصلاح می‌کند؛ منو، ابزارهای تدوین، APIها و تنظیمات Vercel تغییری ندارند.

## نصب
۱. فایل ZIP را استخراج کنید.
۲. فایل `smart-edit.html` را در **ریشه مخزن RushFinder** جایگزین کنید.
۳. تغییر را در GitHub ثبت کنید (Commit). منتظر انتشار Ready در Vercel بمانید.
۴. صفحه تدوین را با Ctrl+F5 بازخوانی کنید.

فونت Vazir از CDN عمومی cdnjs Cloudflare دریافت می‌شود؛ برای بارگذاری دفعه اول اینترنت لازم است. اگر CDN در شبکه شما مسدود باشد، مرورگر از فونت جایگزین استفاده می‌کند. برای استفاده ۱۰۰٪ آفلاین باید فایل‌های فونت مجاز را جداگانه روی سایت میزبانی کرد.

**مهم:** فایل‌های داخل `api/`، فایل `vercel.json` و نسخه‌ای که الان در Vercel سالم منتشر شده را تغییر ندهید.
