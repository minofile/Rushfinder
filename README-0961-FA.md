# اصلاحیه 0961 برای صفحه تدوین RushFinder

این اصلاحیه روی **فایل فعلی پروژه شما** اعمال می‌شود و نسخه قدیمی `smart-edit.html` را جایگزین نمی‌کند.

## تغییرات

- کادر **دوم و تکراری** «انتخاب فایل نریشن»، پیام فایل انتخاب‌شده و «متن نریشن» در منوی «ابزارهای بیشتر» از **نمایش** حذف می‌شوند؛ ورودی اصلی بالای پنل «تدوین» باقی می‌ماند.
- گزینه تزریق‌شده «نمایش ردیف ترنزیشن در تایم‌لاین» در همان منو مخفی می‌شود.
- کادر «فرمت خروجی MP4 / WebM» در ستون تنظیمات از کناره‌ها و پایین فاصله می‌گیرد؛ ستون به‌صورت مستقل اسکرول می‌شود.
- دکمه «ارسال درخواست»، اتصال Hermes و تایم‌لاین تغییری نمی‌کنند.

برای سازگاری با کد قدیمی، شناسه‌های HTML ورودی دوم حذف فیزیکی نمی‌شوند؛ فقط نمایش آن‌ها متوقف می‌شود تا جاوااسکریپت فعلی خطا ندهد.

## نصب

1. محتویات ZIP را در پوشه **اصلی Git** پروژه RushFinder، کنار `smart-edit.html` استخراج کنید.
2. فایل `PUBLISH-0961-EDITOR-FIX.cmd` را اجرا کنید.
3. در Vercel وضعیت آخرین انتشار را بررسی کنید؛ بعد از `Ready` شدن، صفحه را با `Ctrl+F5` تازه‌سازی کنید.

اگر انتشار Vercel قرمز شد، Build Logs لازم است؛ این اصلاحیه به‌تنهایی هیچ API جدیدی اضافه نمی‌کند.

فایل پشتیبان `smart-edit.html.backup-before-0961` فقط روی کامپیوترتان ساخته می‌شود و توسط اسکریپت انتشار به Git اضافه نمی‌شود.
