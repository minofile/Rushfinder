RushFinder Web 0830 — افزودن اخبار مشهد

- انتخاب «اخبار مشهد» در سایت فعال شد و سه گزینه تگ کانال، تگ نام خبرنگار، تگ نام و سمت را نشان می‌دهد.
- مدل خبرنگار و مدل نام و سمت با فایل اصلی «اخبار مشهد.aep» و کامپوزیشن tag2 رندر می‌شوند. در مدل نام و سمت، دو ورودی کاربر در همان نوار نام قالب به صورت «گزارشی از: نام | سمت» قرار می‌گیرد.
- مدل کانال از تصویر ویژه @AkhbarMashhad و تنظیم اندازه کانال استفاده می‌کند.
- سه تصویر لینک‌شده AEP از دارایی‌های پروژه بازسازی و در ae-original/mashhad-assets قرار گرفته‌اند. برای مطابقت صددرصد با طراح اصلی، می‌توان تصاویر مرجع اصلی (تگ copy.png، akhbare mashhad.png، Micropho4.png) را در همین پوشه جایگزین کرد. فایل AEP ارسالی بدون تغییر در پروژه نگه داشته شده است.
- مسیر جدید /ae-api/mashhad-create صرفاً ویژه اخبار مشهد است و مسیرهای سه مدل خبرفوری بدون تغییر باقی مانده‌اند.
- موتور ویندوزی باید یک‌بار مجدد با Start-RushFinder.cmd اجرا شود. در /ae-api/check باید mashhadBuild برابر 0830-mashhad-three-models و mashhadTag برابر true باشد.
- اعتبارسنجی نحوی JS و خروجی استاتیک انجام شده اما رندر واقعی AEP فقط روی کامپیوتر دارای After Effects قابل تأیید است.
- شماره نسخه وب 0830؛ شناسه و پورت موتورهای خبرفوری دست‌نخورده (version=0813, port=18826).

نصب: از پروژه GitHub پشتیبان بگیرید، محتویات ZIP را در ریشه پروژه کپی کنید بدون حذف .git، سپس Commit/Push و Restart موتور انجام دهید.
