# RushFinder 0933 — Gemini + YouTube Video Auto-Cut (آزمایشی)

**بر اساس ZIP نسخه 0932**. این بسته «اصلاحیه» است؛ برای نصب کل پوشه پروژه را پاک نکنید.

## تغییرات این نسخه

1. `api/youtube-music.js`: مسیر تحلیل متن ابتدا از Gemini استفاده می‌کند. برای سازگاری با تنظیمات قبلی، اگر Gemini پاسخ ندهد و کلید OpenAI/OpenRouter هم موجود باشد، آن مسیر همچنان قابل استفاده است.
2. YouTube Data API همچنان نام و لینک و مدت و توضیحات ویدیو را پیدا می‌کند. کلید `YOUTUBE_SMARTEDIT_API_KEY` یا `YOUTUBE_API_KEY` پذیرفته می‌شود.
3. برای هر بخش نریشن، ویدیوی مرتبطِ پیدا شده به **Gemini Video Understanding** ارسال می‌شود تا خود تصویر ویدیو را ارزیابی و شروع/پایان صحنه را پیشنهاد کند. آدرس کامل قابل حدس یا اختیاری به Gemini ارسال نمی‌شود؛ شناسه ویدیو باید ۱۱ حرف معتبر داشته باشد.
4. زمان‌های پیشنهادی Gemini روی **تایم‌لاین مجازی با پیش‌نمایش رسمی YouTube** قرار می‌گیرند؛ قابل پخش، جابه‌جایی و ویرایش هستند. اگر Gemini صحنه مرتبط نیابد، نباید کات جعلی از یک عنوان مشابه به جای آن نشان داده شود.
5. **تبدیل به کات واقعی داخل خود سایت:** بعد از ساخت پیشنهادها، از گزینه «تبدیل کات‌ها به ویدیوهای واقعی» فایل‌های اصلی مجاز را انتخاب کنید. اگر نام هر فایل شامل شناسه ویدیوی یوتیوب باشد، `smart-edit.js` آن را با همان تایم‌کد می‌بُرد، ترتیب را روی نوار واقعی می‌چیند، و بخش‌های بدون تصویر را با زمینه مشکی پر می‌کند تا نریشن جا‌به‌جا نشود. سپس می‌توانید از خروجی عادی مرورگر استفاده کنید (MP4 یا WebM برحسب پشتیبانی مرورگر).
6. وقتی فقط فایل نریشن انتخاب شده و متن خالی است، برای فایل کوچک (حدود ۲.۵ مگابایت) تلاش می‌شود با Gemini متن فارسی پیاده‌سازی شود. **برای فایل‌های بزرگ‌تر متن را هم وارد کنید.** زمان‌بندی جمله‌ها براساس طول و تعداد کلمات تخمین است، نه forced alignment کلمه‌به‌کلمه.
7. طرح JSON اکنون فیلد `geminiVisualVerified` و توضیح دیداری `visualEvidence` را شامل می‌شود. این‌ها بازبینی انسانی محسوب نمی‌شوند.
8. `tools/auto_cut_renderer.py`: ابزار آفلاین جانبی برای برش **فایل‌های ویدئویی محلی که حق استفاده از آن‌ها را دارید** با FFmpeg و ساخت خروجی MP4 با نریشن. فایل‌های منبع باید با شناسه یوتیوب نام‌گذاری شوند؛ مثال: `a1b2c3d4e5F.mp4`.

## نصب در GitHub و Vercel

فایل‌های همین اصلاحیه را با حفظ مسیر در مخزن پروژه جایگزین کنید، Commit و Push کنید و منتظر Ready شدن استقرار بمانید. متغیرهای سرور در **Vercel → Project Settings → Environment Variables**:

- `GEMINI_API_KEY`  (جایگزین مجاز: `GOOGLE_GEMINI_API_KEY` یا `GOOGLE_API_KEY`)
- `YOUTUBE_SMARTEDIT_API_KEY` (جایگزین مجاز: `YOUTUBE_API_KEY`)
- اختیاری: `SMARTEDIT_GEMINI_MODEL=gemini-2.5-flash`

کلیدها را در HTML، JavaScript مرورگر یا GitHub ننویسید. پس از تغییر متغیرها Redeploy لازم است.

## فرآیند آزمایش

1. صفحه `smart-edit.html` را باز و Ctrl+F5 بزنید.
2. متن خبری و/یا فایل نریشن را وارد کنید.
3. «تحلیل با Gemini، دیدن ویدیوها و ساخت کات هوشمند» را بزنید.
4. باید در نوار وضعیت به ترتیب تحلیل متن، جست‌وجوی یوتیوب و دیدن ویدیوها با Gemini نمایش داده شود.
5. بعد از ساخت کات، هر کات را برای دیدن بازه زمانی انتخاب کنید؛ با دکمه دریافت JSON، طرح را ذخیره کنید.
6. در صورت داشتن فایل‌های اصلی مجاز، نام فایل‌ها را مطابق شناسه یوتیوب بگذارید و دکمه انتخاب فایل واقعی را بزنید؛ این کار فایل‌ها را به کات‌های واقعی روی تایم‌لاین اصلی تبدیل می‌کند.
6. ویدیوهای بسیار طولانی، ویدیوهای غیرعمومی، YouTube غیرفعال/تحریم‌شده، محدودیت API، نداشتن صحنه مرتبط، و مجوزهای پخش ممکن است نتیجه ندهند. برنامه نباید کات تصادفی بسازد.

## خروجی MP4 واقعی با فایل‌های مجاز محلی

**تنها داشتن کلید YouTube Data API و Gemini API برای دریافت بایت‌های فایل MP4 از ویدیوهای یوتیوب کافی نیست.** در این نسخه، پیش‌نمایش‌های YouTube همچنان در خروجی مرورگر ضبط نمی‌شوند. برای تدوین و رندر واقعی، فایل‌های ویدیو را با مجوز مناسب تهیه کنید. می‌توانید همان فایل‌ها را با گزینه جدید داخل سایت وارد کنید یا به‌صورت جایگزین از `RUN-0933-AUTOCUT.cmd` و FFmpeg استفاده کنید:

```bat
RUN-0933-AUTOCUT.cmd "C:\Edits\RushFinder-0933-Gemini-Storyboard.json" "C:\Edits\LicensedFootage" "C:\Edits\narration.mp3"
```

اگر `py` یا `ffmpeg.exe` در رایانه موجود نیست، مسیرشان را در اسکریپت/محیط Windows تنظیم کنید. اسکریپت هیچ ویدیویی را از YouTube دانلود نمی‌کند، بلکه فقط از فایل‌های خودتان برش واقعی می‌سازد و نریشن را روی خروجی می‌گذارد. برای بخش‌های بدون راش، فریم سیاه قرار می‌دهد تا نریشن جابه‌جا نشود. اگر منبعی پیدا نشود، با خطا متوقف می‌شود.

## امنیت و محدودیت

- آدرس ویدیو از شناسه YouTube ساخته می‌شود و بدین ترتیب سرور URL دلخواه کاربر را fetch نمی‌کند.
- کلیدها فقط سمت سرور استفاده می‌شوند؛ محدودیت درخواست به صورت best effort در حافظه Serverless است؛ **برای استقرار عمومی و کلید پولی، احراز هویت و سهمیه مرکزی لازم است.**
- API Gemini ممکن است برخی ویدیوها را به دلیل محدودیت دسترسی، طول، اعتبارسنجی یا quota نپذیرد.
- بخش‌های پیشنهادشده توسط مدل ممکن است اشتباه باشند؛ پیش از انتشار یا انتساب تصویر خبری به رویداد باید با چشم بازبینی شوند.
- نسخه حاضر روی **کلیدهای واقعی کاربر و سایت مستقرشده تست نشده**؛ فقط syntax، تست‌های mock API و برش FFmpeg با فایل نمونه آزمایش شده است. آزمایش یکپارچه در مرورگر محیط ساخت به علت محدودیت دسترسی Chromium انجام نشد.
- **پشتیبانی آپارات و دریافت خودکار ویدیوهای YouTube در این اصلاحیه پیاده‌سازی نشده است.**
