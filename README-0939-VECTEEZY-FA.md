# RushFinder 0939 — منبع سوم Vecteezy (ویتیزی)

این نسخه روی RushFinder 0938 ساخته شده است. در منوی «منبع راش خودکار»، گزینه‌های زیر اضافه/به‌روز شده‌اند:
- یوتیوب + آپارات + ویتیزی
- یوتیوب + آپارات (بدون Vecteezy)
- فقط یوتیوب / فقط آپارات / فقط ویتیزی

## برای جست‌وجوی ویتیزی
Vecteezy به‌صورت رسمی API تجاری/آزمایشی عرضه می‌کند: https://www.vecteezy.com/developers
مستندات: https://www.vecteezy.com/api-docs/index.html

بعد از فعال‌کردن حساب توسعه‌دهنده Vecteezy، این متغیرها را در Vercel تنظیم کن:

- `VECTEEZY_API_KEY` = کلید API رسمی Vecteezy
- `VECTEEZY_ACCOUNT_ID` = شناسه حساب API ویتیزی
- `VECTEEZY_API_BASE_URL` = آدرس رسمی API ارائه‌شده در قرارداد/مستندات حساب (اختیاری؛ پیش‌فرض `https://www.vecteezy.com`)
- `VECTEEZY_QUERY_PARAM` = نام پارامتر جست‌وجو در مستندات API حساب (اختیاری؛ پیش‌فرض `qterm`)

اگر API حساب با پیش‌فرض‌ها متفاوت باشد، باید دو تنظیم آخر را طبق مستندات همان حساب اصلاح کرد. **اتصال واقعی به Vecteezy بدون کلید قابل آزمایش نبوده است.**

## برای دانلود و کات واقعی فایل‌های ویتیزی
توجه: دانلود محتوای API ممکن است از سهمیه دانلود استفاده کند یا هزینه داشته باشد؛ تایید هزینه در صفحه تدوین الزامی است.

1. در Vercel متغیر `VECTEEZY_DOWNLOAD_ALLOWED` را برابر `true` قرار بده؛ فقط اگر هزینه/مجوز دانلود API را تأیید کرده‌ای.
2. یک رشته تصادفی بلند (حداقل ۳۲ کاراکتر) به‌عنوان `RUSHFINDER_WORKER_SHARED_KEY` در Vercel ذخیره کن.
3. در کامپیوترت داخل پوشه پروژه، فایل `vecteezy-worker-secret.local.txt` بساز و همان رشته را **فقط در یک خط** داخلش قرار بده. این فایل در `.gitignore` است؛ آن را به GitHub نفرست.
4. از `RUN-0939-MEDIA-WORKER.cmd` استفاده کن. CMD باید باز بماند. برای بررسی سلامت worker آدرس http://127.0.0.1:8767/health را باز کن.
5. در منبع ویتیزی، تیک تأیید حق استفاده و تیک هزینه احتمالی ویتیزی را بزن.

در صورت تنظیم نبودن حساب یا توکن، منبع ویتیزی فعال نمی‌شود ولی در حالت سه‌منبعی **یوتیوب و آپارات کارشان را ادامه می‌دهند**. هیچ جست‌وجوی HTML یا دانلود بدون مجوز از Vecteezy انجام نمی‌شود.

در جریان ویتیزی، API نتیجه ویدیو را پیدا می‌کند، Media Worker فایل مجاز را از API دریافت می‌کند، Gemini فقط فریم واقعی را برای هماهنگی با متن بررسی می‌کند، و FFmpeg کات واقعی را روی لایه ویدیو در تایم‌لاین می‌چیند.

## محدودیت تست
تست‌های محلی با پاسخ ساختگی API و فایل‌های ویدیوی نمونه انجام می‌شوند، نه با حساب اصلی Vecteezy تو. هیچ تضمینی برای کار با فرمت دقیق پاسخ یا سطح دسترسی حساب خاص بدون تست زنده وجود ندارد.

## راه‌اندازی سایت
ZIP کامل را در ریشه پروژه GitHub استخراج و جایگزین کن، Push و سپس Vercel Redeploy کن. اگر فقط نسخه 0938 را داری، بسته Patch کافی است. متغیرهای OpenAI/Claude/Gemini قبلی را حذف نکن.

## مجوز
محتوای رایگان Vecteezy به ذکر نام و رعایت محدودیت‌ها نیاز دارد؛ Pro هم قواعد خاص خود را دارد. بدون مجوز و اطلاعات معتبر از حق استفاده، محتوای Vecteezy را به خروجی ویدیو اضافه نکن.
