# RushFinder 0929 — تشخیص و رفع خطای جست‌وجوی YouTube در تدوین

این اصلاحیه برای خطای «[object Object]» و خالی‌شدن تایم‌لاین پس از جست‌وجوی ناموفق است.

- خطاهای API به شکل خوانا، همراه با کد HTTP و راهنمای عملی نمایش داده می‌شوند.
- روی خطای اول، جست‌وجو متوقف می‌شود؛ دیگر ۱۲ درخواست بی‌فایده پشت سر هم ارسال نمی‌شود.
- کات‌های قبلی و نریشن، تا زمانی که پیشنهاد جدید **واقعاً** پیدا نشده باشد، حذف نمی‌شوند.
- در صورت صفر بودن نتیجه، برنامه به اشتباه ادعای «ساخته‌شدن کات» نمی‌کند.
- جست‌وجوی خودکار فقط YouTube است؛ کلید تدوین YOUTUBE_SMARTEDIT_API_KEY جدا از YOUTUBE_API_KEY قبلی می‌ماند.
- فایل موجود `api/youtube-music.js` ویرایش شده؛ تابع جدیدی به Vercel اضافه نمی‌شود.

## نصب
ZIP اصلاحیه را از حالت فشرده خارج کن و این سه فایل را در ریشه مخزن GitHub جایگزین کن:
- `smart-edit.html`
- `smart-youtube.js`
و این فایل را داخل پوشه `api/` جایگزین کن:
- `api/youtube-music.js`

بعد Commit کن و پس از Ready شدن انتشار Vercel صفحه را با Ctrl+F5 باز کن.

## توجه
اگر خطا از کلید، محدودیت API، فعال‌نبودن API یا تمام‌شدن سهمیه Google Cloud باشد، تغییر کد به‌تنهایی آن را برطرف نمی‌کند؛ اما نسخه 0929 علت را واضح نشان می‌دهد. کلید محرمانه را در گفتگو ارسال نکن.

کات‌های یوتیوب در این نسخه پیش‌نمایش مجازی‌اند و محتوای YouTube دانلود یا وارد خروجی MP4 نمی‌شود. زمان کات پیشنهادی است و بهترین صحنه با تحلیل ویدیویی تأیید نشده است.
