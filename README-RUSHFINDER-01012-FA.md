# RushFinder Web 01012 — مرجع‌محور خبر فوری

این نسخه برای بخش اینفوگرافیک «خبر فوری» آماده شده است.

## هدف نسخه
تثبیت سبک تولید اینفوگرافیک با مدل `GPT Image 2.5 Flare` بر اساس سه مرجع خبر فوری:
1. تم اقتصادی
2. تم موضوعی / بارش / آلودگی
3. تم سهم‌بندی / pie chart

## اصلاح این نسخه
- تقویت دستور هنری خودکار برای برند «خبر فوری»
- تأکید صریح‌تر روی سبک سه‌بعدی پریمیوم و رنگ‌های کرم روشن + سبز زمردی
- تأکید روی پر بودن قاب و حذف فضای خالی بیهوده
- تأکید روی شباهت بیشتر به خروجی‌های مرجع دیروز
- تأکید روی این‌که مدل فقط تصویرسازی بسازد و متن/لوگو را خود سایت کنترل کند

## محدودیت مهم
این نسخه هنوز تضمین نمی‌کند که AvalAI دقیقاً همان تصویرهای مرجع را تکرار کند؛
اما پرامپت خودکار و لحن هنری را برای خبر فوری صریح‌تر می‌کند.

## نصب
فایل `infographic.html` را جایگزین فایل فعلی کن و روی Vercel دوباره Deploy بگیر.
