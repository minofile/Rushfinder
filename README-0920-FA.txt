RushFinder 0920 — اصلاح نمایش منوی تدوین در سایت آنلاین

این نسخه بر پایه 0919 است؛ فقط index.html اصلاح شده است.
دکمه «تدوین» اکنون از ابتدا در HTML منوی اصلی قرار دارد؛ جاوااسکریپت فقط باز کردن صفحه را کنترل می‌کند.
صفحه smart-edit.html از نسخه 0919 بدون تغییر حفظ شده است.

انتشار:
۱) محتوای این پوشه را در ریشه مخزن GitHub سایت RushFinder آپلود کن، نه یک پوشه جدید با نام 0920.
۲) وجود index.html و smart-edit.html را در ریشه مخزن تأیید کن.
۳) Commit کن و در Vercel منتظر Deployment با وضعیت Ready باش.
۴) اول https://rushfinder.vercel.app/smart-edit.html را باز کن تا ببینی فایل صفحه منتشر شده است.
۵) سپس https://rushfinder.vercel.app/?v=0920#smart-edit را با Ctrl+F5 باز کن.

برای مشکل فعلی می‌توانی فقط index.html این نسخه را جایگزین کنی، مشروط به اینکه smart-edit.html قبلاً در ریشه مخزن وجود داشته باشد.
این فایل‌ها به صورت خودکار سایت Vercel را منتشر نمی‌کنند؛ انتشار از GitHub پروژه لازم است.
