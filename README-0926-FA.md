# RushFinder SmartEdit 0926 — جست‌وجوی راش واقعی و کات خودکار

این نسخه ادامه 0925 است و **فقط ۳ فایل** از کل پروژه تغییر کرده‌اند:

- `smart-edit.html` — تنظیمات «جست‌وجوی خودکار چندمنبعی»، توضیحات واضح‌تر و ورودی متن یا نریشن.
- `smart-edit.js` — پیوند نتیجه جست‌وجو به موضوع جمله، دریافت خودکار کلیپ‌های قابل‌استفاده، برش پیشنهادی با بررسی تغییرات تصویری، تولید تایم‌لاین و حفظ نریشن/موسیقی با صدای خاموش راش‌ها.
- `api/smart-stock.js` — برگرداندن متادیتای عنوان ویدئوها برای تطبیق با متن.

## روش استفاده
1. فایل‌ها را در همان مسیرهای قبلی در GitHub **جایگزین** کنید. فایل‌ها را در پوشه تو در تو نریزید.
2. در Vercel پس از Commit وضعیت `Ready` را بررسی کنید.
3. در RushFinder وارد بخش «تدوین» شوید و متن خبر را وارد کنید. فایل نریشن اختیاری است، اما زمان‌بندی با فایل نریشن بهتر است.
4. روی «پیدا کردن راش و ساخت کات خودکار» بزنید. برنامه ابتدا Wikimedia Commons و سپس درصورت تنظیم بودن کلیدهای `PEXELS_API_KEY` و `PIXABAY_API_KEY` منابع بعدی را جست‌وجو می‌کند.
5. کلیپ‌های دانلودشده در **ردیف ویدئو** تایم‌لاین قرار می‌گیرند، صدا خاموش است و نریشن/موسیقی روی ردیف جدا هستند. سپس قبل از خروجی، تناسب تصویر با خبر را کنترل کنید.

## محدودیت‌های مهم
- **YouTube Data API فایل ویدئو را نمی‌دهد.** این نسخه از YouTube به‌عنوان منبع پیش‌نمایش استفاده می‌کند، نه دانلود/رندر آن در MP4.
- این نسخه انتخاب هوشمند معنا و صحت خبر یا تشخیص دقیق زمان کلمات را انجام نمی‌دهد. کلمات کلیدی برای جست‌وجوی آرشیو استفاده می‌شوند و نقاط کات از جزئیات و تغییر تصویری نمونه‌گیری می‌شوند. پیش از نشر باید هم موضوع تصاویر و هم مجوز استفاده بررسی شود.
- اگر هیچ کلیپ مرتبط/قابل‌استفاده دریافت نشود، برنامه کلیپ ساختگی نمی‌گذارد. جست‌وجوی زنده با کلیدهای کاربر هنوز تأیید نشده است.
- فایل‌های شخصی کاربر به Vercel آپلود نمی‌شوند؛ جست‌وجو برای منابع عمومی و در موارد مجاز رله انتقال فایل ممکن است از Vercel عبور کند.
- محدودیت ۱۲ تابع سروری Hobby حفظ شده؛ **فایل API جدید ساخته نشده است**.
- خروجی MP4/WebM با MediaRecorder مرورگر انجام می‌شود؛ نوع خروجی به قابلیت مرورگر بستگی دارد.
