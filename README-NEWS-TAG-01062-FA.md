# RushFinder — اصلاح تشخیص آماده‌بودن موتور تگ خبر (01062)

این بسته از پروژه کامل شما ساخته شده است. خطای واقعی در `news-tag.html` رفع شده: قبلاً همه نوع تگ، حتی «تگ کانال» که فقط FFmpeg می‌خواهد، به نصب After Effects و دارایی‌های قالب خبرنگار وابسته فرض می‌شدند. اکنون هر نوع تگ جداگانه بررسی می‌شود و وابستگی ناقص در صفحه اعلام می‌شود.

**مهم:** این اصلاح Node.js، After Effects یا FFmpeg را روی کامپیوتر دیگران نصب نمی‌کند و موتور ویندوزی را روی Vercel قرار نمی‌دهد. هر شخص برای رندر محلی باید پروژه را کامل Extract کند و روی رایانه ویندوز خودش `Check-RushFinder.cmd` و سپس `Start-RushFinder.cmd` را اجرا کند. Node.js برای روشن‌شدن موتور لازم است. تگ خبرنگار و نام/سمت به After Effects نیاز دارند. تگ کانال به FFmpeg نیاز دارد.

برای تست: بعد از استارت، آدرس `http://127.0.0.1:18827/ae-api/check` را **روی رایانه همان شخص** باز کنید. اگر هیچ پاسخ JSON نداشت، سرور روشن نیست یا پورت مسدود/اشغال است. اگر JSON دارد، `afterEffects`, `ffmpeg`, `channelTag` و `assetsReady` علت نقص را مشخص می‌کنند. گزارش کامل `Check-RushFinder.cmd` و لاگ `%LOCALAPPDATA%\RushFinder\logs\news-tag-server-stderr.log` را نگاه کنید.

برای استفاده همگانی از وب‌سایت بدون نصب و اجرای موتور روی کامپیوتر کاربران، لازم است یک سرور رندر ویندوزی مجزا با احراز هویت ساخته شود؛ این بسته چنین سروری نمی‌سازد.

آزمون‌های این بسته: بررسی نحوی JavaScript، تطبیق منطق دسترسی حالت‌های تگ و سلامت ZIP. اجرای واقعی Windows/After Effects و کامپیوتر دوست شما از این محیط ممکن نیست.
