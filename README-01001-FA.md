# RushFinder 01001 — رفع نوار خالی زیر لوگوی خبر فوری

## علت مشکل
در نسخه 01000 تصویر AI فقط در 88% عرض بوم قرار می‌گرفت و بقیه نوار به رنگ آبی روشن پر می‌شد. فایل لوگوی اصلی در بیشتر طول آن نوار شفاف است؛ بنابراین پایین لوگو یک فضای خالی بزرگ دیده می‌شد.

## اصلاح
- در برند «خبر فوری»، تصویر به اندازهٔ کل بوم رسم می‌شود و فایل PNG شفاف لوگو و نوار سبز اصلی، **در آخر و دست‌نخورده** روی آن قرار می‌گیرد.
- در پرامپت تصویر جدید به AI گفته می‌شود پس‌زمینه را تا لبه ادامه دهد، اما گوشه بالای راست را برای لوگوی اصلی از متن مهم خالی بگذارد.
- تنظیمات AvalAI، API و برندهای دیگر و بخش تدوین/Hermes تغییر نکرده‌اند.
- تصویرسازی واقعی API برای تست این اصلاحیه فراخوانی نشده و هزینه‌ای ندارد؛ صرفاً کد ترکیب محلی آزمایش می‌شود.

## نصب
1. این ZIP را داخل پوشه اصلی GitHub پروژه RushFinder **01000** استخراج کنید و فایل `infographic.html` را جایگزین کنید.
2. فایل `PUBLISH-01001-INFO.cmd` را اجرا کنید.
3. پس از وضعیت Ready در Vercel، صفحه اینفوگرافیک را با `Ctrl+F5` تازه‌سازی کنید.
4. نخست با تصویری که از قبل در مرورگر دارید پیش‌نمایش را بررسی کنید (پس از Refresh تصویر تولیدی قبلی ممکن است در حافظه صفحه نباشد). برای تست خروجی تازه باید یک ساخت جدید را صریحاً تایید کنید و هزینه آن ممکن است از AvalAI کسر شود.

**مهم:** لوگوی اصلی حتی یک پیکسل هم در فایل تمپلیت تغییر نکرده است. پرامپت به AI یادآوری می‌کند محل آن را خالی بگذارد، اما AI همیشه تضمین نمی‌کند هیچ متنی زیر لوگو نیاورد؛ پیش از انتشار بررسی کنید.
