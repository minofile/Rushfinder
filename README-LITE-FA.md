# RushFinder 0941 — نسخه سبک و پاکسازی‌شده

این نسخه از فایل اصلی `Rushfinder(7).zip` تهیه شده و **قابلیت جدیدی به تدوین هوشمند یا موشن‌گرافیک اضافه نکرده است**. پاکسازی فقط روی موارد قابل‌شناسایی و غیرضروری انجام شده است.

## چه چیزی سبک شد؟
- حدود ۷۰ راهنمای تاریخی README و پوشه‌های تصاویر موسیقی مربوط به نسخه‌های منسوخ حذف شدند.
- ۵ فایل پشتیبان خودکار After Effects حذف شد؛ فایل‌های اصلی AEP حفظ شدند.
- تصویرهای قدیمی و تکراری لوگو که در کد فعلی فراخوانی نمی‌شدند حذف شدند.
- چهار تصویر بزرگ تقویم از PNG به **WebP بدون افت حتی یک پیکسل** تبدیل شدند و لینک‌های داخل index.html به‌روزرسانی شد.
- فایل محرمانه `vecteezy-worker-secret.local.txt` از خروجی حذف شده است. فایل موجود روی کامپیوتر خود را **حذف نکنید** و به GitHub نفرستید.
- **فایل‌های فونت داخل ZIP بازتوزیع نشده‌اند**؛ پوشه `fonts` پروژه اصلی خود را دست‌نخورده نگه دارید.

## مواردی که حفظ شدند
- APIهای سرور، تنظیمات Vercel، پنل سایت، تایم‌لاین، Media Worker، برنامه‌های AE و فایل‌های ویدیویی و ابزارهای رندر.
- `assets/ffmpeg/ffmpeg-core.wasm` با وجود حجم زیاد، چون ابزار برش/فشرده‌سازی تحت وب به آن نیاز دارد.
- `CHANNEL-TAG-SIZE.txt` چون سرور After Effects از آن استفاده می‌کند.

## نصب ایمن روی نسخه موجود
1. از پوشه اصلی RushFinder و GitHub خود یک نسخه پشتیبان بگیرید.
2. محتوای ZIP را **روی پوشه موجود RushFinder** استخراج کنید و جایگزین فایل‌های هم‌نام کنید؛ پوشه `fonts` و فایل `vecteezy-worker-secret.local.txt` موجود را نگه دارید.
3. برای حذف فایل‌های قدیمیِ باقی‌مانده، ابتدا `CLEANUP-LITE.ps1` را به‌صورت پیش‌نمایش و بعد با `-Apply` اجرا کنید. پاکسازی فایل‌هایی را که از نسخه آپلودشده تغییر کرده‌اند حذف نمی‌کند و فایل‌های حذف‌شدنی را به پوشه پشتیبان **کنار** پوشه پروژه منتقل می‌کند.
4. قبل از ارسال به GitHub، `git status --short` را بررسی کنید. حواستان باشد فایل رمز محلی هرگز در Commit قرار نگیرد.
5. سپس تغییرات تأییدشده را commit/push کنید و انتشار Vercel را بررسی کنید.

### دستورهای اختیاری پاکسازی (در PowerShell داخل پوشه اصلی RushFinder)
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\CLEANUP-LITE.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\CLEANUP-LITE.ps1 -Apply
git status --short
```

## هشدار
- این فایل، **نسخه سبک‌شده کد فعلی** است و به معنی تکمیل قابلیت «Claude موشن‌گرافیک بسازد و در تایم‌لاین ویرایش شود» نیست.
- تست‌های محلی سینتکس/ساختار جای تست واقعی APIهای کلیددار روی Vercel یا بررسی کیفیت خروجی نیستند.
