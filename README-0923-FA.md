# RushFinder 0923 — اصلاح فونت وزیر و فاصله عنوان تنظیمات

این بسته فقط دو فایل `smart-edit.html` و `smart-edit.js` را به‌روزرسانی می‌کند.

## تغییرات
- استفاده از فونت Vazir در متن‌های محیط تدوین و دکمه‌ها با دو مسیر CDN جایگزین.
- استفاده از وزیر در متن‌های پیش‌نمایش Canvas؛ بازترسیم متن پس از بارگذاری فونت.
- فاصله بالای عنوان «پروژه و تنظیمات» و آیکن آن افزایش یافته است.
- منو، APIها، نریشن، موسیقی، ترنزیشن‌ها و سایر صفحات هیچ تغییری نکرده‌اند.

## انتشار
دو فایل را در **ریشه مخزن RushFinder** جایگزین و Commit / Push کنید.
پس از انتشار موفق روی Vercel، صفحه «تدوین» را با Ctrl+F5 باز کنید.
برای نمایش فونت، مرورگر باید بتواند به cdnjs یا jsDelivr متصل شود؛ در غیر این صورت فونت پشتیبان نمایش داده می‌شود.

هشدار: این ZIP را داخل پوشه api نریزید و فایل‌های api قدیمی را برنگردانید.
