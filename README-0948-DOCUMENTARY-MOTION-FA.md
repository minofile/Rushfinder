# RushFinder 0948 — موتور موشن‌گرافیک مستند قابل ویرایش

این بسته بر مبنای فایل `Rushfinder(8).zip` ساخته شده است. فایل محرمانه محلی موجود در ورودی عمداً در بسته جدید قرار نگرفته است.

## چه کاری واقعاً پیاده‌سازی شد؟

- Groq (یا Claude در صورت فعال‌بودن) متن را به سناریوی ساختاریافته تقسیم می‌کند. کلیدها فقط در Vercel استفاده می‌شوند.
- **تنها با همان دکمه ساخت**، صحنه‌ها و تیترها خودکار به تایم‌لاین چندمسیره اضافه می‌شوند.
- موتور Canvas برای پیش‌نمایش متحرک و فایل خروجی مشترک است: نقشه‌های *شماتیک* متحرک، نمودارهای *نمایشی*، خط زمانی، صفحات سند نمایشی، نقل‌قول و مقدمه/پایان مستند.
- روی کلیپ تایم‌لاین کلیک کن؛ در پنل ویرایش می‌توان نوع صحنه، برچسب کمکی، مکان، عدد تأییدشده، رنگ، حرکت، اندازه تیتر و زمان را تغییر داد. تیترها در ردیف جداگانه‌اند.
- فایل نریشن (MP3/WAV/M4A) در ردیف صدا قابل افزودن است. مدت صحنه‌ها در زمان تولید با طول نریشن واردشده مقیاس می‌شود؛ **هماهنگی کلمه‌به‌کلمه هنوز وجود ندارد**.
- دکمه «ذخیره پروژه لایه‌باز» فایل JSON **قابل بازشدن دوباره در RushFinder** ذخیره می‌کند. فایل صوتی و رسانه‌های خارجی باید جداگانه نگه داشته و دوباره اضافه شوند.
- خروجی فقط با کلیک دستی کاربر روی «خروجی ویدئو» شروع می‌شود. فرمت مستقیم بستگی به قابلیت MediaRecorder در مرورگر دارد: MP4 در مرورگرهای پشتیبانی‌شده وگرنه WebM.

## محدودیت‌های صریح

این نسخه **یک موتور گرافیک دوبعدی پیشرفته‌تر از کارت‌های ایستا** است، اما هنوز جایگزین کامل Premiere/After Effects نیست. به‌خصوص: نقشه جغرافیایی دقیق، مدل سه‌بعدی واقعی، داده اقتصادی معتبر خودکار، فوتیج تاریخی دارای مجوز و تولید تصویر فوتورئالیستی خودکار پیاده‌سازی نشده‌اند. نقشه و نمودار بدون داده معتبر باید «شماتیک/نمایشی» تلقی شوند. کیفیت بصری ویدیوی نمونه را **تضمین نمی‌کند**.

## انتشار

۱. از پوشه پروژه پشتیبان بگیر.
۲. محتویات ZIP را در پوشه اصلی GitHub Rushfinder استخراج کن (پوشه داخلی اضافه ایجاد نکن).
۳. `PUBLISH-0948-GITHUB.cmd` را اجرا کن.
۴. انتشار جدید را در Vercel بررسی کن تا **Ready** شود؛ سپس صفحه smart-edit را با Ctrl+F5 تازه کن.
۵. وجود `GROQ_API_KEY` یا `ANTHROPIC_API_KEY` در Environment Variables لازم است. API جدید لازم نیست.

**نکته امنیتی:** `vecteezy-worker-secret.local.txt` داخل ZIP آپلودشده وجود داشت. در بسته خروجی عمداً حذف شد. آن را به GitHub نفرست. برای احتیاط، اگر این بسته را قبلاً جایی منتشر کرده‌ای، رمز مشترک Media Worker را عوض کن.
