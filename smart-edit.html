▤ نریشن و متن برای تدوین هوشمند

متن یا فایل نریشن را وارد کن. جمنای متن را تحلیل می‌کند و صحنه‌های ویدیوهای عمومی یوتیوب را بررسی می‌کند تا زمان پیشنهادی کات روی نوار قرار بگیرد. اگر فقط فایل نریشن بدهی، برای فایل صوتی کوتاه ابتدا تبدیل به متن انجام می‌شود. پیش‌نمایش یوتیوب هنوز خروجی MP4 نیست.

✂ برش خودکار YouTube بر اساس نریشن

متن یا نریشن را تحلیل می‌کند؛ ویدیوهای عمومی یوتیوب را پیدا می‌کند، تصویر آن‌ها را با Gemini بررسی می‌کند و بازه‌های مناسب را با زمان‌بندی قابل ویرایش روی نوار می‌چیند. برای خروجی واقعی باید نسخه مجاز فایل ویدیو هم موجود باشد.

برای کات واقعی، برنامه RUN-0934-MEDIA-WORKER.cmd روی همین کامپیوتر باید در حال اجرا باشد.

جست‌وجو با YouTube API و تحلیل تصویر با Gemini API انجام می‌شود؛ کلیدها سمت سرور می‌مانند.

برای تطبیق خودکار، نام هر فایل باید شامل شناسه ۱۱ کاراکتری همان ویدیوی یوتیوب باشد (مثلاً a1b2c3d4e5F.mp4). پس از انتخاب، برش‌ها به نوار اصلی و خروجی واقعی منتقل می‌شوند. فایل‌ها به سرور ارسال نمی‌شوند.

کات‌های یوتیوب داخل نوار ویدئو پیش‌نمایش می‌شوند اما فایل واقعی نیستند و در خروجی MP4 نمی‌آیند. از محتوای YouTube مستقیماً MP4 ساخته نمی‌شود؛ برای خروجی ویدئویی واقعی باید فایل مجاز جداگانه داشته باشی. Gemini می‌تواند محتوای ویدیوهای عمومی را تحلیل کند، اما پیشنهادهای مدل خطاپذیرند و باید پیش از انتشار بازبینی شوند.

اگر آهنگ انتخاب نکنی، موسیقی ساده و اختصاصی ساخته می‌شود.
