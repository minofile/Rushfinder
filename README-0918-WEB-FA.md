# RushFinder 0918 — نسخه کامل وب، تدوین با طراحی روشن

این بسته برای جایگزینی فایل‌های وب در مخزن فعلی RushFinder تهیه شده است؛ پیش از جایگزینی از نسخه فعلی پشتیبان بگیرید.

## تغییرات این نسخه
- دکمه «تدوین» در منوی سمت راست که صفحه مستقل smart-edit.html را داخل سایت باز می‌کند.
- طراحی روشن و آبی، تایم‌لاین چندلایه، برش دستی، متن/نریشن/موسیقی، گزینه‌های ترنزیشن که در نسخه 0915 تأیید شده بودند.
- صدای خود راش‌های ویدئویی در پیش‌نمایش و خروجی خاموش شده است؛ فایل نریشن و موسیقی جداگانه پخش می‌شوند.
- تگ خبر، تقویم، فشرده‌سازی و بقیه صفحات سایت دست‌نخورده مانده‌اند.
- کلید YouTube API تنظیم یا منتشر نشده است. جست‌وجوی آنلاین بدون تنظیم سرویس‌ها تضمین نمی‌شود.

## انتشار
1. فایل ZIP را Extract All کنید.
2. **محتویات** پوشه را داخل پروژه فعلی RushFinder جایگزین کنید. فایل‌های موجود که در این بسته نیستند (به‌ویژه پوشه fonts) را حذف نکنید.
3. فایل‌های جدید را Commit و Push کنید تا Vercel نسخه جدید را منتشر کند.
4. پس از انتشار https://rushfinder.vercel.app/#smart-edit را باز و Ctrl+F5 بزنید.

## فونت
طبق درخواست، رابط کاربری از خانواده RFVazir با مسیرهای fonts/VAZIR-*-UI.TTF در مخزن فعلی شما استفاده می‌کند. **فایل‌های فونت داخل بسته قرار نگرفته‌اند**؛ پوشه fonts پروژه موجود را نگه دارید تا فونت وزیر نمایش داده شود.

## محدودیت‌ها
- برای فیلم‌های YouTube بدون فایلِ مجاز، API فقط جست‌وجو/پیش‌نمایش را ممکن می‌کند؛ ویدئوهای مرجع بدون دریافت فایل داخل MP4 رندر نمی‌شوند.
- یافتن و ورود خودکار راش آنلاین به مجوز منبع، اینترنت و دسترسی مرورگر/سرویس وابسته است.
- خروجی ممکن است برحسب پشتیبانی مرورگر MP4 یا WebM باشد.
- راه‌اندازهای قدیمی ویندوز و سرویس محلی مستقل هستند و نباید برای انتشار وب اجرا شوند.
- این نسخه روی سایت زنده منتشر نشده و تدوین انتها به انتها با فایل واقعی کاربر آزمایش نشده است.
