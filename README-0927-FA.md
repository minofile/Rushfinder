# RushFinder 0927 — اصلاح نسبت تصویر، پخش و برش‌های یوتیوب

این بسته از نسخهٔ 0926 ساخته شده و چهار فایل تغییر کرده است:

- `smart-edit.html` — قاب مشترک قابل تغییر ابعاد برای بوم خروجی و پیش‌نمایش YouTube؛ متن و راهنمای بهتر.
- `smart-edit.js` — هماهنگ‌سازی اندازه پیش‌نمایش، قطع پیش‌نمایش YouTube هنگام ورود به تدوین واقعی، افزایش محدود منابع مجاز.
- `smart-youtube.js` — اتصال ▶ اصلی، ⏪ و ⏩ و نشانگر زمان به برش‌های مجازی YouTube؛ نمایش برش‌های مجازی در نوار ویدئو؛ افزایش تعداد کات‌های پیشنهادی براساس طول نریشن؛ تغییر منبع/زمان برش؛ مدیریت حالت بدون فایل صوتی.
- `api/youtube-music.js` — جست‌وجوی ۱۸ نتیجه به‌جای ۵ نتیجه از کلید دوم (`YOUTUBE_SMARTEDIT_API_KEY`) و دریافت مدت ویدئو در صورت دسترسی؛ هیچ تابع API جدید ساخته نشده است.

## نصب
۱. ZIP اصلاحیه را استخراج کنید. فایل‌ها را در **همان مسیر** مخزن GitHub جایگزین کنید.
۲. در GitHub، Commit changes را بزنید.
۳. در Vercel، منتظر Ready شدن استقرار جدید شوید و صفحه تدوین را با Ctrl+F5 باز کنید.
۴. کلیدهای محیطی را تغییر ندهید. `YOUTUBE_API_KEY` قدیمی برای بخش‌های قبلی باقی می‌ماند؛ `YOUTUBE_SMARTEDIT_API_KEY` برای تدوین است.

## استفاده
- برای پیش‌نمایش کات‌های YouTube: متن را وارد کنید، منوی «✂ برش خودکار YouTube بر اساس نریشن» را باز کنید و دکمه جست‌وجو را بزنید. کلیپ‌های قابل پخش، **به‌صورت ارجاع مجازی** در ردیف YouTube و همچنین ردیف ویدئو نمایش داده می‌شوند. دکمه ▶ بزرگ زیر تصویر آن‌ها را پخش می‌کند؛ در صورت وجود نریشن، صدا مبنای زمان است.
- برای راش **واقعی و خروجی ویدئو**: از «پیدا کردن راش و ساخت کات خودکار» استفاده کنید. برنامه از آرشیوهای مجازِ در دسترس راش را به مرورگر دریافت می‌کند، با جست‌وجوی کلمات و بررسی تغییرات بصری برش‌های پیشنهادی می‌سازد و روی ردیف اصلی ویدئو می‌چیند. منابعی که API یا مجوز لازم ندارند کنار گذاشته می‌شوند.
- برای قاب مربع، سمت چپ «۱:۱» را انتخاب کنید؛ کادر خروجی و کادر پیش‌نمایش مربعی می‌شوند. چون خود ویدئوی YouTube ۱۶:۹ است، درون قاب مربعی بدون برش مخفیانه و با حاشیه نمایش داده می‌شود.

## محدودیت‌ها
- **YouTube Data API فایل MP4 ویدئوی دیگران را برنمی‌گرداند؛ «کات‌های YouTube» هنوز دانلودشده، قابل ویرایش به شکل فایل، یا قابل گنجاندن در خروجی نیستند.** این محدودیت با تغییر متغیر محیطی رفع نمی‌شود.
- تشخیص اینکه صحنه واقعاً مربوط به همان جملهٔ خبر است، با جست‌وجوی عنوان تضمین نمی‌شود. زمان‌های اولیهٔ برش YouTube از قواعد زمانی پیشنهاد می‌شوند و باید بازبینی شوند.
- حتی ویدئوهای قابل Embed ممکن است به‌علت تنظیمات مالک، منطقه یا محدودیت پخش خودکار در برخی مرورگرها پخش نشوند.
- خروجی ویدئو به فایل واقعی محلی/آرشیوی دارای حق استفاده وابسته است.
- مجموع توابع پوشه `api` هنوز **۱۲** است؛ سازگار با محدودیت Hobby پروژه قبلی.
