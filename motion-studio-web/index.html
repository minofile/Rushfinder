نسخه اجرایی Remotion هنوز منتشر نشده

این صفحه موتور Remotion نیست؛ صرفاً راهنمای تشخیص نصب ناقص است.

پس از انتشار اصلاحیه، در GitHub به Actions → Build Remotion Studio برو. باید Workflow سبز شود و سپس در Vercel وضعیت Ready نمایش داده شود.

وقتی Build کامل شد، این صفحه خودکار با Player واقعی جایگزین می‌شود. کلید API کلاد لازم نیست.
