# RushFinder 0932 — بررسی و اصلاحِ کات‌های یوتیوب

این نسخه بر پایه فایل‌های 0931 موجود در گفتگو ساخته شده؛ تغییرات احتمالی بعدی GitHub در این بسته نیستند.

## چه چیزی اصلاح شد
- زمان شروع کات دیگر با فرمول حدسیِ 3 + ... از داخل ویدئو ساخته نمی‌شود.
- فقط زمانی کات مجازی پیشنهاد می‌شود که **توضیحات خود ویدئوی یوتیوب دارای فصل‌بندی زمان‌دار (timestamp chapter)** باشد و عنوان فصل به موضوع جمله نریشن بخورد.
- بدون اطلاعات کافی، آن قسمت نریشن خالی باقی می‌ماند و لینک ویدئوهای پیشنهادی برای بررسی دستی نمایش داده می‌شود؛ به‌جای راش نامرتبط چیزی اضافه نمی‌شود.
- در پنل تنظیم کات، زمان شروع از مدت واقعی ویدئو فراتر نمی‌رود.
- تغییر طول برش، مدت کل نریشن را صفر/کوتاه نمی‌کند.
- با عوض کردن منبع یا پاک کردن فایل صوتی، وضعیت قبلی به‌اشتباه باقی نمی‌ماند.
- خروجی JSON و آدرس‌های منبع حفظ شده‌اند.
- تعداد توابع Serverless تغییری نکرده است.

## نصب
برای نصب اصلاحیه، این 3 فایل را در GitHub جایگزین کنید:
- `smart-edit.html`
- `smart-youtube.js`
- `api/youtube-music.js`

سپس GitHub Commit و استقرار جدید Vercel. نیازی به تغییر متغیرهای API نیست.

## محدودیت فنی مهم
YouTube Data API محتوای فریم‌های هر ویدئو را برای تحلیل تصویری در اختیار این برنامه نمی‌گذارد. فصل‌بندی سازنده هم ممکن است نادرست یا نامرتبط باشد. بنابراین هنوز «هوش مصنوعی تشخیص واقعی بهترین صحنه داخل ویدئو» نیست؛ فقط کات‌های **مجازی و زمان‌دار مبتنی بر اطلاعات منتشرشده** ساخته می‌شوند و باید قبل از انتشار بازبینی شوند. محتوای یوتیوب دانلود یا در خروجی MP4 ترکیب نمی‌شود.

## اعتبار آزمایش
بررسی syntax و آزمون‌های مستقل سرور و رابط، با پاسخ‌های شبیه‌سازی‌شده انجام می‌شوند. اتصال واقعی با کلید و سهمیه پروژه شما آزمایش نشده است.
