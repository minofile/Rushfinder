# راهنمای فارسی RushFinder 0967 — AvalAI Image

## این اصلاحیه چه می‌کند؟
خطای `Incorrect API key` با کلید `aa-...` زمانی رخ می‌دهد که کلید AvalAI به‌اشتباه به `api.openai.com` فرستاده شود. این اصلاحیه فقط مسیر اینفوگرافیک را به AvalAI تغییر می‌دهد و از همان تابع موجود `api/avalai-image.js` استفاده می‌کند؛ تعداد توابع Vercel زیاد نمی‌شود.

- نشانی API: `https://api.avalai.ir/v1`
- متغیر Vercel: `AVALAI_API_KEY`
- مدل پیش‌فرض: `gpt-image-2.5-flare`
- مدل‌های قابل انتخاب: `gpt-image-2.5-flare`، `gpt-image-2.5-sunburst`، `gpt-image-2`
- ابزار تدوین و اتصال Hermes تغییر نمی‌کنند.

## نصب
۱. فایل ZIP را در پوشه اصلی GitHub پروژه RushFinder که `infographic.html` در آن است استخراج و جایگزین کنید.
۲. فایل `PUBLISH-0967-AVALAI-IMAGE.cmd` را اجرا کنید.
۳. در Vercel به Project → Settings → Environment Variables بروید و متغیر `AVALAI_API_KEY` را بسازید و **کلید AvalAI خودتان** را در Value آن ثبت کنید. از کلید OpenAI رسمی در این متغیر استفاده نکنید. `RF_INFO_ACCESS_CODE` قبلی را نگه دارید.
۴. Production را فعال کنید، Save و سپس در Deployments → Redeploy بزنید. وضعیت باید Ready شود.
۵. در صفحه اینفو، Ctrl+F5 بزنید؛ همان رمز مدیر قبلی را وارد کنید و «بررسی اتصال AvalAI» را بزنید. این تست تصویر پولی نمی‌سازد و مجوز مدل را تضمین نمی‌کند.
۶. پس از موفقیت تست، فقط یک تصویر با مدل Flare و کیفیت Low ایجاد کنید. برای ساخت تصویر تأیید کاربر لازم است و هزینه از حساب AvalAI کسر می‌شود.

اگر خطای 401 ماند، کلید ثبت‌شده در `AVALAI_API_KEY` را در پنل AvalAI بررسی کنید. اگر 403 یا model_not_allowed شد، دسترسی/سطح حساب و مدل انتخابی را در AvalAI بررسی کنید. کلید را در چت یا GitHub قرار ندهید. در صورت لزوم فقط نام متغیرها یا متن خطا را ارسال کنید.

این بسته با پاسخ شبیه‌سازی‌شده آزمایش می‌شود؛ **تولید تصویر واقعی با کلید شما در این محیط انجام نشده است.**
