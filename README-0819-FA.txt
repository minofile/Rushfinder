RushFinder Web 0819 - کنترل مستقیم اندازه تگ کانال
=================================================
این نسخه مشکل تغییر نکردن اندازه تگ کانال را با ارسال مستقیم درصد از صفحه وب رفع می‌کند.
هنگام انتخاب «تگ کانال» زیر قسمت انتخاب فیلم، نوار «اندازه تگ کانال روی فیلم» ظاهر می‌شود.
مقدار اولیه 20 درصد است. می‌توانید آن را بین 6 تا 40 درصد تغییر دهید.
عدد انتخاب‌شده همراه درخواست ساخت به موتور فرستاده می‌شود و موتور آن را برای همان ویدیو اعمال می‌کند.
پس از ساخت، مقدار واقعی اعمال‌شده و عرض پیکسلی به‌صورت فارسی نمایش داده می‌شود.

فایل CHANNEL-TAG-SIZE.txt همچنان پشتیبانی می‌شود و مقدار اولیه را تأمین می‌کند؛
ولی برای نتیجه قابل‌اعتماد، اندازه را مستقیماً از نوار داخل وب انتخاب کنید.

نصب:
1. از پروژه پشتیبان بگیرید. پوشه مخفی .git را حذف نکنید.
2. محتوای ZIP را داخل ریشه Rushfinder (کنار Start-RushFinder.cmd) جایگزین کنید.
3. در GitHub Desktop، Commit و Push کنید تا نسخه وب آنلاین هم به 0819 برسد.
4. موتور قبلی را ببندید و Start-RushFinder.cmd را از پوشه پروژه اجرا کنید.
5. در http://127.0.0.1:18826/ae-api/check این مقادیر را بررسی کنید:
   "engineBuild":"0819-channel-size-control"
   "channelTagControl":true
   "channelTag":true
6. در بخش تگ کانال درصد دلخواه (مثلاً 20 یا 24) را انتخاب کنید و یک فیلم جدید بسازید.
7. پایین نوار درصد واقعی اعمال‌شده پس از آماده‌شدن خروجی ظاهر می‌شود.

پورت 18826 و موتور API 0813 حفظ شده‌اند. ساخت نام خبرنگار/After Effects/AEP تغییری نکرده است.
