# RushFinder SmartEdit 0908 — اصلاح مسیر تدوین از متن

- برای متن خبر از تب «✦ تدوین از متن» استفاده کنید، نه «تیتر روی فیلم».
- اگر در تب تیتر روی فیلم، بدون راش دکمه افزودن متن را بزنید، به بخش تدوین از متن هدایت می‌شوید.
- در سایت آنلاین، جست‌وجوی آرشیو مجاز به کلید Pexels یا Pixabay در Vercel نیاز دارد؛ کلید را در مخزن GitHub قرار ندهید.
- هیچ دانلود خودکار از YouTube، Aparat یا YTUltra ادعا یا پیاده‌سازی نشده است. این سرویس‌ها فقط برای یافتن لینک و بررسی محتوا قابل جست‌وجو هستند.
- در حالت آفلاین با راه‌انداز TEST-0908-OFFLINE.cmd، گزینه «تست با راش نمونه» فعال است؛ ویدئوهای نمونه ساختگی‌اند، نه راش خبری واقعی.
- سایر قسمت‌های سایت از نسخه 0907 حفظ شده‌اند.
- پردازش فایل‌های انتخاب‌شده داخل مرورگر است؛ متن جست‌وجو در صورت فعال‌کردن جست‌وجوی آنلاین به سرویس آرشیو منتخب ارسال می‌شود.
