# RushFinder 0954 — Hermes + صفحه تدوین خلوت

## چه چیزی واقعاً ساخته شده؟

- صفحه تدوین: فرم اختصاصی Hermes (متن، فایل نریشن، کد دسترسی، وضعیت سفارش، ورود خودکار نتیجه).
- ابزارهای قبلی Groq/YouTube و تنظیمات، حذف نشده‌اند؛ پشت «ابزارهای قبلی» مخفی شده‌اند.
- دکمه خراب Remotion Studio از صفحه برداشته شده است.
- تایم‌لاین، پیش‌نمایش، برش/حذف، تیترها، نریشن و دکمه خروجی قبلی حفظ شده‌اند.
- `api/hermes.js`: واسط سرور Vercel؛ هیچ کلید خصوصی به مرورگر ارسال نمی‌شود.
- `hermes-bridge/bridge.py`: برنامه ویندوز/پایتون روی سیستم همکار که درخواست‌ها را نگه می‌دارد، یک دستور Hermes را اجرا می‌کند و خروجی را تحویل می‌دهد.

**مهم:** این ZIP اتصال نهایی به سیستم همکار را *خودکار انجام نمی‌دهد*. تا اجرای bridge و تنظیم دامنه HTTPS و متغیرهای Vercel، سایت وضعیت «نیازمند اتصال مدیر سایت» نشان می‌دهد و هیچ سفارش ساختگی ثبت نمی‌کند.

## ۱ — انتشار سایت

۱. ZIP را در **همان پوشه GitHub فعلی RushFinder** استخراج کنید (جای `smart-edit.html`، نه یک پروژه تازه).
۲. `PUBLISH-0954-HERMES.cmd` را اجرا کنید. فایل‌های مورد نیاز سایت و تنها مرجع نسخه iframe در index.html به GitHub Push می‌شوند؛ `bridge-config.local.json` اصلاً منتشر نمی‌شود.
۳. منتظر وضعیت **Ready** در Vercel بمانید و با Ctrl+F5 باز کنید.

## ۲ — روی سیستم همکار، کنار Hermes فعال

۱. پوشه `hermes-bridge` را روی کامپیوتر همکار کپی کنید، نه داخل پوشه عمومی وب.
۲. Python 3 باید نصب باشد. فایل `START-HERMES-BRIDGE.cmd` را یک بار اجرا کنید؛ در اولین اجرا `bridge-config.local.json` ساخته می‌شود.
۳. فایل `bridge-config.local.json` را باز کنید. **`bridge_key` را محرمانه نگه دارید**. مقدار `hermes_command` پیش‌فرض `["hermes", "-z", "{prompt}"]` است. اگر تدوین موفق همکارتان با اسکریپت یا Skill دیگری اجرا می‌شود، این قسمت را با فرمان واقعی همان سیستم تنظیم کنید؛ نام فرمان را حدس نزنید. الگوی `{prompt_file}` و `{job_dir}` هم پشتیبانی می‌شود.
۴. با Cloudflare Tunnel یا معادل امن آن، `http://127.0.0.1:8787` را **به یک HTTPS عمومی** متصل کنید. پورت روتر را مستقیم باز نکنید. برای تست موقت Cloudflare Quick Tunnel می‌توانید از `cloudflared tunnel --url http://127.0.0.1:8787` استفاده کنید، اما آدرس Quick Tunnel پایدار نیست. در `bridge-config.local.json`، `public_url` را روی همان HTTPS تنظیم کنید و bridge را دوباره اجرا کنید.
۵. `site_origin` به‌صورت پیش‌فرض `https://rushfinder.vercel.app` است. اگر دامنه اصلی سایت فرق دارد، تغییرش دهید. **فقط** دامنه سایت برای خواندن رسانه‌ها CORS می‌گیرد.

Bridge روی `127.0.0.1` گوش می‌دهد و حتی از LAN مستقیم قابل دسترسی نیست؛ تونل باید روی همان سیستم همکار اجرا شود.

## ۳ — متغیرهای Vercel (Settings → Environment Variables)

```
RF_HERMES_BRIDGE_URL=https://YOUR-TUNNEL-DOMAIN
RF_HERMES_BRIDGE_KEY=<bridge_key از فایل محلی سیستم همکار>
RF_HERMES_SITE_CODE=<یک کد قویِ اختصاصی برای مجوز سفارش کاربران>
```

کدها و کلیدها را **در چت ارسال نکنید**. پس از ثبت، Redeploy کنید. هنگام استفاده، اپراتور سایت `RF_HERMES_SITE_CODE` را در باکس «کد دسترسی تدوین» وارد می‌کند. این محدودیت مانع درخواست تدوین بی‌مجوز از سوی بازدیدکنندگان عمومی می‌شود. راهکار کامل چندکاربره در آینده نیازمند ورود کاربران و سهمیه‌بندی است.

## قرارداد خروجی Hermes

Hermes/اسکریپت تدوین باید در پوشه همان سفارش در `output` یکی از این دو را بسازد:

الف) **خروجی حرفه‌ایِ قابل ویرایش**:

`output/rushfinder-project.json`:

```json
{
  "version": 1,
  "scenes": [
    {"file":"scene-01.mp4","title":"عنوان صحنه اول","duration":5.0,"type":"video"},
    {"file":"scene-02.mp4","title":"عنوان صحنه دوم","duration":7.0,"type":"video"}
  ],
  "voice": "narration.mp3"
}
```

فایل‌های `scene-01.mp4`، `scene-02.mp4` و `narration.mp3` باید در پوشه `output` باشند. هر صحنه روی ردیف ویدئو جداگانه قرار می‌گیرد؛ تیترها روی ردیف متن و نریشن روی ردیف صدا قرار می‌گیرد. می‌توان هر صحنه را برش یا حذف و تیترها را ویرایش کرد. برای کیفیت بهتر، MP4ها باید H.264/AAC قابل پخش در مرورگر باشند. این نسخه هنوز فایل پروژه داخلی Premiere/After Effects/Remotion را مستقیم وارد نمی‌کند و همه لایه‌های داخل یک MP4 را نمی‌تواند جدا کند.

ب) **خروجی تخت**: اگر فقط `output/final.mp4` وجود داشته باشد، سایت آن را **یک کلیپ** وارد می‌کند. قابل برش و حذف است اما نقشه‌ها/متن‌های رندرشده داخل فایل مستقل قابل انتخاب نیستند.

فایل `output/final.mp4` در حالت الف نیز می‌تواند به‌عنوان پیش‌نمایش اختیاری وجود داشته باشد. دکمه Export فعلی سایت تنها پس از کلیک کاربر عمل می‌کند.

## فایل نریشن

در نسخه 0954 حداکثر **۲ مگابایت** صوت با درخواست مستقیم ارسال می‌شود، زیرا تابع‌های Vercel محدودیت اندازه ورودی دارند. برای نریشن‌های طولانی و فایل ویدئوی حجیم، بعداً به آپلود مستقیم در فضای ذخیره‌سازی امن احتیاج داریم. فایل‌های تصویری خروجی روی سیستم همکار ذخیره می‌شوند؛ سایت لینک‌های دارای بلیت تصادفی (signed link) دریافت می‌کند.

## امنیت و ملاحظات عملیاتی

- Hermes توانایی اجرای فرمان دارد؛ worker را روی **حساب کاربری محدود** و کامپیوتر اختصاصی اجرا کنید، نه با دسترسی مدیر سیستم و نه کنار فایل‌های محرمانه.
- تونل HTTPS و کلید طولانی اجباری است؛ `RF_HERMES_SITE_CODE` نیز فعال باشد. کلید worker را هیچ‌وقت به Frontend ندهید.
- فایل‌های `bridge-config.local.json` و `jobs/` در `.gitignore` قرار گرفته‌اند. از آن‌ها در GitHub/ZIP عمومی نسخه‌برداری نکنید.
- سرعت، کیفیت و مجوز استفاده از تصاویر تاریخی بستگی به Skill واقعی Hermes همکارتان دارد؛ این نسخه به‌خودی‌خود کیفیت مستند مرجع را تضمین نمی‌کند.
- ربات تلگرام که از قبل به Hermes وصل است، همچنان مسیر خودش را دارد. برای تحویل خودکار پروژه‌های تلگرام در همان صف/تایم‌لاین سایت، باید Skill یا webhook ربات هم با این قرارداد خروجی یکپارچه شود؛ در این پچ اتصال ربات فعلی تغییر نکرده است.

## بررسی سلامت

- سایت: `https://rushfinder.vercel.app/api/hermes` باید JSON با `configured` و `online` بدهد؛ اگر `online:false` باشد، تونل یا bridge خاموش است.
- سیستم همکار: `http://127.0.0.1:8787/health` باید `{"ok":true,...}` بدهد.
- خطای سفارش در پنل، به همراه شماره سفارش، و گزارش کامل‌تر در `hermes-bridge/jobs/<job-id>/hermes.log` روی همان سیستم قابل بررسی است.

**نکته انتشار:** پروژه فعلی ۱۱ تابع `/api` دارد؛ اضافه‌کردن این یک تابع در سقف ۱۲ تابع Vercel Hobby می‌ماند، به شرط آنکه شما تابع دیگری اضافه نکرده باشید.
