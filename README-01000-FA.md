# RushFinder WEB 01000 — لوگوی ثابت در تمام اینفوگرافیک‌ها

## هدف

- لوگوی «خبر فوری» از فایل اصلی و دقیق شما `خبرفوری.png` برداشته شده و **بدون تغییر پیکسلی** در `assets/infographic-templates/urgent-square.png` قرار دارد.
- محتوای ساخته‌شده توسط AvalAI فقط در فضای محتوا قرار می‌گیرد؛ نوار کنار، نوشتهٔ سبز، شکل لوگو و حاشیهٔ قالب در لایه‌ای ثابت و محافظت‌شده باقی می‌ماند.
- برای «اخبار مشهد» و «جریان» قالب‌های ثابت همان برند استفاده می‌شود و برای «خبرفردا» مشکل نمایش اشتباهی لوگوی «خبر فوری» برطرف شده است.
- قالب استوری و مربع جداگانه حفظ می‌شوند. تصویر انتخاب‌شده در پیش‌نمایش و فایل PNG دانلودی یکسان ترکیب می‌شود. تا فایل قالب اصلی بارگذاری نشود خروجی تصویر AI مجاز نیست.
- سیستم تولید تصویر همچنان به `AVALAI_API_KEY` و رمز مدیر `RF_INFO_ACCESS_CODE` در Vercel متکی است. هیچ هزینه‌ای برای تست محلی این نسخه صرف نشده است.

## نصب پیشنهادی: فقط اصلاحیه

۱. در پروژه **فعلی** RushFinder (پوشهٔ GitHub) فقط فایل ZIP `RushFinder_01000_INFO_BRAND_LOCK_PATCH.zip` را استخراج و فایل‌های هم‌نام را جایگزین کنید.
۲. `PUBLISH-01000-INFO.cmd` را اجرا کنید.
۳. در Vercel آخرین Deployment باید سبز **Ready** باشد. سپس روی صفحه اینفوگرافیک `Ctrl+F5` بزنید.
۴. ابتدا با **عکس خروجی قبلی** تست کنید. برای تولید تصویر جدید لازم است درخواست پولی را خودتان تأیید کنید.

## نسخه کامل

فایل `RushFinder_01000_WEB_FULL.zip` برای نصب نو / بررسی همه فایل‌های وب است. چون فایل‌های محلی سایت شما ممکن است تغییرات جدید داشته باشند، برای سایت فعال بهتر است از **اصلاحیه کوچک** استفاده کنید، نه جایگزینی کامل پوشه بدون پشتیبان.

## نکات مهم

- لوگوی دقیق با کامپوزیت محلی قفل است، اما متن فارسی داخل تصویر ساخته‌شده توسط هوش مصنوعی ممکن است غلط باشد. متن، آمار و اسامی را قبل از انتشار بررسی کنید.
- برای نسخه **استوری** «خبر فوری»، از فایل قالب استوری موجود پروژه استفاده می‌شود. اگر فایل استوری نهایی دیگری دارید باید همان فایل را جایگزین کنید.
- این نسخه فقط روی اینفوگرافیک اثر می‌گذارد و Hermes، Groq و سایر مسیرهای تدوین را تغییر نمی‌دهد.
