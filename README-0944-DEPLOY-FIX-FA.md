# RushFinder 0944 — رفع خطای انتشار Vercel (نسخه وب)

## دلیل
نسخه 0943 دارای ۱۳ تابع مستقل در پوشه `api` بود؛ پروژه Hobby در حالت Vercel Functions مستقیم، حداکثر ۱۲ تابع در هر انتشار دارد. این موضوع می‌تواند موجب خطای Deploy بعد از `Build Completed` شود. این تشخیص از ساختار کد و لاگ موجود به دست آمده؛ پیام نهایی خطای Vercel در تصویر کاربر دیده نشده بود.

## اصلاح
- تابع تولید سناریوی Claude به `api/chat.js?mode=claude-motion-plan` انتقال یافت.
- درخواست مرورگر در `claude-motion-editor.js` به مسیر جدید تغییر یافت.
- یک Rewrite برای مسیر قبلی گذاشته شد تا مرورگرهای دارای فایل کش قدیمی نیز کار کنند.
- **فایل قدیمی `api/claude-motion-plan.js` باید حذف شود.** باقی ماندن آن یعنی همان ۱۳ تابع و ادامه خطای انتشار.
- محدودیت تعداد درخواست مشترک چت برای این تابع نیز فعال است.
- گزینه ChatGPT همچنان غیرفعال است؛ تولید سناریوی موشن از Claude استفاده می‌کند.
- خروجی MP4 فقط با دستور کاربر انجام می‌شود.

## نصب بدون تکرار ادیت‌ها
۱. محتویات ZIP را به ریشه مخزن RushFinder کپی کن.
۲. `PUBLISH-0944-FIX.cmd` را از داخل **همان پوشه اصلی GitHub پروژه** اجرا کن؛ این اسکریپت فایل API قدیمی را حذف می‌کند و تغییرات مشخص را ارسال می‌کند.
۳. در Vercel منتظر Ready باش. اگر خطای دیگری باقی ماند، متن خطای Deployment را بررسی کن.
۴. صفحه `/smart-edit.html` را با Ctrl+F5 تازه کن.

## بررسی فنی
`api/` در نسخه اصلاح‌شده باید دقیقاً ۱۲ فایل جاوااسکریپت داشته باشد. فایل `api/claude-motion-plan.js` نباید در `git ls-tree` دیده شود.

کلیدهای API و فایل رمز Media Worker را تغییر نده؛ هرگز آنها را به GitHub ارسال نکن.
