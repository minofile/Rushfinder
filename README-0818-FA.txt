RushFinder Web 0818 - Adjustable Channel Tag (راهنمای فارسی)
=======================================================
نسخه 0818: تنظیم آسان اندازه تگ کانال خبرفوری (بدون دست‌زدن به کدهای JS).

فایل جدید: CHANNEL-TAG-SIZE.txt
- داخل همین پوشه اصلی پروژه Rushfinder قرار دارد، کنار Start-RushFinder.cmd
- فایل را با Notepad باز کنید و تنها عدد داخل آن را تغییر دهید.
- 8  = اندازه قبلی (خیلی کوچک)
- 10 = کمی بزرگ‌تر از قبلی
- 12 = اندازه پیش‌فرض این نسخه؛ پیشنهاد فعلی
- 14 = کمی بزرگ‌تر
- 16 = بزرگ‌تر
- عدد مجاز از 5 تا 40 است. اگر فایل نباشد یا عدد اشتباه باشد، 12 استفاده می‌شود.
- تنظیم جدید در ساخت فیلم بعدی خوانده می‌شود؛ نیازی به ویرایش فایل ae-auto-server.js نیست.
- فیلم‌های ساخته‌شده قبلی تغییر نمی‌کنند.

نصب:
1) از پوشه پروژه فعلی نسخه پشتیبان بگیرید و پوشه .git را حفظ کنید.
2) تمام فایل‌های ZIP را در ریشه پوشه Rushfinder استخراج و جایگزین کنید؛
   فایل CHANNEL-TAG-SIZE.txt باید کنار ae-auto-server.js و Start-RushFinder.cmd باشد.
3) از GitHub Desktop، Commit و Push انجام دهید.
4) موتور فعلی را ببندید و Start-RushFinder.cmd را از همان پوشه اجرا کنید.
5) آدرس http://127.0.0.1:18826/ae-api/check را باز کنید. باید ببینید:
   "engineBuild":"0818-channel-adjustable"
   "channelTagWidthPercent":12
   "channelTag":true
   در صورت مشاهده نشدن engineBuild بالا، موتور قبلی هنوز اجراست.
6) فیلم جدید بسازید. اگر اندازه دلخواه نبود، فقط عدد فایل CHANNEL-TAG-SIZE.txt
   را تغییر داده و ذخیره کنید؛ هنگام ساخت فیلم بعدی، مقدار جدید خوانده می‌شود.

نکته: فقط اندازه تگ کانال تغییر می‌کند. تگ نام خبرنگار و مسیر AEP/AE دست‌نخورده است.
نسخه API موتور 0813 و پورت محلی 18826 حفظ شده است.
این ZIP به‌صورت خودکار روی GitHub یا Vercel منتشر نمی‌شود.
