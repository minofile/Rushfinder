# RushFinder 0843 — بسته کامل وب برای GitHub / Vercel

## تغییرات مشخص و محدود
- رفع خطای بازنشدن بخش «تگ خبر» نسخه 0841 حفظ شد؛ فایل `news-tag.html` در iframe بارگذاری می‌شود.
- در `ae-auto-server.js` دامنه اصلی `https://rushfinder.vercel.app` به فهرست محدود مبدأهای مجاز موتور رندر محلی اضافه شد. فهرست به‌صورت عمومی (`*`) باز نشده است.
- مسیرها و نشانه‌های کش صفحات تگ خبر و کم‌حجم‌کننده به 0843 به‌روزرسانی شدند.
- نشانی نسخه قدیمی 0837 در راه‌انداز محلی فقط به 0843 تغییر کرده است. رفتار بازشدن صفحه **همچنان محلی** است و راه‌انداز جدیدی برای بازکردن سایت آنلاین اضافه نشده است.
- موتور محلی با شاخص `webOriginAllowed` خودش را به راه‌انداز معرفی می‌کند. در صورتی که موتور قبلی **از همین پوشه** هنوز فعال باشد، راه‌انداز موجود می‌تواند مطابق کنترل‌های قبلی خودش آن را دوباره اجرا کند. موتور متعلق به پوشه دیگر خودکار بسته نمی‌شود.
- منطق کم‌حجم‌کننده، رزولوشن، کیفیت و بخش‌های دیگر سایت تغییر داده نشده‌اند.

## نصب نسخه وب
1. از پروژه اصلی در GitHub یک نسخه پشتیبان تهیه کنید.
2. این ZIP را در رایانه استخراج کنید. **محتویات** پوشه استخراج‌شده را در ریشه مخزن GitHub / پروژه RushFinder قرار دهید (نه خود فایل ZIP و نه یک پوشه تو‌در‌توی اضافی).
3. تغییرات را Commit و Push کنید. انتشار در Vercel در صورت فعال‌بودن اتصال مخزن انجام می‌شود.
4. پس از انتشار، سایت `https://rushfinder.vercel.app` را با Ctrl+F5 تازه‌سازی کنید.

## نکته ضروری: موتور رندر روی ویندوز
تغییر فایل‌ها در GitHub به‌تنهایی موتور محلی در حال اجرای رایانه را تغییر نمی‌دهد. فایل `ae-auto-server.js` از انتشار در Vercel مستثنا است و فقط روی رایانه ویندوزی اجرا می‌شود. برای فعال‌شدن اجازه اتصال جدید:
1. فایل جدید `ae-auto-server.js` را در **همان پوشه‌ای که موتور RushFinder واقعاً از آن اجرا می‌شود** جایگزین کنید.
2. همان موتور را متوقف و با فایل `Start-RushFinder.cmd` مربوط به همان پوشه دوباره اجرا کنید. اگر موتور در پوشه دیگری پورت 18827 را گرفته است، باید ابتدا همان نسخه قدیمی را ببندید.
3. آدرس `http://127.0.0.1:18827/ae-api/check` را روی **همان رایانه** باز کنید؛ در خروجی JSON باید `"webOriginAllowed": true` دیده شود.
4. روی سایت اصلی تگ خبر را باز کنید. اگر Chrome اجازه دسترسی به شبکه محلی خواست، فقط اگر موتور خودتان است اجازه بدهید. بعضی سیاست‌های مرورگر یا شبکه ممکن است همچنان اتصال سایت به localhost را محدود کنند.

## مرزهای عملکرد
- موتور After Effects روی Vercel اجرا نمی‌شود؛ سایت آنلاین فقط به موتور روی کامپیوتر خود کاربر درخواست می‌دهد.
- هنگام استفاده از «تگ خبر»، ویدیو برای پردازش از مرورگر به **موتور محلی روی همان رایانه** فرستاده می‌شود، نه به Vercel. کم‌حجم‌کننده نیز در مرورگر کار می‌کند و فیلم را به Vercel آپلود نمی‌کند.
- راه‌انداز CMD برای ویندوز است و لازم نیست در Vercel اجرا شود.
- انتشار روی دامنه واقعی و پردازش After Effects در ویندوز کاربر در این محیط تست عملی نشده است.
