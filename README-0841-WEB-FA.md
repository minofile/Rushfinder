# RushFinder 0841 — رفع مشکل بازنشدن «تگ خبر» در نسخه وب

## علت
در نسخه‌های وب 0838 تا 0840، کد `index.html` هنگام آماده‌کردن صفحه تگ خبر به متغیر `tagDocument` ارجاع می‌داد، درحالی‌که این متغیر از فایل اصلی حذف شده بود. این خطا باعث می‌شد بخش «تگ خبر» اصلاً راه‌اندازی نشود.

## اصلاح
- صفحه «تگ خبر» اکنون از فایل واقعی `news-tag.html` بارگذاری می‌شود؛ متغیر ناموجود حذف شده است.
- ورود به تگ خبر، پنجره کم‌حجم‌کننده و سایر پنجره‌های شناور باز را می‌بندد تا روی آن قرار نگیرند.
- مسیرها و قابلیت کم‌حجم‌کننده نسخه 0840 حفظ شده‌اند.

## نصب روی سایت
فایل‌های ZIP را در مخزن پروژه GitHub جایگزین، Commit و Push کنید. در صورت اتصال خودکار Vercel، پس از انتشار سایت را با Ctrl+F5 تازه‌سازی کنید.

## نکته مهم درباره رندر تگ
صفحه تگ خبر روی وب باز می‌شود، ولی عملیات ساخت ویدئوی تگ نیازمند موتور محلی After Effects روی رایانه دارای ویندوز است. بازشدن رابط وب به معنای آماده‌بودن موتور رندر نیست.

## تغییرات ناخواسته
هیچ فیلمی توسط کم‌حجم‌کننده به سرور منتقل نمی‌شود؛ این اصلاح کد کم‌حجم‌کننده را تغییر نداده است.
