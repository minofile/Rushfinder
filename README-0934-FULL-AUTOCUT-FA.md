# RushFinder 0934 — نسخه کامل تدوین خودکار واقعی (آزمایشی)

این ZIP **کل فایل‌های پروژه** را دارد، نه فقط یک پچ. با نسخه 0933 ادغام شده و پروژه‌های قدیمی/قالب‌ها را حفظ می‌کند.

## قابلیت جدید

- متن نریشن یا فایل صوتی را می‌گیرد (فایل نریشن بلند نیز با FFmpeg به قسمت‌های کوچک تقسیم و با Gemini پیاده‌سازی می‌شود؛ برای نریشن بیش از حدود ۹ دقیقه، متن همراه فایل لازم است).
- Gemini متن را تحلیل می‌کند، YouTube Data API و جست‌وجوی عمومی آپارات نامزدها را می‌یابند.
- Gemini محتوای واقعی ویدیوهای عمومی یوتیوب یا فریم‌های استخراج‌شده از ویدیوهای آپارات را برای تعیین تایم‌کد ارزیابی می‌کند؛ صرفاً از عنوان ویدیو کات نمی‌سازد.
- برشگر محلی در ویندوز با `yt-dlp` و `FFmpeg` فایل‌های **مجاز و قابل‌دریافت** را دریافت و برش واقعی MP4 تولید می‌کند.
- کلیپ‌های واقعی به‌طور خودکار وارد لایه «ویدئو/راش» می‌شوند؛ نریشن روی لایه صوتی جداگانه می‌ماند. بازه‌های نامرتبط خالی می‌مانند.
- خروجی از دکمه معمول «خروجی ویدیو» گرفته می‌شود. نوع فایل خروجی MP4 یا WebM به پشتیبانی مرورگر بستگی دارد.

## نصب سریع برای سایت متصل به GitHub و Vercel

1. **قبل از تغییر، از پوشه GitHub پروژه نسخه پشتیبان بگیرید.** تمام محتویات این ZIP را در پوشه اصلی مخزن Rushfinder کپی کنید، بدون حذف پوشه مخفی `.git`.
2. در PowerShell داخل پوشه پروژه:

   ```powershell
   git add .
   git commit -m "RushFinder 0934 real autocut"
   git push
   ```

3. در Vercel > Settings > Environment Variables بررسی کنید `GEMINI_API_KEY` و `YOUTUBE_API_KEY` (یا نام‌های جایگزین درج‌شده در README 0933) موجود باشند. کلیدها را به فایل‌های سایت اضافه نکنید. Deployment جدید باید Ready شود.
4. روی همان کامپیوتر ویندوزی که سایت را باز می‌کنید، Python 3 و FFmpeg نصب باشد. در صورت نیاز ابتدا `setup-ffmpeg.ps1` را اجرا کنید. **`RUN-0934-MEDIA-WORKER.cmd` را باز بگذارید.** این فایل `yt-dlp` را در صورت نبودن نصب می‌کند و یک سرویس فقط محلی روی `127.0.0.1:8767` اجرا می‌کند.
5. در Chrome روی **همان کامپیوتر** صفحه `https://rushfinder.vercel.app/smart-edit.html` را باز کنید و `Ctrl+F5` بزنید. نریشن/متن وارد کنید، منبع را انتخاب کنید، مجوز استفاده را تأیید کنید و دکمه «جست‌وجو، دیدن صحنه، کات واقعی و قراردادن خودکار روی نوار» یا دکمه اصلی «تدوین خودکار واقعی» را بزنید.

اگر آدرس سایتتان `https://rushfinder.vercel.app` نیست، پیش از اجرای Worker متغیر محیطی `RUSHFINDER_SITE_ORIGINS` را با Origin واقعی سایت تنظیم کنید و پنجره Worker را مجدد اجرا کنید؛ برای مثال:

```powershell
$env:RUSHFINDER_SITE_ORIGINS='https://YOUR-PROJECT.vercel.app,http://localhost:8000'
py -3 tools\rf_media_worker.py
```

## نکته فنی مهم

- **صرف API Gemini و YouTube برای دانلود و برش واقعی کافی نیست.** سایت Vercel فقط جست‌وجو/تحلیل را انجام می‌دهد؛ Worker برای دریافت فایل و اجرای FFmpeg ضروری است. بدون باز بودن Worker، کات واقعی اجرا نمی‌شود.
- سرویس Worker به‌صورت پیش‌فرض فقط روی `127.0.0.1` گوش می‌دهد. برای استفاده از سیستم‌های دیگر یا همیشه روشن بودن، نیاز به استقرار امن Worker و ذخیره‌سازی رسانه دارید؛ نسخه حاضر یک Worker دسکتاپ است.
- دریافت ویدیوی یوتیوب/آپارات ممکن است به‌دلیل محدودیت خود پلتفرم، نبود فایل قابل‌دریافت یا محدودیت منطقه‌ای ناموفق باشد؛ تأیید مجوز استفاده به معنی تضمین اجازه دانلود از پلتفرم نیست. از منابعی استفاده کنید که حق دریافت و تدوین‌شان را دارید.
- جست‌وجوی آپارات از endpoint عمومی قدیمی استفاده می‌کند که پایداری/دسترسی دائمی آن تضمین نشده است.
- صحنه‌های تأییدشده توسط Gemini هنوز احتمال خطا دارند؛ پیش از انتشار اخبار با چشم بررسی کنید.
- سقف نسخه آزمایشی: حداکثر ۸ بخش نریشن در تدوین، ۱۲ کلیپ واقعی، ۱۲ قطعه برای پیاده‌سازی نریشن بلند، ویدیوهای منبع حداکثر ۳۰ دقیقه. نرخ API و موجود بودن FFmpeg/yt-dlp روی Windows اثرگذار است.
- **تست با حساب واقعی کاربر یا سایت Vercel انجام نشده**؛ تست‌های syntax، mock Gemini و آپارات، پردازش FFmpeg و API سرویس محلی پاس شده‌اند. راه‌اندازی واقعی پس از Deploy و اجرای Worker باید آزموده شود.
