# RushFinder 0955 — حذف ابزارهای برش خودکار قدیمی

**بر پایه صفحه تدوین 0954 Hermes**؛ فقط سه فایل صفحه وب تغییر کرده‌اند.

## حذف‌شده از صفحه تدوین
- بخش «✂ برش خودکار YouTube بر اساس نریشن» و تمام گزینه‌های آن، شامل یوتیوب، آپارات، ویتیزی، پیش‌نمایش برش و تأیید مجوز.
- دکمه آبی «تدوین خودکار واقعی · جست‌وجو، کات و تایم‌لاین»، متن Gemini/FFmpeg، گزارش و نوار پیشرفت مرتبط.
- گزینه جست‌وجوی خودکار ویدئو و منوی پنهان قدیمی جست‌وجو.
- ردیف قدیمی «کات YouTube» و دکمه نمایشش در تایم‌لاین.
- بارگیری دو اسکریپت قدیمی `smart-youtube.js` و `smart-autocut.js` از صفحه تدوین.

## باقی‌مانده
- فرم ارسال متن و نریشن به Hermes و پیگیری سفارش.
- ساخت موشن‌گرافیک با Groq/Claude در «ابزارهای بیشتر».
- ابزارهای فایل، صدا، تیتر، برش دستی، ترنزیشن، تایم‌لاین و Export.

## نحوه انتشار
1. ZIP را در همان پوشهٔ **Git موجود RushFinder** استخراج و فایل‌های هم‌نام را جایگزین کنید.
2. فایل `PUBLISH-0955-CLEAN-EDITOR.cmd` را اجرا کنید.
3. وضعیت Vercel را بررسی کرده، سپس `Ctrl+F5` بزنید.

**هیچ تنظیم API یا Hermes عوض نشده است.** اتصال واقعی Hermes به سیستم همکار نیازمند تنظیم Bridge است.

### نکته فنی
برای حفظ سازگاری اسکریپت اصلی صفحه، چند عنصر غیرفعال و مخفی (بدون منو و بدون قابلیت استفاده) حفظ شده‌اند. اسکریپت‌های برش خودکار YouTube دیگر در این صفحه بارگذاری نمی‌شوند.
