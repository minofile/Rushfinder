# RushFinder 0968 — اصلاح پاسخ تصویر AvalAI

این اصلاحیه مشکل «HTTP 200 ولی base64 دریافت نشد» را بررسی می‌کند و فرمت‌های مستند پاسخ تصویر را پشتیبانی می‌کند:

- `data[0].b64_json` و برخی فیلدهای Base64 رایج
- `data[0].url` به شکل data URL یا لینک HTTPS فایل تصویر
- دانلود امن لینک تصویرِ میزبان‌های شناخته‌شده توسط سرور و ارسال به سایت، در صورت حجم مناسب
- نمایش پیام تشخیصی شامل نام فیلدهای پاسخ (بدون نمایش کلید API، متن پرامپت یا محتوای تصویر) اگر پاسخ همچنان فاقد تصویر باشد
- جلوگیری از ارسال خودکار درخواست پولی تکراری

**مهم:** این اصلاحیه نمی‌تواند تصویر قبلی را پس بگیرد. اگر قبل از نصب خطای «base64 دریافت نشد» دیده‌اید، پیش از ایجاد تصویر جدید، سوابق مصرف در حساب AvalAI را بررسی کنید. درخواست قبلی ممکن است هزینه داشته باشد. قفل آن درخواست در مرورگر باقی می‌ماند؛ آن را کورکورانه پاک نکنید.

## نصب

1. ZIP را کنار فایل `infographic.html` در پوشه Git RushFinder استخراج کنید و جایگزینی دو فایل اصلاح‌شده را تأیید کنید.
2. `PUBLISH-0968-AVALAI-IMAGE-FIX.cmd` را اجرا کنید.
3. منتظر **Ready** شدن Vercel بمانید و صفحه اینفو را با `Ctrl+F5` باز کنید.
4. **بدون ساخت تصویر جدید**، ابتدا در AvalAI گزارش مصرف و نتیجه درخواست قبلی را بررسی کنید. اگر مبلغ کسر شده یا در وضعیت نامشخص مانده، شناسه درخواست/زمان آن را به پشتیبانی AvalAI بدهید.
5. فقط پس از تعیین وضعیت درخواست قبلی، در صورت تمایل یک تصویر تازه با تغییر متن و تأیید هزینه بسازید.

متغیرهای Vercel همان `AVALAI_API_KEY` و `RF_INFO_ACCESS_CODE` هستند؛ API جدید یا خرید جدید لازم نیست. قسمت تدوین، Hermes و تایم‌لاین تغییر نکرده‌اند.

محدودیت: اگر AvalAI پاسخ را به صورت لینک موقت بدهد و سرور میزبان آن اجازه دریافت CORS ندهد، عکس شاید در بوم قابل استفاده نباشد؛ پیام مشخص نمایش داده خواهد شد و ساخت تصویر به‌صورت خودکار تکرار نمی‌شود. تصویر Base64 بسیار بزرگ هم ممکن است از سقف پاسخ Vercel فراتر برود.

اگر سرویس URL مستقیم تصویر برگرداند ولی اجازه CORS ندهد، لینک **«بازکردن تصویر برگشتی AvalAI»** در همان صفحه ظاهر می‌شود تا بتوانید آن را بدون درخواست پولی جدید باز کنید.
