راهنمای RushFinder نسخه 0802 — نسخه سبک و مرتب

۱) کل ZIP را در یک پوشه جدید استخراج کنید. فایل‌ها را روی پروژه قدیمی بازنویسی نکنید تا خروجی‌های قبلی حفظ شوند.
۲) برای اجرای موتور، روی Start-RushFinder.cmd دوبار کلیک کنید. Node.js، After Effects و FFmpeg برای رندر واقعی لازم‌اند.
۳) صفحه اصلی index.html در آدرس زیر باز می‌شود:
   http://127.0.0.1:18815/index.html?v=0802
۴) از منوی همان صفحه روی «تگ خبر» کلیک کنید. پس از رندر موفق، فایل MP4 جدید در پوشه زیر ذخیره می‌شود:
   %USERPROFILE%\RushFinder-Exports
   (در نوار آدرس File Explorer، همین مسیر را وارد کنید.)
۵) پوشه فایل‌های موقت جدید این است:
   %USERPROFILE%\RushFinder-Cache\ae-jobs
   بعد از رندر موفق، فایل‌های موقت همان کار پاک می‌شوند؛ در صورت خطا برای عیب‌یابی باقی می‌مانند.

برای انتقال MP4های قدیمی از پوشه ae-jobs داخل پروژه قدیمی:
- فایل Move-Old-RushFinder-Outputs.cmd را از پوشه همان پروژه اجرا کنید. فقط فایل‌های MP4 نهایی که نامشان شناسهٔ رندر است منتقل می‌شوند؛ هیچ فایل تکراری بازنویسی نمی‌شود.
- فیلم‌ها را در RushFinder-Exports بررسی کنید.
- اگر خواستید فایل‌های موقت پردازش‌های تکمیل‌شده را حذف کنید، Clean-Completed-Render-Temp.cmd را اجرا و هنگام درخواست، DELETE تایپ کنید. فقط پوشه‌هایی که MP4 نهایی متناظرشان وجود داشته باشد، برای پاک شدن انتخاب می‌شوند.
- فایل‌های موقتِ رندر ناموفق به صورت خودکار حذف نمی‌شوند.

GitHub / Vercel:
- مسیر ae-jobs و فایل‌های موقت در .gitignore قرار گرفته‌اند. برای فایل‌های قبلاً ثبت‌شده، در ترمینال پوشه پروژه اجرا کنید:
  git rm -r --cached --ignore-unmatch ae-jobs
- این دستور فایل‌های محلی را حذف نمی‌کند. .git را پاک نکنید.
- فایل‌های بزرگ که از قبل در تاریخچه Git ثبت شده‌اند ممکن است نیاز به پاک‌سازی جداگانه تاریخچه داشته باشند.
- تغییرات سایت آنلاین تا زمان Deploy نسخه جدید دیده نمی‌شود. Vercel خودش After Effects را اجرا نمی‌کند؛ موتور ویندوز باید روی همان رایانه روشن باشد.

حذف‌های نسخه جدید: ۱۲ تصویر قدیمی و بلااستفاده assets/music-v0135 (حدود ۳۳ مگابایت)، فایل تکراری ae-render.html و راهنماهای قدیمی. تصاویر فعال music-v0136، فونت‌ها، FFmpeg و قالب AEP حفظ شدند.

تست اجرای صفحه اصلی و API موتور در محیط آزمایشی انجام شده؛ ساخت MP4 با After Effects روی ویندوز همچنان نیازمند آزمایش است.
