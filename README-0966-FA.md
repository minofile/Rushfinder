# RushFinder 0966 — اتصال مستقیم اینفوگرافیک به API رسمی OpenAI

این اصلاحیه به‌جای واسط گیسو و چابکان، برای ساخت تصویر **فقط از OpenAI** استفاده می‌کند. بخش تدوین و Hermes تغییر نمی‌کند. مسیر سرور همان `api/avalai-image.js` است؛ تابع جدید Vercel اضافه نمی‌شود.

## نصب
1. فایل ZIP را در ریشهٔ پوشه Git پروژه RushFinder استخراج کنید؛ ساختار پوشه `api` را حفظ کنید.
2. فایل `PUBLISH-0966-OPENAI-IMAGE.cmd` را اجرا کنید.
3. در Vercel → پروژه RushFinder → Settings → Environment Variables این مقادیر را در **Production** ثبت کنید:
   - `OPENAI_API_KEY` = کلید رسمی OpenAI Platform (نه کلید گیسو)
   - `RF_INFO_ACCESS_CODE` = رمز جداگانه و دلخواه برای مدیر (همان رمز قبلی را می‌توانید حفظ کنید)
4. Save و بعد Redeploy کنید. منتظر **Ready** باشید و صفحه اینفوگرافیک را با `Ctrl+F5` تازه‌سازی کنید.
5. رمز دسترسی مدیر را در بخش اینفو وارد کنید، «بررسی اتصال OpenAI» بزنید (این تست تصویر پولی نمی‌سازد)، سپس با **GPT Image 2.5 Flare / Low** یک تصویر کوچک آزمایشی بسازید.

## مدل‌های قابل انتخاب
- `gpt-image-2.5-flare` (پیش‌فرض برای تست)
- `gpt-image-2.5-sunburst`
- `gpt-image-2.6-flare`
- `gpt-image-2.6-sunburst`

دسترسی به هر مدل به حساب API OpenAI بستگی دارد. موفقیت «بررسی اتصال» مجوز ساخت تصویر را تضمین نمی‌کند. مدل و کیفیت در تأییدیه قبل از درخواست پولی مشخص می‌شود.

## امنیت و محدودیت‌ها
- کلید API **فقط روی Vercel** ذخیره می‌شود، نه در مرورگر، GitHub یا فایل HTML.
- `GISOO_API_KEY` و `GISOO_BASE_URL` دیگر برای **این مسیر اینفو** استفاده نمی‌شوند؛ لازم نیست فعلاً آن‌ها را از Vercel پاک کنید اگر بخش دیگری به آن‌ها نیاز دارد.
- در صورت timeout یا خطای نامشخص، ممکن است تصویر ساخته و هزینه کسر شده باشد: قبل از تلاش مجدد مصرف API را بررسی کنید. سیستم برای یک درخواست مبهم قفل تکرار دارد.
- مدل تصویری متن و آمار را ممکن است اشتباه بنویسد. حتماً خروجی را بررسی کنید.
- این اصلاحیه با کلید خصوصی واقعی کاربر تست نشده؛ ساخت تصویر واقعی بعد از Redeploy باید با یک درخواست کم‌هزینه امتحان شود.
