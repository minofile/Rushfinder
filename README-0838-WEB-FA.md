# RushFinder 0838 — نسخه وب با کم‌حجم‌کننده داخل مرورگر

این بسته از نسخه 0837 تهیه شده و **برای انتشار آنلاین در Vercel** آماده شده است.
بخش «کم‌حجم‌کننده» زیر «برش ویدیو» در منوی سمت راست قابل استفاده است.

## نکات مهم حریم خصوصی و کیفیت

- ویدئوهای انتخاب‌شده با `File`/`ArrayBuffer` فقط در مرورگر کاربر و حافظه موقت FFmpeg WebAssembly پردازش می‌شوند.
- درخواست POST یا آپلود ویدئو به Vercel یا سایر سرورها در کد کم‌حجم‌کننده وجود ندارد.
- **فایل‌های موتور FFmpeg** (`assets/ffmpeg/ffmpeg.js` و فایل‌های JS/WASM آن) روی Vercel قرار می‌گیرند و مرورگر برای پردازش دانلودشان می‌کند؛ این کاملاً متفاوت از آپلود ویدئو است.
- اگر فایل اصلی **از حجم هدف کوچک‌تر** باشد، مستقیماً و بدون بازکدگذاری دانلود می‌شود.
- حالت «کیفیت بسیار بالا» با CRF 17 و بدون تغییر رزولوشن/فریم‌ریت کار می‌کند؛ افت جزئی احتمالی است.
- حالت «کاملاً بدون افت کیفیت» جریان‌های صدا و تصویر را بدون بازکدگذاری کپی می‌کند؛ ممکن است حجم کمتر نشود.
- امکان تضمین حجم ۳۰ مگابایت **هم‌زمان** با حفظ کامل کیفیت وجود ندارد.
- پردازش ویدئوهای خیلی بزرگ ممکن است به‌دلیل محدودیت RAM یا مرورگر با خطا مواجه شود (محدودیت ۵۱۲ MiB).

## روش انتشار در Vercel

1. ابتدا از مخزن/پروژه فعلی نسخه پشتیبان بگیرید. فایل‌های این ZIP را در ریشه پروژه وب جایگزین کنید.
2. `index.html`، `video-compress.html`، `.vercelignore`، `.gitignore` و پوشه `assets/ffmpeg/` را حتماً در Git ثبت کنید. اگر از Vercel CLI استفاده می‌کنید، فایل‌ها در ریشه پروژه موجود باشند.
3. در Vercel همان پروژه را **Redeploy** کنید یا تغییرات را به شاخه‌ای که به Vercel متصل است push کنید. این بسته به‌تنهایی آپلود/منتشر نشده است.
4. پس از انتشار آدرس `https://YOUR-DOMAIN/index.html?v=0838#video-compress` را باز کنید.
5. اگر منو نمایش داده نشد با Ctrl+F5 بارگذاری مجدد کنید و بررسی کنید `https://YOUR-DOMAIN/video-compress.html` و `https://YOUR-DOMAIN/assets/ffmpeg/ffmpeg-core.wasm` بدون خطای 404 در دسترس‌اند.

### نکته درباره محلی و آنلاین
فایل‌های `Start-RushFinder.*` در بسته جهت سازگاری حفظ شده‌اند؛ برای نسخه آنلاین نیازی به اجرای آنها نیست. قابلیت‌های محلی After Effects و آرشیو LAN ممکن است همچنان به خدمات محلی خودشان نیاز داشته باشند؛ کم‌حجم‌کننده مستقل است.

این نسخه فقط فایل‌های پروژه را آماده کرده است؛ انتشار واقعی نیازمند دسترسی شما به پروژه Vercel یا GitHub است.
