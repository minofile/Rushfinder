# RushFinder 0799 - Windows launcher fix

1. Extract the entire ZIP to a NEW folder (do not run files from inside ZIP).
2. Double-click Start-RushFinder.cmd (recommended), or RushFinder.vbs.
3. The launcher opens http://127.0.0.1:18813/index.html?v=0799
4. Node.js LTS must be installed and available on PATH.
5. After Effects and FFmpeg are required to RENDER a news tag, not just to open the site.
6. If port 18813 is in use by a previous RushFinder copy, close its local engine first.

If Windows Script Host shows "Invalid character" (800A0408), run Start-RushFinder.cmd directly.
This package retains the original index.html and all rendering assets and functionality.
The hosted public website cannot itself run Windows After Effects; the local engine must be running for MP4 rendering.
