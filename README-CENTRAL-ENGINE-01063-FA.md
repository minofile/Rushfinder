# RushFinder 01063 — موتور مرکزی تگ خبر، بدون نصب برای کاربران

## معماری
- `Start-RushFinder.cmd`: موتور اصلی فقط روی کامپیوتر مدیر، پورت 18827 (localhost).
- `Start-Central-Gateway.cmd`: درگاه امن فقط روی localhost:18828؛ کلید HMAC و مسیرهای محدود.
- `cloudflared`: فقط به پورت 18828 تونل می‌زند، **نه 18827**.
- `rushfinder.vercel.app`: مجوز کوتاه‌مدت را از `/api/news-tag-session` می‌گیرد؛ فایل ویدیو را **در قطعه‌های ۱۶ مگابایتی مستقیماً از مرورگر به درگاه** آپلود می‌کند. بنابراین از محدودیت حجم Vercel عبور می‌کند.
- کاربران باید **کد دسترسی بخش تگ** را از مدیر بگیرند. نیازی به نصب ندارند.

## نصب برای مدیر (به ترتیب)
1. پوشه کامل ZIP را روی کامپیوتر اصلی استخراج و نسخه قبلی را با حفظ پشتیبان جایگزین کنید.
2. `Setup-Central-Engine.cmd` را اجرا کنید. یک کلید تصادفی بلند فقط روی سیستم تولید می‌شود. آن را در چت/گیت‌هاب نفرستید.
3. متغیرهای محیطی پروژه Vercel را در Settings > Environment Variables بسازید:
   - `RF_TAG_SIGNING_KEY` = همان کلید خروجی مرحله 2
   - `RF_TAG_ACCESS_CODE` = کد محرمانه قوی ۱۲ کاراکتر یا بیشتر که فقط به کاربران مجاز می‌دهید
   - `RF_TAG_GATEWAY_URL` = آدرس HTTPS تونل Cloudflare پس از روشن‌شدن (بدون / انتهایی)
4. برای دفعات اول `Start-RushFinder.cmd`، سپس `Start-Central-Gateway.cmd` و `Start-Cloudflare-Tunnel.cmd` را به‌ترتیب اجرا کنید؛ پس از نصب cloudflared، فایل `Start-Central-RushFinder.cmd` هر سه را با یک کلیک باز می‌کند.
5. `cloudflared` را از سایت رسمی Cloudflare نصب و در PATH قرار دهید: https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/
6. `Start-Cloudflare-Tunnel.cmd` را اجرا کنید تا `https://...trycloudflare.com` ساخته شود. آن آدرس را در `RF_TAG_GATEWAY_URL` قرار دهید و **Redeploy** کنید.
7. سایت `https://rushfinder.vercel.app` را باز کنید؛ بخش تگ خبر برای اولین ورود کد دسترسی می‌خواهد.

## نکات مهم
- **Cloudflare Quick Tunnel آزمایشی است و URL آن با هر اجرا ممکن است تغییر کند.** پس برای تولید دائمی یا آدرس ثابت، یک تونل مدیریت‌شده با دامنهٔ تحت کنترل Cloudflare یا راهکار دارای hostname پایدار لازم است. لازم نیست دامنهٔ وب‌سایت فعلی را تغییر دهید.
- اگر تونل یا کامپیوتر خاموش شود، تگ جدید پردازش نمی‌شود.
- کد دسترسی را عمومی نکنید. برای انتشار بزرگ، سامانه ورود کاربران/محدودیت نرخ و ذخیره‌سازی فایل حرفه‌ای نیاز است. این نسخه برای کاربران مجاز و آزمایش مرکزی است.
- ویدیوها روی کامپیوتر مدیر پردازش می‌شوند و خروجی تا پایان کار همان‌جا باقی می‌ماند. حافظه مرورگر و لینک‌های خروجی را ماندگار فرض نکنید.
- تست Node gateway و endpoint با API شبیه‌سازی شده انجام می‌شود؛ کارکرد واقعی تونل و After Effects را باید روی ویندوزتان آزمایش کنید.
- برای دیباگ: `http://127.0.0.1:18827/ae-api/check` و `http://127.0.0.1:18828/ae-api/check` (دومی بدون توکن باید 401 بدهد).
- **موتور پورت 18827 را به اینترنت مستقیم متصل نکنید.**

- آپلود قطعه‌ای برای محدودیت حجم درخواست‌های Cloudflare تعبیه شد؛ سقف هر فایل ۱ گیگابایت است (محدودیت حجم/پهنای باند حساب Cloudflare و کیفیت ارتباط همچنان اعمال می‌شود).
