# RushFinder 0941 — رفع خطای قطعی «پاسخ غیر JSON» در تدوین هوشمند

## ایراد
در `api/youtube-music.js` و `api/chat.js` فایل‌های کمکی `../lib/ai-failover.mjs` و `../lib/vecteezy.mjs` به‌صورت مستقیم import می‌شدند. در برخی استقرارهای Vercel این فایل‌ها همراه تابع اجرایی گنجانده نشده و تابع هنگام شروع خطای `Cannot find module` می‌دهد. پاسخ پیش‌فرض Vercel غیر JSON است و سایت پیام `پاسخ غیر JSON از api/youtube-music?mode=smartedit-config` نمایش می‌دهد. وجود فایل در Source یا وضعیت Ready به تنهایی رفع این مشکل را تضمین نمی‌کند.

## تغییر فنی
منطق AI failover و Vecteezy مستقیماً به خود فایل‌های `api/youtube-music.js` و `api/chat.js` منتقل و محصور شد؛ تابع‌ها دیگر به مسیرهای کمکی `lib/` وابسته نیستند. مسیرها، پارامترها، نام متغیرهای محیطی و ترتیب OpenAI → Claude → Gemini تغییر نکرده است. فایل‌های اصلی در `lib/` فقط جهت نگهداری باقی مانده‌اند.

## نصب آسان
1. **از پوشه GitHub پروژه پشتیبان بگیر.**
2. همه محتویات ZIP کامل را داخل همان پوشه اصلی پروژه Rushfinder استخراج و فایل‌های تکراری را جایگزین کن. (ZIP کوچک برای دارندگان نسخه 0939/0940 کافی است.)
3. یک بار `PUBLISH-0941-GITHUB.cmd` را اجرا کن. این دستور فقط فایل‌های مشخص این اصلاحیه را stage و commit کرده و به GitHub push می‌کند؛ در صورت خطا قبل از push متوقف می‌شود.
4. در Vercel، **Production / Ready** و commit حاوی «0941: self-contained API fixes» را تأیید کن. سپس سایت را با Ctrl+F5 باز کن.
5. با یک متن کوتاه تست کن. در صورت خطا، از Vercel Runtime Logs **جدیدترین خطا** را بررسی کن.

## تست بدون دخالت API واقعی
`node tests/test-0941-api-self-contained.mjs`

این تست تابع `/api/youtube-music` و `/api/chat` را **بدون پوشه `lib/`** در یک محیط موقت بارگذاری کرده و دریافت JSON را تست می‌کند؛ بنابراین وابستگی حذف‌شده را به‌صورت عملی چک می‌کند.

## نکته
این اصلاحیه فقط مشکل آغاز به کار API و بسته‌بندی را هدف می‌گیرد. سلامت APIها، اعتبار و سهمیه واقعی، دسترسی قانونی به فایل‌های ویدیو، ارتباط مرورگر با Media Worker و موفقیت تدوین نهایی باید جداگانه روی سایت بررسی شوند. کلیدها را در چت یا GitHub قرار نده.
