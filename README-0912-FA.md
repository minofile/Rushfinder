# RushFinder SmartEdit 0912 — نریشن و متن

این نسخه فقط صفحه تدوین هوشمند را اصلاح می‌کند؛ منوی سایت و سایر بخش‌ها حفظ شده‌اند.

## روند استفاده
۱. نریشن MP3/WAV/M4A را در بخش «نریشن + متن» وارد کن.
۲. متن دقیق همین نریشن را وارد کن.
۳. در سایت منتشرشده یا سرور محلی روی «ساخت تدوین هماهنگ با نریشن» بزن.
۴. برنامه راش محلیِ انتخاب‌شده و آرشیو مجاز Wikimedia Commons را جست‌وجو می‌کند؛ وقتی فایل قابل دریافت پیدا شود وارد کتابخانه و تایم‌لاین می‌کند.
۵. طول کلیپ‌ها براساس طول نریشن تقسیم می‌شود، موسیقی و ترنزیشن اضافه می‌شود؛ متن خبر روی تصویر نمایش داده نمی‌شود.

### محدودیت‌های واقعی
- تطبیق زمان هر جمله با نریشن در این نسخه «تخمینی» است، نه تشخیص گفتار و زمان‌بندی کلمه‌به‌کلمه.
- برای جست‌وجوی آنلاین باید از آدرس HTTP (سایت Vercel یا سرور محلی تست) استفاده شود، نه بازکردن مستقیم `file://`.
- ممکن است جست‌وجو راش مناسبی پیدا نکند یا دانلود با خطای CORS، شبکه یا محدودیت حجم متوقف شود. هیچ فیلم ساختگی به جای خبر قرار نمی‌گیرد.
- دانلود خودکار YouTube، Aparat یا YTUltra هنوز موجود نیست. راش اینترنتی فقط از آرشیوهای دارای مجوز و API قابل دسترس دریافت می‌شود.
- فایل نریشن/موسیقی شخصی به سرور Vercel آپلود نمی‌شود؛ فقط عبارات جست‌وجو به API ارسال می‌شود. بخشی از انتقال عمومی Wikimedia ممکن است موقتاً از سرور عبور کند.
- خروجی واقعی مرورگر بستگی به پشتیبانی MediaRecorder دارد و لزوماً MP4 نیست.

قبل از انتشار، منابع و مجوز کلیپ‌ها، تطبیق تصاویر با خبر و زمان‌بندی را بازبینی کن.
