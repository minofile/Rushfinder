# RushFinder 01013 – رفع خطای نمایش تصویر

خطای `rf01012UrgentTheme is not defined` به دلیل جدا بودن محدوده تعریف توابع JavaScript بود.

## تغییرات
- استفاده از تابع واحد `window.rfUrgentTheme` برای انتخاب تم در ساخت پرامپت و نمایش Canvas
- حذف تابع قدیمی با تشخیص اشتباه نمودار دایره‌ای
- حفظ بقیه قالب‌ها و مسیر AvalAI بدون تغییر
- هیچ درخواست پولی انجام نشده است

## نصب
فایل `infographic-RushFinder-01013-FIX.html` را در مخزن خود با نام `infographic.html` جایگزین کنید و Deploy کنید.

## هشدار بازیابی
تصویری که قبلاً دریافت شده ممکن است فقط در حافظه صفحه وجود داشته باشد. قبل از refresh یا بستن تب، در صورت امکان PNG یا آدرس تصویر را ذخیره کنید. تغییر HTML به تنهایی تصویر از دست رفته را برنمی‌گرداند.

- افزودن تشخیص موضوع دریاچه، تالاب و تغییر حجم آب به تم موضوعی؛ نه نمودار دایره‌ای
