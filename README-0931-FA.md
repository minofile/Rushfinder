# RushFinder 0931 — Track Visibility & Clean YouTube Preview

## این اصلاحیه چه می‌کند؟
- چشم کنار **متن‌ها**: نمایش/پنهان کردن متن روی تصویر در پیش‌نمایش و خروجی فایل واقعی.
- چشم کنار **ویدئو / راش**: نمایش/پنهان کردن تصویر کلیپ‌های محلی، بدون حذف یا تغییر زمان‌بندی.
- چشم کنار **کات YouTube**: نمایش/پنهان کردن پیش‌نمایش یوتیوب با حفظ کات‌ها و پخش نریشن.
- بلندگو کنار **موسیقی** و **نریشن**: قطع/وصل صدای همان لایه؛ زمان تایم‌لاین ثابت می‌ماند.
- کنترل‌های معمول یوتیوب با `controls=0` کمتر نمایش داده می‌شوند؛ اگر مرورگر پخش خودکار را مسدود کند، کنترل رسمی یوتیوب دوباره فعال می‌شود تا پخش دستی ممکن باشد؛ **عنوان، برند و اعلان‌های رسمی YouTube ممکن است همچنان نمایش داده شوند و نمی‌توان تضمین کرد حذف می‌شوند**.
- در JSON پروژه وضعیت لایه‌ها نیز ثبت می‌شود؛ ابزار موجود در نسخه فعلی هنوز بازیابی کامل پروژه از JSON ندارد.

## نصب
فایل‌های `smart-edit.html`، `smart-edit.js` و `smart-youtube.js` را در ریشه GitHub جایگزین کنید. تنظیمات Vercel و API را تغییر ندهید؛ تابع سروری جدیدی اضافه نشده است.

## محدودیت مهم
کات‌های یوتیوب صرفاً پیش‌نمایش قابل پخش هستند؛ دانلود خودکار و ورود به MP4 انجام نمی‌شود. خاموش کردن چشم فقط دیدن لایه را کنترل می‌کند، فایل‌ها را پاک نمی‌کند.
