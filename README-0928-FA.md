# RushFinder 0928 — فقط YouTube در تدوین هوشمند

- دکمه اصلی «فقط YouTube · پیدا کردن و چیدن کات‌ها» اکنون تنها به `/api/youtube-music?mode=smartedit` وصل است.
- مسیر جست‌وجوی خودکار Wikimedia Commons، Pexels و Pixabay از UI تدوین غیرفعال و پنهان شده است. هیچ‌کدام به‌عنوان جایگزین یوتیوب استفاده نمی‌شوند.
- در پنجره شروع پروژه نیز دکمه تدوین فقط همین مسیر یوتیوب را اجرا می‌کند.
- اگر کات‌های ویدیویی قبلی از منبع دیگر در پروژه باشند، پیش از پاک‌شدن آنها از تایم‌لاین **تأیید کاربر** گرفته می‌شود؛ نریشن و موسیقی حفظ می‌شوند.
- نتیجه‌های یوتیوب به شکل برش‌های مجازی با زمان شروع/پایان روی نوار اصلی ویدئو به‌صورت پیش‌نمایش قرار می‌گیرند. زمان‌های انتخاب‌شده از متن و اطلاعات ویدئو تخمین زده شده‌اند، نه تحلیل واقعی صحنه.
- YouTube Data API قابلیت دانلود محتوای ویدئو را ندارد. برای تدوین/MP4 واقعی با فایل یوتیوب، دریافت مجوز و دسترسی به فایل اصلی از صاحب اثر ضروری است؛ این نسخه چنین دانلودی انجام نمی‌دهد.
- تنظیم API قبلی دست نخورده می‌ماند؛ تدوین از `YOUTUBE_SMARTEDIT_API_KEY` در تابع موجود `api/youtube-music.js` استفاده می‌کند. فایل API تغییر نکرده و تعداد توابع Vercel افزایش نیافته است.

## نصب
فایل‌های `smart-edit.html`، `smart-edit.js` و `smart-youtube.js` را در ریشه پروژه GitHub جایگزین کن. بعد Commit و آماده‌شدن Vercel، Ctrl+F5 بزن.
