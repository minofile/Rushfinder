# RushFinder 0940 — رفع خطای نبودن ماژول AI

## علت
در فایل `PUBLISH-0939-GITHUB.cmd` نسخه قبلی، `lib/ai-failover.mjs` برای Git ثبت نمی‌شد. اما فایل‌های `api/youtube-music.js` و `api/chat.js` آن را import می‌کنند. به همین دلیل پس از انتشار، Vercel خطای `Cannot find module ../lib/ai-failover.mjs` می‌دهد و API به جای JSON خطا برمی‌گرداند.

## نصب
1. از پروژه پشتیبان بگیرید.
2. محتویات همین ZIP را **داخل پوشه اصلی پروژه GitHub Rushfinder** (کنار `smart-edit.html`، `api` و `lib`) استخراج و فایل‌های تکراری را جایگزین کنید. پوشه اضافی در مسیر نسازید.
3. `PUBLISH-0940-FIX-GITHUB.cmd` را اجرا کنید؛ اگر Git اجازه خواست وارد شوید.
4. در GitHub مطمئن شوید `lib/ai-failover.mjs` موجود است و در Vercel انتشار Production به وضعیت Ready رسیده است.
5. سایت را با `Ctrl+F5` باز کنید و دوباره کات خودکار را آزمایش کنید.

## حدود این اصلاحیه
این بسته فقط خطای ناپدیدشدن فایل ماژول و مشکل import سمت سرور را هدف قرار می‌دهد؛ رفع این خطا **تضمین نمی‌کند** که دریافت ویدیو، سهمیه API، تحلیل Gemini یا برش FFmpeg هم بدون مشکل کار کند. اگر باز هم شکست خورد، خطای جدید را از Runtime Logs ببینید. کلید API را داخل چت یا GitHub نگذارید.

هشدارهای `url.parse()` در `appwrite-music` خطای اصلی اسکرین‌شات نیستند.
