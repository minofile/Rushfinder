# RushFinder 01008 — سه تم ثابت خبر فوری

## تغییرات
- سه چیدمان خودکار برای برند «خبر فوری»: اقتصادی/لیستی، موضوعی/هواشناسی، سهم از کل.
- تم سهم از کل فقط زمانی انتخاب می‌شود که همه آیتم‌ها درصد غیرمنفی باشند و جمع آن‌ها حدود ۱۰۰٪ باشد؛ نمودار دایره‌ای برای درصدهای مستقل ساخته نمی‌شود.
- رنگ‌های ثابت: کرم روشن، سفید، سبز زمردی و مشکی.
- لوگوی اصلی فقط از قالب PNG پروژه در لایه آخر رسم می‌شود.
- تیتر از متن کاربر و با فونت انتخاب‌شده وسط‌چین و پایین لوگو رسم می‌شود.
- متن کارت‌ها و مقادیر از متن ورودی رسم می‌شوند. هیچ هندل @AkhbareFori به خروجی افزوده نمی‌شود.
- خروجی عکس پولی AvalAI صرفاً برای تصویرسازی بدون نوشته استفاده می‌شود.

## نصب
فایل infographic.html را در ریشه پروژه فعلی جایگزین و در Vercel منتشر کنید؛ فایل‌های assets/infographic-templates باید همراه پروژه باقی بمانند.

## وضعیت آزمون
کدهای inline JavaScript از نظر Syntax با node --check بررسی شده‌اند. نمایش واقعی در مرورگر، کیفیت تصویرسازی مدل و آپلود در Vercel هنوز تست نشده‌اند. برای آزمون اولیه تا جای ممکن از پیش‌نمایش‌های بدون درخواست پولی استفاده کنید.
