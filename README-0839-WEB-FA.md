# RushFinder 0839 — اصلاح خطاهای کم‌حجم‌سازی روی Vercel

## چه چیزی اصلاح شد؟
- فیلم‌های بزرگ به جای کپی کامل به حافظه WASM، با `WORKERFS` و از خود File API مرورگر خوانده می‌شوند. این روش مصرف حافظه برای ورودی‌های حجیم را کاهش می‌دهد؛ اما همه خطاهای حافظه و کدک را تضمینی حل نمی‌کند.
- اگر دسترسی WORKERFS ناموفق بود، تنها برای فیلم‌های کوچکتر از ۹۶ MiB از مسیر قبلی استفاده می‌شود.
- در صورت خطا، «جزئیات خطا» و دکمه کپی در همان صفحه نمایش داده می‌شود تا علت دقیق مشخص باشد.
- اگر فیلم از حجم انتخاب‌شده کوچک‌تر **یا مساوی** باشد، همان فایل بدون بازکدگذاری تحویل داده می‌شود.
- نسخه وب همچنان ویدئو را به سرور نمی‌فرستد. درخواست‌های HTTP فقط برای دریافت فایل‌های JS/WASM هستند.
- به‌دلیل حفاظت از کیفیت، رسیدن به دقیقاً ۳۰ MB تضمین‌شده نیست.

## انتشار
۱. از پروژه نسخه پشتیبان بگیرید.
۲. محتوای ZIP را در ریشه همان مخزنی که Vercel از آن منتشر می‌کند جایگزین کنید.
۳. `index.html` و `video-compress.html` و پوشه `assets/ffmpeg` را commit و push کنید.
۴. آدرس `https://YOUR-DOMAIN/index.html?v=0839#video-compress` را پس از انتشار باز کنید و `Ctrl+F5` بزنید.
۵. روی ویدئو تست کنید. اگر خطا داد، «جزئیات خطا» را باز و متن یا عکس آن را بفرستید.

**این ZIP روی Vercel منتشر نشده است** و تست عملکرد در مرورگر واقعی کاربر نیاز دارد. استفاده از ۲۵۶ MB حافظه همچنان به توان دستگاه بستگی دارد.
