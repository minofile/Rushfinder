# RushFinder Web 01006 — رفع خطای نمایش تصویر و لوگو

## رفع باگ
تابع `rf724PaintLogoSafeZone` در اسکریپت بستهٔ دیگری قرار داشت، بنابراین تابع ترکیب تصویر `rf702DrawFinal` به آن دسترسی نداشت و پس از دریافت تصویر هزینه‌دار AvalAI با `ReferenceError` متوقف می‌شد.
در این نسخه تابع حفاظت از محدوده لوگو با نام `rf702PaintLogoSafeZone` در همان اسکریپت موتور Canvas تعریف و فراخوانی شده است. قالب‌های PNG اصلی برندها بدون تغییر باقی می‌مانند.

## نصب
تمام فایل‌های ZIP را در مخزن پروژه جایگزین/همگام کن و روی Vercel منتشر کن. اگر فقط نسخهٔ 01005 را قبلاً نصب کرده‌ای، جایگزینی `infographic.html` کافی است؛ فایل‌های `assets/infographic-templates/` باید در deploy وجود داشته باشند.

## جلوگیری از هزینه دوباره
رفع این مشکل هیچ تماس جدیدی با AvalAI ایجاد نمی‌کند. **برای بررسی رفع باگ دوباره روی دکمهٔ ساخت تصویر پولی نزن.** نخست صفحهٔ منتشرشده را باز کن و فایل‌های قالب را چک کن؛ اگر تصویر قبلی را ذخیره کرده‌ای از همان استفاده کن. اگر صفحه را تازه‌سازی کرده باشی و تصویر فقط در حافظه تب بوده باشد، خودکار برنمی‌گردد.

## تست
کدهای JavaScript داخل infographic.html با `node --check` بررسی شدند. تست واقعی AvalAI یا انتشار زنده انجام نشده است.
