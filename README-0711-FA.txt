RushFinder WEB 0711 — انتشار با قالب‌های اصلی

نسخه کامل، بر مبنای نسخه 0710.
هر شش فایل قالب اصلی خبر فوری / اخبار مشهد / جریان، مربع / استوری، بدون تغییر بایت‌به‌بایت حفظ شده است.

- تصویر هوش مصنوعی در فضای محتوایی محدود می‌شود و قالب اصلی روی آن رسم می‌شود.
- تیتر از بخش بالای راست و لوگو فاصله دارد.
- سرویس Gemini چابکان از API سمت سرور استفاده می‌کند، کلید را در GitHub نگذارید.
- تنها برای تست تولید تصویر، متغیرهای CHABOKAN_API_KEY و CHABOKAN_IMAGE_URL و CHABOKAN_IMAGE_MODEL لازم‌اند.
- مقدار CHABOKAN_IMAGE_URL: https://ai.chabokan.net/v1/chat/completions
- مقدار CHABOKAN_IMAGE_MODEL: google/gemini-3.1-flash-lite-image

قبل از انتشار در main، ZIP پروژه جاری را روی کامپیوتر نگه دارید. ابتدا یک استقرار Preview را تست کنید و سپس فقط در صورت رضایت به main منتقل کنید.
سرورهای آرشیو داخلی شرکت و اتصال بیرونی آرشیو همچنان یک موضوع جداگانه‌اند.
ساخت این بسته به معنی اثبات موفقیت تماس واقعی Gemini یا درستی همه صفحه‌ها در مرورگر نیست.
