# RushFinder 0840 — نسخه وب با ظاهر خلوت‌تر

این بسته برای انتشار روی Vercel از نسخه 0839 ساخته شده است.

## تغییرات

- حذف عنوان توضیحی اضافی بالای دکمه‌های انتخاب حجم.
- حذف دو کادر انتخاب نوع کیفیت؛ پردازش به‌صورت پیش‌فرض روی حالت «کیفیت تصویری بسیار بالا» (CRF 17، بدون کاهش رزولوشن یا نرخ فریم و با کپی صدای اصلی) انجام می‌شود.
- حذف متن بلند توضیحی پایین دکمه فشرده‌سازی.
- حذف توضیح بلند درباره Vercel از زیر پیش‌نمایش فیلم.
- حفظ انتخاب حجم ۱۰/۲۰/۳۰/۵۰/۱۰۰ مگابایت و حجم دلخواه، دکمه فشرده‌سازی و گزارش خطا.
- حفظ اصلاح مصرف حافظه برای فیلم‌های بزرگ از نسخه 0839.

## نصب

فایل‌های این بسته را روی فایل‌های پروژه GitHub جایگزین کنید و commit/push انجام دهید تا Vercel نسخه جدید را منتشر کند. فقط بازکردن Start-RushFinder.cmd، نسخه وب را منتشر نمی‌کند.

## نکات

- پردازش ویدئو با FFmpeg WASM در مرورگر کاربر انجام می‌شود و در کد کم‌حجم‌کننده مسیر آپلود فیلم به Vercel وجود ندارد. فایل‌های موتور FFmpeg به‌عنوان فایل‌های استاتیک از سایت دریافت می‌شوند.
- انتخاب حجم «هدف» است؛ بدون کاهش محسوس کیفیت، رسیدن به آن قطعی نیست.
- اگر حجم ویدئو پیشاپیش کمتر از هدف باشد، خود فایل اصلی برای دریافت ارائه می‌شود.
- اجرا روی سایت واقعی پس از انتشار لازم است تست شود.
