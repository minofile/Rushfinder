RushFinder WEB 0710 — Gemini Chabokan — محافظت از قالب اصلی

این بسته از روی نسخه کامل 0709 ساخته شده است.
فایل‌های قالب PNG اصلی در assets/infographic-templates بدون حتی یک بایت تغییر حفظ شده‌اند.

اصلاحات:
- تصویر تولیدشده فقط داخل محدوده امن محتوا رسم می‌شود.
- تیتر فارسی از ورودی کاربر و در ناحیه جدا و دور از لوگوی بالای راست رسم می‌شود.
- قالب اصلی پس از همه محتوا روی خروجی قرار می‌گیرد.
- پرامپت Gemini از ساخت تیتر داخل تصویر خودداری می‌کند تا متن تکراری یا روی لوگو نیفتد.
- اتصال Gemini / Chabokan API مانند نسخه 0709 نگه داشته شده است.
