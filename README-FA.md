# RushFinder 01050 — Premium Reference Rules

این اصلاحیه بر پایه نسخه 01049 است. قانون ثابت هشت‌گانهٔ طراحی سه‌بعدی لوکس به موتور پرامپت Flare افزوده شده است. سه نمونهٔ مرجع بازار مالی، بارندگی و خودروسازان در گالری پنجره بازبینی قابل مشاهده‌اند. انتخاب چیدمان بر اساس تعداد، طول متن و سهم واقعی از کل انجام می‌شود: کارت‌های افقی همراه صحنه اصلی، کارت‌های منظم محصولی، کارت‌های توضیحی یا سهم‌های یک کل.

اندازهٔ کارت‌ها در هر مجموعه یکسان است و از طولانی‌ترین داده محاسبه می‌شود؛ محل هر ناحیهٔ متن در پرامپت و Canvas مشترک است. تیتر روی محور میانی تصویر قفل شده و عرضش برای ناحیه لوگوی اصلی محدود شده است. تصاویر لوگوی چهار رسانه و API موجود بدون تغییر کپی شده‌اند. استوری همچنان غیرفعال است.

توجه مهم: تصاویر مرجع **در رابط کاربر** قابل مشاهده‌اند و به عنوان ورودی تصویری به AvalAI ارسال نمی‌شوند؛ فقط توضیح ساختاری سبک و محل کارت‌ها در متن پرامپت فرستاده می‌شود. هر درخواست پولی فقط پس از تأیید پرامپت است. تضمین کیفیت بصری مدل بدون آزمایش واقعی ممکن نیست.
