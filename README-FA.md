# RushFinder 01048 — متن ورودی بدون محدودیت طول

- متن خام هر اندازه‌ای باشد، صرفاً به خاطر طول آن ساخت مسدود نمی‌شود.
- برای پست مربع، حداکثر ۸ دادهٔ منتخب به خلاصه‌های کوتاه تبدیل می‌شوند؛ متن اصلی در فرم محفوظ می‌ماند.
- هنگام کلیک ساخت، پنجرهٔ پرامپت و فهرست داده‌های انتخاب‌شده نشان داده می‌شود؛ تأیید قبل از درخواست پولی الزامی است.
- محتوای کاملِ نامحدود نمی‌تواند هم‌زمان با فونت درشت روی یک تصویر مربع نمایش داده شود. گزینش ۸ نکته و خلاصه‌سازی به‌صورت شفاف اعلام می‌شود.
- لوگوها و API همان نسخه پیشین‌اند. هیچ درخواست پولی تست نشده است.
- کیفیت بصری Flare در این اصلاحیه تست نشده است.
