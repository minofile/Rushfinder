# RushFinder 01021 — اصلاح سبک پریمیوم 2D/3D

## نصب بدون هزینه AvalAI
این فایل ZIP **پچ بخش اینفوگرافیک** است، نه کل پروژه. محتوای آن را روی مسیرهای متناظر پروژه موجود در GitHub کپی و جایگزین کنید. برای جلوگیری از تغییر ناخواسته، ابتدا از فایل فعلی نسخه پشتیبان بگیرید.

## تغییرات
- رفع باگ مهم پرامپت خبر فوری: انتخاب 2D دیگر به صورت اجباری 3D فرستاده نمی‌شود.
- ارتقای پرامپت 3D به رندر پرجزئیات و حجمی و جلوگیری از تصاویر کوچک، تخت و ساده.
- رنگ‌بندی موضوعی برای قیمت‌ها (قرمز/زرد) و موضوع‌های طبیعی (کرم/سبز).
- ارتقای کارت‌های سفید با سایه، آیکون، ارزش‌گذاری بهتر اعداد و حالت مجزای 2D.
- فایل لوگوهای اصلی و قالب‌های مربع/استوری دست‌نخورده مانده‌اند.
- حذف‌نشدن داده‌های منبع و نمایش هشدار برای داده‌های بسیار زیاد.
- تغییر سبک روی تصویر پولی قبلی، بدون ارسال درخواست پولی جدید؛ پیام وضعیت توضیح می‌دهد که سبک جدید مربوط به ساخت بعدی است.

## اعتبارسنجی
اسکریپت‌های JavaScript از نظر نحوی با Node بررسی شده‌اند. هیچ درخواست پولی AvalAI یا تست زنده Vercel انجام نشده است. کیفیت تصویرسازی نیاز به مشاهده خروجی مدل پس از نصب دارد.
