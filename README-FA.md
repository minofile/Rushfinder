# RushFinder 01042 — پرامپت موضوع‌محور و پیش‌نمایش داده‌ها

این بسته **اصلاحیه وب** است و جایگزین کل مخزن نمی‌شود. فایل‌ها را با حفظ ساختار پوشه‌ها روی مخزن فعلی کپی کنید.

## اصلاحات
- خبر فوری: تم سبز زمردی و تیره ثابت؛ لوگوی اصلی بدون تغییر.
- در حالت پیشنهادی «تصویرسازی اختصاصی هر کارت + متن دقیق سایت»، تصویرسازی داده‌ها از معنی هر مورد انتخاب می‌شود و برای هر مورد مختصات هم‌خوان با کارت واقعی در پرامپت ارسال می‌شود.
- صورت مسئله هر خبر و موضوع اصلی در پرامپت تصویر لحاظ می‌شود. هیچ اطمینانی وجود ندارد مدل تصویرساز تمام مختصات را دقیق اجرا کند.
- شش کارت مربع به‌عنوان سقف انتخاب می‌شوند؛ اگر ورودی بیشتر باشد، موارد انتخاب‌شده در پنجره تأیید نمایش داده می‌شود. تمام متن اصلی در ورودی می‌ماند.
- پنجره کامل پرامپت همیشه قبل از ارسال هزینه‌دار باز می‌شود، قابل‌ویرایش است و **فهرست واقعی داده‌های منتخب** را هم نمایش می‌دهد.
- گزینه استوری برای همه چهار رسانه غیرفعال می‌ماند؛ فایل‌های اصلی لوگو و API بدون دستکاری حفظ شده‌اند.
- بدون کلیک «تأیید و ساخت تصویر»، درخواست تصویرسازی پولی ارسال نمی‌شود. پاسخ نامعلوم به صورت خودکار تکرار نمی‌شود.

## محدودیت‌های شفاف
- آزمایش‌های رایگان انجام شده‌اند: کنترل نحوی JS و سلامت ZIP. آزمایش تصویری واقعی AvalAI انجام نشده است و کیفیت یکسان با تصاویر ChatGPT تضمین نیست.
- مرورگر محلی به دسترسی فایل خطای `ERR_BLOCKED_BY_ADMINISTRATOR` داد، بنابراین این نسخه به عنوان «مرورگری آزمایش‌شده» معرفی نمی‌شود.
- گزینش اطلاعات در مرورگر هنوز عمدتاً مبتنی بر قواعد است؛ معنای پیچیده و انتخاب نهایی سوژه را مدل تصویرساز انجام می‌دهد. برخی خبرهای طولانی ممکن است نیاز به بازبینی داده‌ها قبل از ارسال داشته باشند.
