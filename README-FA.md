# RushFinder — نسخه وب 01038 | طراحی خودکار ممتاز و اصلاح ساختاری کارت‌ها

## نصب
فایل‌های داخل ZIP را با حفظ مسیر در ریشه مخزن GitHub جایگزین کنید. `infographic.html`، `api/avalai-image.js` و هشت PNG اصلی در `assets/infographic-templates/` موجودند. سپس Commit/Push و انتشار Vercel.

## تغییرات اساسی
- طرح عکس کنار متن برای خبرهای دارای ۱ تا ۴ داده، به‌جای تصویر فشرده در نوار بالای کارت. هندسه برش عیناً با پرامپت تصویرسازی مطابقت دارد.
- برای پنج داده، چینش سه کارت بالا و دو کارت پایین، با تصویر اختصاصی هر کارت حفظ شده است.
- تصویرسازی لوکس موضوعی و اصلی یکپارچه؛ بدون آیکون ساده Canvas و بدون درخواست پولی جداگانه برای هر محصول.
- متون دقیق فارسی از سایت با فونت انتخابی، نام+وزن+قیمت یکجا، حذف داده تکراری و لوگوی شفاف اصلی هر چهار برند.
- «High» کیفیت پیش‌فرض است؛ هزینه آن می‌تواند بیشتر باشد و کاربر هنگام تأیید یک‌باره از هزینه‌دار بودن ساخت مطلع می‌شود. مدل Flare پیش‌فرض و Sunburst همچنان اختیاری است.
- حذف پنجره تأیید هزینه تکراری؛ یک مرحله تأیید صریح پیش از هر درخواست هزینه‌دار باقی می‌ماند.
- استوری چهار رسانه غیرفعال و خروجی فعلاً مربع است.

## ملاحظات
API AvalAI به وب‌سایت chatgpt.com وصل نمی‌شود؛ از سرویس تصویرسازی استفاده می‌کند. کیفیت دقیقاً یکسان تضمین نیست. پرامپت و تصویر نهایی به رفتار مدل وابسته‌اند. هیچ درخواست پولی در فرایند تهیه این بسته ارسال نشده است.
