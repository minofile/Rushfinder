# RushFinder 01032 — کارت‌های دارای المان موضوعی، تراز دقیق

اصلاحیه بخش اینفوگرافیک برای قرار دادن در ریشه پروژه GitHub. **کل سایت نیست**.

- تغییر اصلی مستقیماً داخل رندر Canvas است؛ نه یک اسکریپت جدا با توابع غیرقابل دسترس.
- برای هر نکته، کارت دارای المان تصویری متناسب با کلیدواژه آن (مثلاً باران، سد، خط انتقال آب، تصفیه، آزمایش، شهر، پزشکی، آموزش، مالی و ...) اضافه شد.
- متن هر کارت در قسمت مخصوص خودش افقی و عمودی وسط‌چین است و با فونت انتخابی کاربر رسم می‌شود.
- کارت‌های ردیف آخر در صورت کم بودن تعداد، به شکل گروهی وسط‌چین می‌شوند.
- کادر تیتر، اندازه‌های پست و استوری، لوگوهای اصلی چهار برند و تایید پیش از درخواست پولی حفظ شده‌اند.

**محدودیت مهم:** المان‌ها در این نسخه آیکون‌های موضوعی ترسیم‌شده با Canvas هستند، نه تصاویر فوتورئال اختصاصیِ هر کارت. برای تصاویر اختصاصیِ هر کارت به مراحل تولید و بررسی جداگانه نیاز است. متن‌های بسیار بلند در یک کارت ممکن است همچنان محدودیت خوانایی داشته باشند.

## نصب
فایل‌های `infographic.html`، `api/avalai-image.js` و پوشه `assets/infographic-templates/` را در مسیرهای متناظر پروژه جایگزین کن. پوشه فونت‌های پروژه را حذف نکن.

این فایل بدون فراخوانی AvalAI ساخته شده است. بررسی نحوی جایگزین آزمایش خروجی واقعی مرورگر و مدل تصویرسازی نیست.
