# RushFinder 01030 — تایپوگرافی دقیق کارت‌ها و تیتر

این بسته فقط **اصلاحیه** است؛ فایل‌های آن را در همان مسیرهای پروژه GitHub جایگزین کنید. بخش‌های دیگر سایت و پوشه فونت‌های قبلی را حذف نکنید.

- حالت «کارت‌های شیک + متن دقیق با فونت انتخابی» اکنون پیش‌فرض است. تصویرسازی حرفه‌ای و بدون هیچ نوشته به مدل درخواست می‌شود؛ تیتر و کارت‌ها در Canvas سایت با فونت انتخابی (کهربا، مودام، ری، دوران) و ارقام فارسی رسم می‌شوند.
- متن در کارت‌ها وسط‌چین افقی و عمودی است، فاصله داخلی دارد و اندازه فونت براساس ابعاد و طول متن کاهش می‌یابد.
- برای هر چهار رسانه از قالب‌های اصلی پست و استوری استفاده می‌شود؛ خبر فوری تم سبز ثابت دارد.
- انتخاب سبک‌های 3D/2D/جدولی/نموداری/مقایسه‌ای/خط زمانی در درخواست تصویر حفظ شده است؛ کارت‌های وب در حالت 3D/خودکار برجسته و در سایر سبک‌ها کم‌حجم هستند.
- حالت «طراحی حرفه‌ای مدل‌ساخته» نیز برای حفظ ظاهر قبل باقی است، اما متن تولیدی داخل عکس ممکن است غلط و متفاوت از فونت انتخابی باشد.
- اگر جمله‌ها خیلی طولانی باشند، حتی رندر دقیق ممکن است نیاز به خلاصه‌کردن متن انتخابی داشته باشد؛ اعداد یا اطلاعات منبع تغییر نمی‌کنند.
- برای جلوگیری از هزینه، هیچ درخواست AvalAI در تست این بسته ارسال نشده است. خروجی واقعی مدل روی Vercel تضمین نشده است.

**نصب:** فایل‌های این بسته را در مسیر مشابه جایگزین، Commit و Push کنید. حتماً `fonts/` در پروژه اصلی موجود باشد. ابتدا بدون ساخت پولی، نمایش نسخه وب 01030 و قالب پست/استوری را بررسی کنید.
