# RushFinder 01053 — اصلاح محل واقعی متن و حذف کوتاه‌سازی

این بسته یک اصلاحیه مسیر وب اینفوگرافیک است، نه کل سایت.

- دیگر اطلاعات منتخب با «…» و محدودیت ۷۰ یا ۸۰ نویسه حذف نمی‌شوند.
- متن از همان منبع انتخاب‌شده بدون برش در خروجی قرار می‌گیرد.
- پس از دریافت تصویر Flare، سایت رنگ روشن سطح کرم هر کارت را از پیکسل‌های واقعی تشخیص می‌دهد و متن را وسط همان سطح قرار می‌دهد؛ مختصات ثابت فقط مسیر جایگزین‌اند.
- هیچ مستطیل سفید، حاشیه یا کادر دوم در حالت Flare کشیده نمی‌شود.
- فونت فارسی تا ۸ پیکسل در صورت ضرورت کوچک می‌شود؛ اگر حتی آن هم جا نشود، هشدار می‌دهد و متن حذف نمی‌کند.
- لوگوهای اصلی هر چهار رسانه، رنگ‌ها، فایل API و محدودیت استوری حفظ شده‌اند.

**محدودیت:** مدل ممکن است ناحیه کرم را بسیار متفاوت تولید کند؛ تشخیص پیکسلی برای رنگ‌ها و جایگاه‌هایی شبیه تصاویر مرجع طراحی شده و تضمین صددرصد ندارد. هیچ تماس پولی با AvalAI برای آزمایش این نسخه انجام نشده است.
