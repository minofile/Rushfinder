# RushFinder 01043 — Flare-first premium infographic patch

این بسته فقط اصلاحیه وب است. مسیرهای فایل‌ها را عیناً روی GitHub جایگزین کنید.

## تغییر اصلی
- موتور انتخاب‌شده GPT Image 2.5 Flare (AvalAI)، کیفیت High؛ تغییر مدل از UI حذف شده است.
- حالت پیش‌فرض «طراحی کامل کارت‌های سه‌بعدی توسط مدل» است. سایت دیگر در این حالت مستطیل‌های ساده Canvas تولید نمی‌کند.
- Flare تمام صحنه و کارت‌های سه‌بعدی را تولید می‌کند ولی از رسم نوشته منع می‌شود؛ سایت متن دقیق فارسی را در صفحه‌های داخلی پایین کارت‌ها اضافه می‌کند و لوگو PNG اصلی را مهر می‌زند.
- پرامپت کامل در هر درخواست باز می‌شود، قابل ویرایش است و بدون تأیید به API ارسال نمی‌شود.
- تا هشت مورد در مربع قابل انتخاب است؛ بیش از هشت مورد باید در بازبینی به‌صورت شفاف اعلام شود؛ داده‌ها بی‌صدا حذف نمی‌شوند.
- استوری همچنان غیرفعال است و تم خبر فوری سبز است.

## محدودیت‌های مهم
- هیچ تصویر پولی با AvalAI تولید نشده است؛ کیفیت واقعی خروجی مدل و پایبندی به مختصات بررسی نشده و تضمین نمی‌شود.
- پرامپت و Canvas هم‌مختصات هستند، ولی مدل ممکن است کارت‌ها را در جای دیگری بکشد؛ در این حالت ساخت دوباره پولی بدون تأیید ممنوع است.
- برای خبرهایی با ۱۰ یا تعداد بیشتری مورد، نمایش ۸ مورد در مربع هنوز یک محدودیت است؛ قبل از تأیید هزینه فهرست موارد منتخب را بررسی کنید.
- API و لوگوهای اصلی از نسخه قبل بدون تغییر کپی شده‌اند.
