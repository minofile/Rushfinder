# RushFinder 01020 — قالب پست و استوری چهار برند

این بسته یک وصله برای پروژه موجود است، نه جایگزین کل پروژه.

- پست مربع: خروجی ۱۰۸۰×۱۰۸۰ و فایل مربع همان برند.
- استوری: خروجی ۱۰۸۰×۱۹۲۰ و فایل عمودی همان برند.
- هشت قالب اصلی مستقل با نام و مسیر مشخص موجودند.
- لوگوی اصلی در لایه آخر روی تصویر قرار می‌گیرد؛ مدل نباید لوگو تولید کند.
- برای قالب‌های ۱۲۸۰×۱۹۲۰ استوری به‌جای فشرده‌کردن لوگو، ناحیه خالی چپ بریده می‌شود.
- قالب مربع خبر فوری از نسخه شفاف اصلی پروژه است، چون فایل مرجع آپلودی RGB و سفید غیرشفاف بود و اگر مستقیماً روی محتوا کشیده می‌شد محتوا را پاک می‌کرد.
- هیچ دانلود یا ساخت تصویر از AvalAI برای تهیه این بسته انجام نشده است.

## نصب
فایل‌های `infographic.html` و `api/avalai-image.js` را در همان مسیر جایگزین کنید، و **هر هشت فایل** `assets/infographic-templates/` را نیز آپلود کنید. فایل‌های فونت و دارایی‌های دیگر پروژه را نگه دارید. Deploy کنید. برای اطمینان از اندازه، ابتدا یک پیش‌نمایش محلی بدون تولید پولی باز کنید.

## محدودیت تست
مسیرهای انتخاب، ابعاد فایل‌ها، شفافیت قالب‌ها و ساختار JavaScript کنترل شده‌اند. تست اتصال زنده AvalAI انجام نشده است.
