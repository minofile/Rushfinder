# RushFinder 01036 — اصلاح کیفیت اینفوگرافیک

این بسته **اصلاحیه بخش اینفوگرافیک** است و نباید به جای کل وب‌سایت نصب شود. محتویات را در همان مسیرهای مخزن GitHub قرار دهید.

تغییرات:
- کیفیت اولیه از Low به Medium تغییر داده شد؛ **Medium ممکن است هزینه بیشتری داشته باشد**. تأیید پولی دستی باقی مانده است.
- برای حالت «تصویرسازی اختصاصی هر کارت + متن دقیق»، مختصات هر تصویر کارت دقیقاً با برش همان کارت در Canvas یکسان‌سازی شد.
- متن دقیق فارسی و فونت انتخابی در مرورگر رسم می‌شوند؛ مدل فقط سوژه و تصویرسازی بدون متن تولید می‌کند.
- انتخاب المان از روی عنوان همان آیتم انجام می‌شود، با اجتناب از تکرار یک نوع تصویر در یک خروجی.
- زمینه پشت کارت‌ها کمی شفاف‌تر شده تا تصویر اصلی لوکس‌تر به نظر برسد.
- چهار رسانه و PNGهای اصلی حفظ شده‌اند، استوری فعلاً غیرفعال و خروجی مربع ۱۰۸۰×۱۰۸۰ است.

نکته: API مدل تصویر لزوماً با موتور تصویرسازی خود ChatGPT یکسان نیست؛ تضمین کیفیت یکسان یا قرارگیری کاملاً دقیق اشیا ممکن نیست. **هیچ درخواست پولی برای آزمایش این بسته ارسال نشده است.**

روش نصب: فایل‌های `infographic.html`، `api/avalai-image.js` و پوشه `assets/infographic-templates/` را روی نسخه موجود سایت جایگزین کنید؛ پوشه فونت‌های پروژه را پاک نکنید.
