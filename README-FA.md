# RushFinder 01057 — تحلیل نکات قبل از تصویرسازی

این بسته اصلاحیه وب است؛ جایگزین فایل‌های هم‌مسیر GitHub شود.

- تشخیص بندهای شماره‌دار، تیترهای Markdown و بندهای نشانه‌دار با توضیحات همان بند در **یک کارت**.
- تعداد کارت‌ها از نکات واقعی متن استخراج می‌شود؛ برای تعداد زیاد، صفحه‌بندی چند پست مربع مستقل انجام می‌شود و هیچ صفحه بعدی بدون تأیید هزینه‌دار ساخته نمی‌شود.
- انتخاب ظرفیت هر پست علاوه بر بلندترین متن، حجم کل متن همان صفحه را هم در نظر می‌گیرد.
- در پنجره پرامپتِ قابل‌ویرایش، فهرست واقعی نکات و المان پیشنهادی تک‌تک کارت‌ها پیش از هزینه نمایش داده می‌شود.
- GPT Image 2.5 Flare مسئول ساخت کارت‌های سه‌بعدی و تصویرسازی است. RushFinder باید متن دقیق فارسی را روی سطح متنی همان کارت اضافه کند. قالب‌های ۴ رسانه و رنگ سبز خبر فوری ثابت‌اند؛ استوری همچنان خاموش است.
- در این بسته هیچ فراخوانی به AvalAI انجام نشده است؛ تضمین کیفیت عکس مدل بدون تولید آزمایشی ممکن نیست.
- **محدودیت قابل‌توجه:** تجزیه متن غیراستاندارد همچنان ممکن است به بازبینی کاربر نیاز داشته باشد؛ موارد منتخب قبل از پرداخت نمایش داده می‌شوند.
