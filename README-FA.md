# RushFinder 01065 — اصلاح خطای خواندن فایل در برش ویدیو

این بسته فقط `video-cut.html` را تغییر می‌دهد. به فایل‌های تگ خبر، After Effects، اینفوگرافیک، API و سایر صفحه‌ها دست نمی‌زند.

## نصب

۱. از فایل فعلی `video-cut.html` در ریشه پروژه یک نسخه پشتیبان تهیه کن.
۲. فایل جدید این بسته را جایگزین فایل هم‌نام در ریشه پروژه GitHub کن.
۳. Commit/Push کن و بعد از انتشار موفق سایت، در مرورگر Ctrl+Shift+R بزن.
۴. فایل ویدیو را از نو انتخاب کن و یک برش کوتاه آزمایش کن.

## تغییر

- فایل انتخاب‌شده قبل از بارگذاری FFmpeg WASM خوانده و کنترل می‌شود تا خطای از دست رفتن دسترسی با تأخیر رخ ندهد.
- خطای دسترسی، حافظه و خطای موتور به تفکیک و با توضیح فارسی نمایش داده می‌شود.
- پیام ارجاع به فایل ناموجود RushFinder.bat حذف شده است.

## محدودیت

اگر مرورگر از همان ابتدا به فایل دسترسی نداشته باشد این نسخه آن را دور نمی‌زند؛ خطای روشن و راهنمای انتخاب دوباره ارائه می‌کند. اگر فیلم بسیار حجیم باشد، محدودیت حافظه FFmpeg داخل مرورگر همچنان وجود دارد. این بسته بدون آپلود ویدیو به سرور کار می‌کند. تست زنده روی فایل/سیستم کاربر انجام نشده است.
