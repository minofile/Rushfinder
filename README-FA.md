# RushFinder — اصلاحیه وب 01028

این بسته **اصلاحیه بخش اینفوگرافیک** است، نه وب‌سایت کامل. فایل `infographic.html`، پوشه `api` و هشت فایل قالب در مسیرهای یکسان GitHub جایگزین شوند. سایر فایل‌های پروژه و فونت‌های نصب‌شده را حذف نکنید.

## تغییرات
- تفاوت واقعی دستور سبک‌های 3D، 2D، جدولی، نموداری، مقایسه‌ای، تایم‌لاین، کارت، مینیمال و خودکار برای چهار برند.
- تم سبز خبر فوری و رنگ‌بندی مستقل سه برند دیگر حفظ شده است.
- قاب تیتر در سبک 3D برجسته‌تر و دارای سایه و هایلایت است؛ نوشتار با فونت انتخابی در Canvas و محدوده امن لوگو باقی می‌ماند.
- قالب اصلی ۸گانه و مکان لوگوی هر رسانه دست‌نخورده است؛ منع پس‌زمینه سفید مصنوعی حفظ می‌شود.
- بازبینی و تأیید کاربر قبل از درخواست AvalAI حفظ شده؛ بدون تماس با API آزموده شده است.

## محدودیت صادقانه
در حالت «حرفه‌ای و آزاد»، اعداد و متن کارت‌های داده هنوز ممکن است به‌وسیله مدل تصویرسازی تولید شوند و غلط املایی یا تاری داشته باشند. برای دقت کامل متن، گزینه «چیدمان دقیق سایت» را انتخاب کنید، هرچند ظاهر آن ممکن است کمتر آزاد باشد. کیفیت واقعی خروجی پولی و انتشار Vercel آزمایش نشده‌اند.
