# RushFinder 01017 — اصلاح رد شدن میزبان لینک تصویر AvalAI

## خطا
`آدرس تصویر خارج از میزبان‌های مجاز یا نامعتبر است`

علت: در 01016 سرور فقط لینک فایل از چند دامنه ثابت را اجازه می‌داد و هر URL دیگر را قبل از دانلود رد می‌کرد؛ حتی اگر AvalAI همان URL را داده باشد.

## نصب
هر دو فایل در مسیر صحیح GitHub قرار گیرند:
- `api/avalai-image.js`
- `infographic.html`

در Vercel، Settings → Environment Variables متغیر زیر را **در صورت نیاز** بسازید:

`RF_IMAGE_ALLOWED_HOSTS` = فقط hostname دقیق فایل تصویری که در پیام خطای جدید نمایش داده می‌شود.

مثال ساختاری (مقدار واقعی نیست): `image-cdn.example.com`

اگر چند میزبان معتبر و بررسی‌شده وجود دارد، با کاما جدا شوند. `https://`، مسیر فایل، علامت `*` یا URL کامل قرار ندهید. هیچ کلید API در این متغیر نوشته نشود. محیط Production را انتخاب کنید و Redeploy انجام دهید.

## بازیابی امن
1. در همان تب قدیمی RushFinder، URL ساخته‌شده را ذخیره کنید؛ تب را نبندید.
2. پس از انتشار فایل‌های اصلاح‌شده، با گزینه «بازیابی تصویر قبلی (رایگان)» فقط همان فایل موجود دانلود می‌شود.
3. این مسیر **هیچ POST به `/images/generations`** انجام نمی‌دهد.
4. اگر تصویر منقضی یا حجم آن بیش از سقف سرور باشد، ممکن است بازیابی ممکن نشود.
5. پس از نمایش خروجی، PNG را ذخیره کنید.

## امنیت
هیچ آدرس دلخواه اینترنتی آزاد نشده است. فقط لینک HTTPS بدون پورت، userinfo و میزبان خصوصی بررسی می‌شود و میزبان اضافه صرفاً از تنظیمات سرور انتخاب می‌شود. Redirect دنبال نمی‌شود. هر hostname اضافی باید قبلاً بررسی شود.

## وضعیت تست
کد API و همه بلوک‌های JavaScript صفحه از نظر نحوی کنترل شد. امکان آزمون لینک واقعی بدون URL خصوصی فایل کاربر وجود ندارد. اصلاح *قطعی* مشکل CORS یا انقضای لینک را تضمین نمی‌کند.
