RushFinder 01040 — اصلاح موتور اینفوگرافیک (WEB PATCH)

- پرامپت کامل و قابل ویرایش با هر کلیک ساخت نمایش داده می‌شود؛ تا تأیید کاربر هیچ درخواست پولی انجام نمی‌شود.
- انتخاب تصویر هر کارت براساس محتوای دقیق همان کارت و موضوع خبر انجام می‌شود؛ «قیمت» و «تومان» دیگر محرک تصاویر فروشگاهی نیستند.
- برای موضوعات ناشناخته، به‌جای انتخاب نماد ثابت بی‌ربط، از مدل خواسته می‌شود سوژه دقیق مرتبط با همان داده را انتخاب کند.
- هویت رنگی و فایل‌های اصلی لوگوی چهار رسانه بدون تغییر؛ خروجی فقط مربع، استوری غیرفعال.
- این بسته فقط صفحه اینفوگرافیک، API و لوگوهای اصل را شامل می‌شود، نه کل سایت. فایل‌ها را در مسیر متناظر GitHub جایگزین کنید.
- آزمایش رایگان نحو JS و یکپارچگی ZIP انجام شده؛ کیفیت واقعی مدل AvalAI بدون درخواست پولی قابل تأیید نیست.
