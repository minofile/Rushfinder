# RushFinder 01016 — رفع مشکل لینک تصویر / CORS بدون ساخت دوباره

این بسته شامل **دو فایل** است و باید هر دو در مسیر صحیح پروژه جایگزین شوند:

- `infographic.html` در ریشه پروژه
- `api/avalai-image.js` در پوشه `api`

## تغییرات
- وقتی AvalAI لینک HTTPS برگرداند، سایت تصویر **از طریق API خود RushFinder** دانلود می‌کند و سپس روی Canvas نشان می‌دهد؛ مرورگر دیگر به CORS میزبان AvalAI وابسته نیست.
- این endpoint فقط فایل **قبلاً تولیدشده** را دانلود می‌کند؛ به `/images/generations` هیچ درخواست جدیدی نمی‌زند.
- لینک HTTPS نتیجه در sessionStorage همان تب مرورگر حفظ می‌شود و گزینه بازیابی آن در صفحه نشان داده می‌شود.
- محدودیت حجم پاسخ Vercel و لینک‌های منقضی همچنان ممکن است مانع بازیابی شوند؛ در این صورت پیام مناسب می‌دهد و لینک اصلی حفظ می‌شود.
- به هیچ‌وجه API Key را در فایل عمومی وارد نکنید. متغیرهای محرمانه Vercel بدون تغییر می‌مانند.

## نصب
هر دو فایل را در GitHub جایگزین کنید و Deploy کنید. در برگه قدیمی، قبل از بستن یا تازه‌سازی صفحه، **لینک تصویر تولیدشده** را ذخیره کنید. پس از Deploy، اگر همان تب و sessionStorage باقی مانده باشد، لینک را می‌توان برای بازیابی به کار برد. صرفاً Deploy کردن فایل‌ها، بایت‌های تصویر منقضی یا حذف‌شده را بازیابی نمی‌کند.

## محدودیت تست
JavaScript از نظر نحوی کنترل شده است؛ اتصال واقعی به فایل خصوصی AvalAI بدون URL اصلی ممکن نیست. این اصلاح کیفیت تصویر یا سرویس ساخت تصویر را تغییر نمی‌دهد.
