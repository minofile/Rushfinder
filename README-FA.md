# RushFinder 01049 — Center Lock + Persian Card Text

اصلاحیه وب: تیتر و پنل آن دقیقاً حول مرکز فیزیکی تصویر مربع قرار می‌گیرند و سمت راست با لوگوی اصلی تداخل ندارند. متن‌های هر کارت با اندازه‌گیری واقعی Canvas، راست‌به‌چپ، در یک ناحیه واحد و وسط‌چین عمودی/افقی قرار می‌گیرند. پرامپت Flare و مختصات کادر متن سایت هماهنگ شد.

نصب: تمام فایل‌های بسته را در همان مسیر پروژه GitHub جایگزین کنید؛ لوگوهای PNG اصلی و API حفظ شده‌اند. هیچ تست هزینه‌دار AvalAI انجام نشده است.

## آزمون انجام‌شده
در مرورگر Chromium با یک پس‌زمینه آزمایشیِ بدون API، خبر شش‌موردی آزمایش شد: مرکز کادر تیتر روی X=540 از عرض 1080 ثبت شد؛ شش متن در شش جایگاه رسم شدند؛ پنجره پرامپت با کلیک «ساخت» باز شد؛ هیچ درخواست پولی ارسال نشد؛ خطای اجرایی JavaScript ثبت نشد. این آزمون کیفیت واقعی تصاویر Flare را تأیید نمی‌کند.
