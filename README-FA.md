## نصب
این فایل **پچ قابل جایگزینی در پروژه موجود** است، نه کل وب‌سایت. فایل‌های `infographic.html`، `api/avalai-image.js` و هشت فایل PNG در `assets/infographic-templates/` را در همان مسیرهای GitHub جایگزین کنید. فونت‌ها و سایر فایل‌های سایت فعلی را دست‌نخورده نگه دارید.

## تغییرات
- خبر فوری: رنگ هویت **همیشه** سبز #00834A و #006D3C و کرم #F6F3EF؛ حتی برای خبر قیمت و گرانی.
- تصویر خبر فوری: لوگو و نوار اصلی از **فایل PNG اصلی آپلودشده** اعمال می‌شوند؛ لوگوی مصنوعی ساخته نمی‌شود.
- پست مربع 1080×1080، استوری 1080×1920. قالب‌های استوری اصلی 1280×1920 هستند و هنگام درج از سمت چپ برش امن می‌خورند تا لوگو کشیده نشود.
- حالت آزاد حرفه‌ای پیش‌فرض: مدل طراحی کامل 2D یا 3D را بنا بر انتخاب کاربر انجام می‌دهد؛ **متن فارسی ممکن است توسط مدل اشتباه نوشته شود**. لطفاً پیش از انتشار بررسی کنید.
- حالت چیدمان دقیق: اعداد و متن را مرورگر می‌نویسد؛ در اخبار طولانی ممکن است فشرده شود.
- **قبل از درخواست پولی**، وجود قالب اصلی و سازگاری نسبت ابعاد آن بررسی می‌شود؛ در صورت مشکل درخواست ارسال نمی‌شود.
- پنجره بررسی پرامپت و **تأیید صریح هزینه** همچنان اجباری است.
- جلوگیری از تلاش مجدد ناخواسته در صورت نتیجه نامعلوم حفظ شده است.
