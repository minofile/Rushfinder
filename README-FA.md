# RushFinder 01024 — تحلیل خودکار خبر خام، بدون محدودیت ۱۸ ردیف

## نصب
این بسته پچ وب است؛ داخل مخزن فعلی GitHub در همان مسیرها جایگزین شود، نه به‌عنوان پروژه مستقل. فایل‌های دیگر پروژه، فونت‌ها و تنظیمات API حفظ شوند.

## تغییرات
- متن خام خبر حتی بیش از ۱۸ خط پذیرفته می‌شود؛ هیچ پیام توقف ۱۸ ردیفی ندارد.
- گزینش رایگان و قطعی در مرورگر: برای پست مربع حداکثر ۵ نکته و برای استوری حداکثر ۷ نکته کلیدی از متن *اصلی*، با اولویت عدد، واحد و مقایسه؛ هیچ مقدار ساختگی ایجاد نمی‌شود. متن کامل در ورودی کاربر حفظ می‌شود.
- اگر خبر طولانی باشد، قبل از تأیید پولی اعلام می‌شود چند نکته انتخاب شده است و پرامپت کامل قابل بازبینی است.
- پرامپت و پیش‌نمایش محلی خبر فوری از انتخاب یکسان استفاده می‌کنند؛ کارت‌های ریز و غیرخوانا تولید نمی‌شوند.
- قالب‌های اصلی چهار برند در پست و استوری، تم سبز ثابت خبر فوری، انتخاب 2D/3D و تأیید دوباره برای AvalAI باقی مانده‌اند.
- برای پاراگراف‌های خیلی بلند، متن فقط بر اساس جمله‌های موجود شکسته می‌شود؛ خلاصه‌سازی زبانی عمیق یا درک قطعی صحت همه نکات بدون AI امکان‌پذیر نیست. متن انتخابی را قبل از پرداخت بازبینی کنید.

## توجه
این فایل پچ است و شامل کل سایت نیست. بررسی نحوی و ZIP بدون تماس پولی انجام می‌شود. خروجی واقعی AvalAI، کیفیت فارسی و سرور Vercel بدون ساخت واقعی قابل تضمین نیست.
