# RushFinder 01031 — Visual Cards Web Patch

این نسخه وب مشکل «کارت‌های بدون المان» را برطرف می‌کند.

## اصلاحات اصلی
- هر کارت خبری در حالت **متن و کارت دقیق سایت** حالا یک **المان تصویری/آیکون موضوعی** دارد.
- کارت‌ها با رندر حرفه‌ای‌تر `rf01019RenderCard` ساخته می‌شوند.
- فونت انتخاب‌شده کاربر همچنان برای متن کارت‌ها حفظ می‌شود.
- رنگ‌بندی کارت‌ها برای هر 4 رسانه نگه داشته شده است.
- محدوده امن لوگو و تیتر دست نخورده باقی می‌ماند.

## فایل اصلی
- `infographic.html`

## توضیح
در این پچ، بخش مرورگر که کارت‌ها را روی خروجی نهایی می‌کشد بازنویسی شده تا کارت‌های خالی جای خود را به کارت‌های دارای المان بدهند.
