# RushFinder 01018 — اصلاح بارگذاری تصویر و آزمون خروجی

## مشکل گزارش‌شده
میزبان فایل تصویر تولیدشده از AvalAI با نام `image-proxy-worker.gnbellosc.workers.dev` توسط سیاست میزبان‌های مجاز رد می‌شد.

## تغییرات
- میزبان **دقیق** `image-proxy-worker.gnbellosc.workers.dev` به فهرست مجاز سمت سرور افزوده شده است؛ هیچ wildcard یا دسترسی عمومی به دامنه‌های متفرقه اضافه نشده است.
- کنترل‌های HTTPS، ممنوعیت redirect و بررسی نوع و حجم فایل برقرارند.
- بازیابی از مسیر `GET /api/avalai-image?recover=image&url=...` است؛ بدون درخواست ساخت تصویر.
- در خروجی برند خبر فوری، برش و جای‌گذاری **بخش تصویری** از تصویر مربع به‌گونه‌ای تنظیم شد که مدل سه‌بعدی سمت راست بزرگ‌تر نشان داده شود. لوگو، متن و کارت‌ها همچنان از سایت هستند؛ لوگوی اصلی و بقیه برندها تغییر نکردند.

## نصب
فقط دو فایل زیر را در **همان مسیرها** در مخزن فعلی GitHub جایگزین کنید:
- `infographic.html`
- `api/avalai-image.js`

سپس Deploy بگیرید. اگر متغیر `RF_IMAGE_ALLOWED_HOSTS` از قبل تنظیم شده، نیازی به تغییر آن برای این میزبان خاص نیست.

## بازیابی بدون هزینه ساخت
1. اگر تب قبلی هنوز باز است، لینک فایل تصویر را از آن نگه دارید.
2. پس از انتشار نسخه جدید، در همان تب دکمه «بازیابی تصویر قبلی (رایگان)» را بزنید. اگر تب بسته شده باشد، ممکن است مقدار sessionStorage دیگر موجود نباشد.
3. **دکمه ساخت را برای بازیابی نزنید.** لینک‌های موقت منقضی‌شده را کد نمی‌تواند احیا کند.

## آزمون‌ها انجام‌شده
- بررسی نحوی ۶ بلوک JavaScript در HTML و فایل API با Node.js: موفق.
- شبیه‌سازی واقعی handler API با میزبان گزارش‌شده: `200 image/png`، بدون POST و بدون هزینه تصویرسازی.
- آزمون رد دامنه‌های دیگر و localhost: موفق (400).
- اجرای واقعی کد رندر در Chromium با `page.set_content` و داده‌های نمونه سدها: موفق، PNG 1080×1080؛ بدون خطای JavaScript.
- از همان تصویر تولیدشده قبلی که کاربر بارگذاری کرده بود و PNG قالب لوگوی اصلی در فایل پروژه استفاده شد.

## محدودیت صداقت تست
- دسترسی به URL امضاشده واقعی کاربر و حساب AvalAI در این محیط موجود نبود؛ تست شبکه زندهٔ آن میزبان و Vercel انجام نشده است.
- اگر میزبان تصویر، دانلود از IPهای Vercel را محدود کند، لینک منقضی شده باشد، یا فایل از سقف پروکسی بزرگ‌تر باشد، بازیابی همچنان ممکن است شکست بخورد؛ این خرابی به معنی نیاز به ساخت پولی دوباره نیست.
- پیش‌نمایش آزمایشگاهی فقط نمونه چیدمان است و تأیید صحت خبر نیست. فونت پیش‌نمایش آزمایشگاهی جانشین است؛ نسخه وب از انتخاب فونت خود سایت استفاده می‌کند.
