# RushFinder 01046 — اصلاح واقعی مسیر پیش‌نمایش و متن

این ZIP **اصلاحیه بخش اینفوگرافیک** است؛ فایل‌ها را در مسیرهای مشابه مخزن GitHub جایگزین کنید. API و ۸ قالب PNG اصلی رسانه‌ها بدون تغییر نسبت به 01045 همراه بسته هستند.

## تغییرات
- Flare همچنان مدل اصلی تولید کارت‌ها، المان‌ها و صحنه سه‌بعدی است؛ سایت فقط متن دقیق فارسی، صفحه ظریف هم‌جنس کارت و لوگوی اصلی را اضافه می‌کند.
- لایه متنی کارت از پوشش مستطیلی تخت به صفحه سرامیکی با گرادینت و لبه نرم تغییر کرده است؛ جای تصویر و متن طبق شبکه واحد تعیین می‌شود.
- جداکردن عنوان و مقدار با «:» و «—» بهتر شده و تلاش برای کم‌کردن نوشته‌ها به فونت غیرخوانا ممنوع است.
- قبل از درخواست پولی، داده‌های بیش‌ازحد بلند برای فضای کارت در پست مربع رد می‌شوند.
- اگر بیش از ۸ نکته وجود داشته باشد، بدون تیک تأیید آگاهانه حذف موارد، دکمه تأیید پولی فعال نمی‌شود.
- با هر کلیک «ساخت»، پرامپت کامل و قابل‌ویرایش باز می‌شود. یک درخواست پولی فقط بعد از تأیید؛ هیچ تلاش مجدد خودکار انجام نمی‌شود.
- خبر فوری سبز است، قالب‌ها و لوگوهای اصلی دست‌نخورده‌اند، استوری همچنان غیرفعال است.

## آزمایش انجام‌شده
- بررسی نحوی هر شش بلوک JavaScript با node --check.
- آزمون با Chromium/Playwright به‌صورت set_content (به دلیل مسدود بودن لوکال‌هاست): هشت قیمت مرغ → هشت داده در پنجره پرامپت؛ پیش از تأیید صفر درخواست API؛ بدون خطای JavaScript.
- آزمون حفاظت از داده‌های بیش از ظرفیت با ۱۰ مورد؛ دکمه تأیید باید تا تیک رضایت غیرفعال بماند.
- سلامت فایل ZIP.

## محدودیت جدی
**خروجی واقعی Flare در این نسخه ساخته یا ارزیابی نشده است.** کیفیت برابر با سه مرجع بصری ChatGPT هنوز اثبات نشده است. بدون اجازه کاربر هیچ هزینه AvalAI مصرف نشده است.
