# RushFinder 01052 — یک سطح متن داخل هر کارت

این بسته **اصلاحیه وب** است نه کل پروژه. پوشه‌ها را در همان مسیرهای GitHub جایگزین کنید.

- مدل GPT Image 2.5 Flare همچنان طراح اصلی است؛ بدون درخواست آزمایشی پولی.
- پرامپت جدید: **هر کارت فقط یک سطح کرم‌رنگ متصل به بدنه همان کارت**، نه برچسب یا مستطیل سفید اضافه.
- ارتفاع سطح متن در کارت‌های عمودی به ۴۵٫۵٪ کارت افزایش یافت؛ مختصات پرامپت و رندر یکسان شد.
- سایت در حالت editorial فقط «جوهر نوشته» را رسم می‌کند؛ هیچ کادر اضافی، ماسک سفید، سایه یا حاشیه‌ای اضافه نمی‌کند.
- متن هیچ کارتی بی‌صدا با سه‌نقطه کوتاه نمی‌شود؛ اگر جا نشود هشدار می‌دهد. این مورد برای متون بسیار بلند هنوز می‌تواند رخ دهد و باید با چیدمان/گزینش متن قبل از پرداخت مدیریت شود.
- قالب‌های اصلی چهار رسانه، سبز خبر فوری، فونت انتخابی، لوگوها و غیرفعال‌بودن استوری حفظ شدند.

**محدودیت مهم:** اگر مدل خودش با وجود دستور دو کادر در تصویر تولید کند، این اصلاح نمی‌تواند کادر دومِ پخته‌شده در تصویر را پاک کند. کیفیت واقعی Flare بدون اجرای پولی بررسی نشده است.
