# RushFinder 01047 — Adaptive Readable Cards

- اصلاح توقف بی‌دلیل «متن کارت بلند است»: به جای سقف ثابت نویسه، ابعاد کارت و متن اندازه‌گیری می‌شود.
- برای خبرهای شش یا هشت موردی با شرح طولانی، کارت افقی دو ستونه با تصویر 3D در یک سمت و سطح نوشتاری خوانا در سمت دیگر انتخاب می‌شود.
- مختصات پرامپت Flare و متن Canvas از یک قرارداد چیدمان گرفته می‌شوند.
- پیش‌نمایش پرامپت قابل ویرایش و تأیید پیش از هزینه حفظ شد.
- قالب و لوگوی اصلی هر چهار رسانه حفظ شد؛ استوری غیرفعال است.
- هیچ تماس پولی انجام نشده است. اجرای واقعی مدل هنوز نیاز به تأیید خروجی دارد.
