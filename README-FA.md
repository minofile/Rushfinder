# RushFinder نسخه وب 01054 — تشخیص واقعی کادر کرم‌رنگ برای همه اینفوها

این ZIP فقط پچ بخش اینفوگرافیک است؛ فایل‌ها را در همان مسیرهای پروژه GitHub جایگزین کنید. این بسته شامل `infographic.html`، فایل API و لوگوهای اصلی رسانه‌ها و تصاویر مرجع است. **فایل تست داخل بسته نیست.**

## اصلاح اصلی
- در حالت Flare، متن فارسی مستقیم در همان سطح کرم‌رنگ ساخته‌شده توسط مدل قرار می‌گیرد؛ سایت کادر دوم روی تصویر نمی‌کشد.
- تشخیص کادر براساس ناحیه پیکسلی پیوسته انجام می‌شود، نه صرفاً مختصات ثابت یا چند ردیف نمونه.
- متن با محاسبه عرض و شکست خط و کاهش اندازه فونت تا حد لازم داخل سطح قرار می‌گیرد. متن به‌طور عمدی با «…» کوتاه نمی‌شود.
- اگر کادر کرم‌رنگ قابل تشخیص نباشد یا متن در آن جا نشود، متن بیرون کارت رندر نمی‌شود و پیام هشدار نمایش داده می‌شود.
- پرامپت قابل ویرایش، GPT Image 2.5 Flare، قالب‌های اصلی چهار رسانه و غیرفعال بودن استوری حفظ شده‌اند.

## آزمون‌ها و محدودیت‌ها
- آزمون‌های مرورگری بدون درخواست AvalAI روی چیدمان‌های آزمایشی ۴ کارت، ۶ کارت آماری، ۶ کارت توضیحی و ۸ کارت انجام شده‌اند.
- نمونه تصویر واقعیِ خراب کاربر هم برای تشخیص ۸ سطح کرم‌رنگ بررسی شده است. نوشته‌های خرابِ قبلی از خود تصویر پاک نمی‌شوند.
- تشخیص رنگی برای همه طراحی‌های احتمالی Flare تضمین‌شده نیست؛ بعضی زمینه‌ها ممکن است با رنگ کادر یکسان باشند. وقتی تشخیص ناکام باشد، سایت باید اخطار بدهد.
- کیفیت زیبایی خروجی واقعی و جدید Flare هنوز با درخواست پولی آزمایش نشده است. هیچ هزینه API در این آزمون‌ها مصرف نشده است.
