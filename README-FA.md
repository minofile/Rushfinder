# RushFinder 01051 — متن داخل کادر اصلی مدل

این نسخه بر پایه 01050 ساخته شده است. در حالت پیش‌فرض «موتور اصلی Flare» دیگر **هیچ کادر کرم‌رنگ دوم، حاشیه، سایه یا نوار جداگانه** برای متن روی کارت‌های مدل رسم نمی‌شود. تنها حروف فارسی با فونت انتخابی کاربر دقیقاً در ناحیهٔ داخلیِ سطح کرم‌رنگِ اصلی کارت رسم می‌شوند. همهٔ داده‌ها از متن اصلی استخراج می‌شوند. تنظیمات لوگوی PNG اصلی، تم سبز خبر فوری، مدل Flare و نمایش پرامپت قابل ویرایش پیش از پرداخت حفظ شده است.

**محدودیت مهم:** اگر مدل برخلاف پرامپت خودش داخل همان سطح متن بنویسد یا کادر را در مختصات اشتباه بکشد، حذف کادر دوم به‌تنهایی آن را پاک نمی‌کند. به همین دلیل پرامپت تولید متن/برچسب توسط مدل را صریحاً ممنوع می‌کند. تست مرورگر و متن‌گذاری بدون هزینه انجام می‌شود؛ کیفیت تصویر واقعی Flare بدون درخواست پولی قابل تأیید نیست.
