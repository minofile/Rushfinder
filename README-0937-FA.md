# RushFinder 0937 — نسخه کامل تدوین خودکار

## رفع خطاها

- انتخاب مدل Gemini با همان کلید ثبت‌شده در Vercel از فهرست مدل‌های مجاز API (`models.list`). اگر مدل قدیمی `gemini-2.5-flash` در تنظیمات مانده باشد، مدل فعال `gemini-3.8-flash` یا یک مدل Flash سازگار موجود انتخاب می‌شود؛ خطای 404 مدل دیگر نباید بدون توضیح باقی بماند.
- بررسی لینک عمومی یوتیوب توسط Gemini؛ در صورت شکست تحلیل لینک یا پیدا نشدن صحنه، نمونه‌گیری از فریم‌های **فایل قابل‌دریافت مجاز** با Media Worker و بررسی آن‌ها توسط Gemini.
- **کات واقعی FFmpeg** از فایل‌های مجاز؛ حفظ برش‌های موفق هنگام شکست دریافت یک ویدیو و افزودن آن‌ها به لایه اصلی ویدیو در تایم‌لاین.
- کاهش جست‌وجوهای تکراری YouTube API با حافظه موقت؛ خطای سهمیه همچنان واقعاً رخ می‌دهد و قابل دورزدن نیست.
- گزارش وضعیت روشن و تفکیک خطاهای مدل Gemini، سهمیه و اتصال Media Worker.
- در ویندوز، اگر ffprobe در دسترس نبود، مدت زمان ویدیو با خروجی ffmpeg خوانده می‌شود.

## نصب یک‌باره

۱. از پوشه کنونی `Rushfinder` پشتیبان بگیرید. ZIP را **داخل همان پوشه ریشه GitHub پروژه** استخراج و فایل‌ها را Replace کنید؛ **پوشه `.git` را پاک نکنید**.
۲. فایل `PUBLISH-0937-GITHUB.cmd` را اجرا کنید. این دستور فقط فایل‌های مرتبط با اصلاحیه را Stage، Commit و Push می‌کند. در Vercel مطمئن شوید Deployment جدید Ready شده است. کلید API در فایل ZIP وجود ندارد و همان کلید Production قبلی استفاده می‌شود.
۳. CMD قبلی Media Worker را ببندید و فایل `RUN-0937-MEDIA-WORKER.cmd` را اجرا و باز نگه دارید. صفحه سایت را با `Ctrl+F5` باز کنید.
۴. متن یا نریشن وارد کنید، منبع را انتخاب کنید، مجوز استفاده از ویدیوها را تأیید و دکمه «جست‌وجو، دیدن صحنه، کات واقعی...» را بزنید.

## محدودیت‌های واقعی

- این بسته با APIهای **آزمایشی/Mock** و FFmpeg محلی تست شده، ولی با کلید شخصی شما یا ویدیوی عمومی اینترنت در محیط سازنده تست زنده نشده است. کارکرد نهایی روی سایت نیاز به Deployment موفق، سهمیه Gemini و YouTube، دریافت قانونی ویدیو و اجازه دسترسی مرورگر به Media Worker دارد.
- دانلود و استفاده از ویدیو تابع مجوز، محدودیت سرویس و امکان دریافت فایل است. اگر فایل در دسترس نبود، کات واقعی ایجاد نمی‌شود؛ این نسخه محدودیت DRM، کپی‌رایت یا مسدودبودن سرویس را دور نمی‌زند.
- اگر `YOUTUBE_SMARTEDIT_API_KEY` سهمیه روزانه‌اش تمام شده باشد، ابزار در حالت فقط YouTube نتیجه نمی‌دهد؛ می‌توان منبع آپارات را آزمایش کرد (بسته به دسترس‌بودن سرویس آپارات).
- پنجره `RUN-0937-MEDIA-WORKER.cmd` باید روی همان کامپیوتری باز باشد که مرورگر سایت را باز کرده است. بدون سرویس محلی، خروجی واقعی از ویدیوهای آنلاین ساخته نمی‌شود.
- فایل‌های صحنه از کلید سمت سرور Gemini استفاده می‌کنند و کلید هیچ‌وقت به مرورگر تحویل داده نمی‌شود.
