RushFinder Web 0814 — فعال‌سازی تگ کانال خبرفوری

این بسته فقط قابلیت «تگ کانال» را به نسخه وب 0814 اضافه می‌کند.
مدل پیش‌فرض «تگ نام خبرنگار» و تمام رندر قبلی After Effects بدون تغییر باقی مانده‌اند.
تصویر دقیق ارسال‌شده (@AkhbareFori) روی فیلم قرار می‌گیرد.

فایل‌های تغییر‌یافته:
1) index.html
2) news-tag.html
3) ae-auto-server.js (فقط مسیر جدید تگ کانال؛ مسیر قبلی رندر تغییر نکرده)
4) assets/news-tag/fori-channel-tag.png (تصویر خود شما)

نصب:
- از فایل‌های قبلی پشتیبان بگیرید.
- این فایل‌ها را در ریشه پروژه Rushfinder جایگزین کنید.
- پوشه assets/news-tag را در همان مسیر پروژه نگه دارید.
- در GitHub Desktop تغییرات را Commit و Push کنید تا سایت Vercel بروز شود.
- موتور محلی Start-RushFinder.cmd را پس از جایگزینی ae-auto-server.js خاموش و دوباره راه‌اندازی کنید.
- در سایت، مدل «تگ کانال» را انتخاب کنید؛ نام خبرنگار برای این مدل لازم نیست.
- هنگام انتخاب «تگ نام خبرنگار» همان قالب اصلی After Effects به کار می‌رود.

توجه: کاربران دیگر همچنان به موتور محلی خود نیاز دارند؛ این بسته اتصال سرور ابری را تغییر نمی‌دهد.
