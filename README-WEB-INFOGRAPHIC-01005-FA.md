# نسخه وب RushFinder — اینفوگرافیک خبر فوری با سبک ثابت مرجع (01005)

این نسخه بر اساس فایل Rushfinder(9).zip کاربر تهیه شده است.

## نحوه استفاده
۱. پروژه را روی سرویس وب خود (همان تنظیمات GitHub/Vercel قبلی) منتشر کنید.
۲. بخش «اینفوگرافیک» را باز کنید و برند «خبر فوری» را انتخاب کنید.
۳. متن خبر را وارد کنید: سطر نخست عنوان و سطرهای بعد اطلاعات/اعداد.
۴. سبک «خودکار» یا «سه‌بعدی» و اندازه مربع یا استوری را انتخاب کنید.
۵. روی «ساخت» بزنید؛ قبل از ارسال هزینه‌دار به AvalAI پیش‌نمایش پرامپت نمایش داده می‌شود و نیاز به تأیید دستی دارد.
۶. PNG نهایی با لوگوی اصلی ثابت روی تصویر قابل دانلود است.

## اصلاحات
- دستور طراحی «خبر فوری» برای همه موضوعات محتوایی به سیستم کارت‌های سفید برجسته، متن سیاه/سبز، آیکون‌های مرتبط و تصویر سه‌بعدی سبز نزدیک به سه نمونه مرجع محدود شده است.
- تیتر باید کاملاً بیرون ناحیه رزروشده لوگو باشد: یا در عرض مجاز سمت چپ چندخطی شود، یا از زیر محدوده لوگو آغاز شود.
- در ترکیب نهایی ناحیه لوگو از محتوای تولیدشده پاک و بعد فایل PNG لوگوی اصلی بدون تغییر روی آن حک می‌شود.
- قالب‌ها و لوگوهای مستقل سه برند دیگر حفظ شده‌اند.
- API تصویر، کلیدهای محیطی، ابزارهای تدوین و سایر صفحات دستکاری نشده‌اند.

## نکات مهم
- این نسخه هنوز روی Vercel شما منتشر نشده؛ فقط فایل قابل انتشار تحویل داده شده است.
- خروجی مدل تصویرساز تصادفی است؛ حفظ ۱۰۰٪ پیکسل‌به‌پیکسل سبک مرجع از طریق پرامپت تضمین‌پذیر نیست، ولی لوگوی ثابت از فایل واقعی پروژه استفاده می‌شود.
- قبل از انتشار خبر، همه اعداد و نوشته‌های فارسی تصویر تولیدی را بررسی کنید.
- آزمایش واقعی ساخت تصویر هزینه‌دار AvalAI انجام نشده است.
- فایل‌های محرمانه محلی، فایل‌های پشتیبان و پوشه Git در آرشیو تحویلی قرار داده نشده‌اند.
