# RushFinder SmartEdit 0907 — نسخه آزمایشی وب

این پروژه بر پایه بسته کامل 0906 تهیه شده و فقط فایل‌های `index.html`، `smart-edit.html`، `smart-edit.js` و `api/smart-stock.js` برای SmartEdit تغییر یافته‌اند. منوی جمع‌وجور 0903 و سایر ابزارها حفظ شده‌اند.

## چه چیزهایی واقعاً کار می‌کنند؟
- صفحه مستقل «تدوین هوشمند» از منوی اصلی، با تایم‌لاین، لایه‌های متن، ویدئو، موسیقی و نریشن.
- انتخاب پوشه راش‌های کامپیوتر و تطبیق متن با **نام فایل‌ها** (نه تحلیل تصویریِ هوشمند).
- جست‌وجوی خودکار در Pexels یا Pixabay با **کلید API**، دریافت مستقیم فایل از منبع به مرورگر اگر CORS مجاز باشد، و افزودن به کتابخانه.
- جست‌وجوی یوتیوب/آپارات در تب جدید فقط برای یافتن و بررسی محتوا؛ دکمه دانلود خودکار این دو منبع وجود ندارد.
- افزودن فایل MP4/WebM از لینک مستقیم HTTPS با تأیید حق استفاده، در صورت پشتیبانی CORS.
- حفظ آهنگ انتخابی کاربر در تدوین از متن، اضافه‌کردن ترنزیشن محو، متون و خروجی ویدئو با MediaRecorder.

## چه چیزی هنوز ساخته نشده؟
- اتصال و اتوماسیون YTUltra: API رسمی و قابل‌اتکای عمومی برای آن تأیید نشده؛ از سایت ثالث API مخفی و استخراج ویدئو جعل نشده است.
- دریافت خودکار عمومی ویدئوهای YouTube/Aparat. قراردادهای پلتفرم و حق نشر باید رعایت شوند. ویدئوی دارای مجوز را از مسیر مجاز دانلود و از فایل یا لینک مستقیم مجاز وارد کنید.
- انتخاب هوشمند بهترین لحظات تصویر، تولید نریشن فارسی از متن، موزیک دارای مجوز خودکار، انطباق ضرب‌آهنگ حرفه‌ای؛ این موارد در 0907 پیاده‌سازی نشده‌اند.
- تضمین MP4: خروجی به پشتیبانی مرورگر بستگی دارد و ممکن است WebM باشد.

## فعال‌سازی جست‌وجوی آنلاین
در Vercel > Project > Settings > Environment Variables یکی از کلیدهای `PEXELS_API_KEY` یا `PIXABAY_API_KEY` را تنظیم و Redeploy کنید. کلید را در GitHub نگذارید. درخواست‌های متادیتا از `/api/smart-stock` عبور می‌کنند، نه خودِ ویدئو. اگر کلید ندارید، فقط بخش محلی را تست کنید. کلید Pexels برای حساب‌های جدید ممکن است فعلاً صادر نشود.

## تست و انتشار
- بدون تغییر سایت اصلی، پوشه 0907 را استخراج و فایل `TEST-SMARTEDIT-0907.cmd` را اجرا کنید؛ برای صفحه تدوین محلی، `smart-edit.html` باز می‌شود. درخواست آنلاین به API Vercel فقط در انتشار آنلاین پشتیبانی می‌شود.
- برای GitHub، محتوای بسته کامل را در ریشه مخزن جایگزین و Commit/Push کنید.
- برای بررسی مستقیم صفحه: `https://rushfinder.vercel.app/smart-edit.html` یا از منوی «تدوین هوشمند».

هشدار: راش‌های آرشیوی لزوماً تصویر خودِ رویداد خبری نیستند و باید پیش از انتشار از نظر صحت و مجوز بررسی شوند. ویدئو و موسیقی به Vercel آپلود نمی‌شوند؛ درخواست جست‌وجوی متن به سرویس منتخب ارسال می‌شود.
