# RushFinder 01009 — اصلاح چیدمان براساس داده‌ها

- مشکل کارت‌های بسیار باریک با متن ناپدیدشده رفع شده است.
- با توجه به تعداد سطرها، از یک، دو یا سه ستون استفاده می‌شود.
- عدد صفر و مقادیر جداشده با «:» قابل تشخیص‌اند؛ اعداد از متن کاربر گرفته می‌شوند.
- برای داده‌های کم، تصویرسازی سه‌بعدی در کنار کارت‌ها باقی می‌ماند.
- برای ردیف‌های زیاد، نمایش کامل داده‌ها بر تصویرسازی اولویت دارد.
- بیشتر از ۳۰ ردیف در یک تصویر پذیرفته نمی‌شود تا پیش از درخواست پولی کاربر مطلع شود.
- لوگوی فایل اصلی و حریم امن بالای آن حفظ شده؛ هندل اضافه نمی‌شود.

در GitHub فایل infographic.html را جایگزین کنید و در Vercel مجدداً منتشر کنید.
برای بررسی چیدمانِ نتیجه قبلی به ساخت دوباره تصویر پولی نیاز نیست؛ در صورتی که همان صفحه و نتیجه هنوز در حافظه باشد، می‌توان رندر مجدد کرد.

نکته: بررسی نحوی انجام شده اما خروجی زنده Vercel یا API پولی آزمایش نشده است.
