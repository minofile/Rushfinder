# RushFinder 0935 — اصلاح توقف تدوین در مرحله تحلیل متن

## چه چیزی اصلاح شد؟

1. در حالت «فقط آپارات» دیگر درخواست غیرضروری به برنامه‌ریز متن Gemini/OpenAI ارسال نمی‌شود. جست‌وجو با واژه‌های متن انجام می‌شود و **تأیید تصویری Gemini همچنان الزامی است**.
2. در حالت یوتیوب یا هر دو منبع، اگر برنامه‌ریز هوشمند پاسخ ندهد، جست‌وجو با واژه‌های متن ادامه پیدا می‌کند؛ این واژه‌ها به معنای تأیید کات نیستند.
3. وقتی هیچ کات تصویری تأیید نشود، دلیل دقیق‌تر مانند مشکل تأیید فریم‌های آپارات یا تحلیل تصویری یوتیوب نشان داده می‌شود.
4. API خطاهای تحلیل اولیه را با علت ایمن و قابل‌فهم (429، مجوز، مدل نامعتبر، تأخیر، JSON نامعتبر) نمایش می‌دهد؛ کلیدهای API نمایش داده نمی‌شوند.

## نصب

این فایل ZIP یک **نسخه کامل** پروژه است. اول از مخزن GitHub نسخه پشتیبان بگیرید، سپس فایل‌های نسخه 0935 را در پوشه پروژه کپی و Commit/Push کنید. بعد از Ready شدن Deployment در Vercel، سایت را با Ctrl+F5 باز کنید. `RUN-0934-MEDIA-WORKER.cmd` همچنان باید روی همان رایانه اجرا باشد.

**تنظیم ضروری:** در Vercel > Project > Settings > Environment Variables برای محیط Production کلید `GEMINI_API_KEY` (یا `GOOGLE_GEMINI_API_KEY`) باید موجود و معتبر باشد. اگر متغیر را اصلاح کردید، Redeploy کنید. کلید را در چت یا کد نفرستید.

این اصلاحیه قطع شدن تدوین در صورت اختلال برنامه‌ریز را رفع می‌کند، اما **سهمیه Gemini، جست‌وجوی YouTube، مجوز دریافت ویدیو یا دسترسی واقعی به فایل‌ها را افزایش نمی‌دهد**. در صورت نبود Gemini کار مرحله تأیید بصری همچنان متوقف می‌شود؛ کات ساختگی ساخته نخواهد شد.

## تست

اجرای تست‌های API با Mock و بررسی syntax موفق بوده است؛ اتصال واقعی Vercel یا کلیدهای کاربر در این محیط آزمایش نشده است.
