# RushFinder 0946 — اتصال Groq به ساخت صحنه‌های موشن

این بسته **اصلاحیه** نسخه 0944 / 0945 است، نه کل پروژه.

## تغییرها
- استفاده از `GROQ_API_KEY` برای طراحی صحنه‌ها و سناریوی موشن، بدون نیاز اجباری به Claude.
- وقتی کلید Groq ثبت شده باشد، Groq اول فراخوانی می‌شود؛ Claude در صورت داشتن کلید پشتیبان است.
- مدل پیش‌فرض Groq: `openai/gpt-oss-20b`. برای تغییر مدل می‌توان در Vercel متغیر `GROQ_MOTION_MODEL` تنظیم کرد؛ لازم نیست.
- نام سرویس فعال به‌صورت پویا در صفحه تدوین نشان داده می‌شود.
- گزینه ChatGPT همچنان غیرفعال است.
- تمام درخواست‌ها از سرور `api/chat.js` عبور می‌کنند؛ کلید API به مرورگر ارسال نمی‌شود.
- API جدیدی در پوشه `api/` ایجاد نمی‌شود (برای حفظ سقف ۱۲ تابع).

## نصب
1. **از پوشه پروژه GitHub نسخه پشتیبان بگیر.**
2. محتویات این ZIP را **داخل پوشه اصلی** RushFinder کپی و چهار فایل `api/chat.js`، `claude-motion-editor.js`، `smart-edit.html` و `vercel.json` را جایگزین کن. پوشه `api` باید داخل همان پروژه باشد.
3. در Vercel → Settings → Environment Variables مطمئن شو متغیر `GROQ_API_KEY` برای Production ذخیره شده؛ **کلید را در چت یا GitHub قرار نده**.
4. `PUBLISH-0946-GROQ.cmd` را از پوشه اصلی پروژه اجرا کن، یا چهار فایل را با Git ثبت و Push کن.
5. وقتی Vercel وضعیت Ready شد، صفحه تدوین را با Ctrl+F5 باز کن. یک متن بلندتر از ۲۰ نویسه وارد کن و روی «طراحی و چیدن صحنه‌ها» بزن. سپس با دکمه «ذخیره سناریو» صحنه‌ها را به تایم‌لاین منتقل کن.

## محدودیت‌ها
- این مسیر **طرح صحنه‌ها و کارت‌های قابل ویرایش** را می‌سازد؛ خودش هنوز موشن‌گرافیک سینمایی کامل را رندر نمی‌کند.
- این اتصال، تشخیص تصویر و کات ویدیوهای YouTube/Aparat را تغییر نمی‌دهد.
- به محدودیت و اعتبار حساب Groq وابسته است و بدون کلید واقعی آن در اینجا فقط با پاسخ شبیه‌سازی‌شده تست شده است.
- نتیجه باید در سایت منتشرشده آزمایش شود؛ آماده بودن Deployment به‌تنهایی صحت کل مسیر تدوین را ثابت نمی‌کند.
