# RushFinder 0911 — SmartEdit Web (تدوین خودکار)

این نسخه روی نسخه وب 0908 ساخته شده و **فقط** فایل‌های مرتبط با SmartEdit و مسیر صفحه آن را تغییر می‌دهد. صفحه تگ خبر، تقویم، کم‌حجم‌کننده، منوی 0901 و سایر بخش‌ها تغییر عمدی ندارند.

## طرز استفاده
۱. پروژه را در GitHub جایگزین و در Vercel منتشر کن؛ سپس از منوی سمت راست «تدوین هوشمند» را باز کن.
۲. متن خبر را وارد و «پیدا کردن راش و تدوین خودکار» را بزن.
۳. SmartEdit در Wikimedia Commons جست‌وجوی ویدئوی عمومی می‌کند (بدون کلید)، و تلاش می‌کند فیلم را دانلود کرده و *خودش* به تایم‌لاین اضافه کند.
۴. اگر فایل مناسب و قابل دریافت یافت شود، کات‌ها، ترنزیشن محو و موسیقی ساده خودکار اضافه می‌شوند؛ متن سناریو روی تصویر نمی‌آید.
۵. قبل از انتشار، صحت نسبت‌دادن تصاویر به خبر و شرایط مجوز/انتساب را بررسی کن؛ می‌توانی فهرست منابع را دانلود کنی.

## محدودیت‌های صادقانه
- دانلود ویدئو از YouTube/Aparat/YTUltra به‌صورت خودکار فعال نیست؛ این‌ها صرفاً برای پیدا کردن منابع و بررسی حقوق اثر هستند.
- محتوای Wikimedia آرشیوی است و ممکن است در رابطه با واقعه مشخص اصلاً راش مرتبط نداشته باشد؛ در این صورت برنامه به‌جای ساخت فیلم گمراه‌کننده پیام شفاف می‌دهد.
- بارگیری مرورگری از منبع ممکن است به‌خاطر CORS شکست بخورد؛ در این صورت تنها برای ویدئوهای عمومی Wikimedia یک مسیر جایگزینِ موقت در Vercel در نظر گرفته شده است. **هیچ ویدئوی شخصیِ کاربر به Vercel آپلود نمی‌شود؛** راش عمومی ممکن است از سرور واسط به‌صورت عبوری دریافت شود و ذخیره نمی‌شود.
- Pexels / Pixabay کلید API (`PEXELS_API_KEY` / `PIXABAY_API_KEY`) می‌خواهند. دریافت برخی ویدئوها به CORS مرورگر وابسته است.
- این نسخه موتور تشخیص بینایی خبر یا نریشن فارسی خودکار ندارد و کیفیت «تدوین حرفه‌ای» را برای همه ورودی‌ها تضمین نمی‌کند. موسیقی پیش‌فرض یک قطعه ساده ساخته‌شده محلی است، نه آهنگ تجاری.
- خروجی مرورگری بسته به پشتیبانی Chrome ممکن است MP4 یا WebM باشد.
