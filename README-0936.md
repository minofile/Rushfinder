# RushFinder 0936 — رفع خطای بررسی تصویر YouTube

- فایل اصلاحیهٔ نسخه 0935 است. فایل‌های همین ZIP را در ریشه پروژه جایگزین و Git Push کنید؛ سپس Vercel را مجدد منتشر کنید و در مرورگر Ctrl+F5 بزنید.
- ورودی لینک عمومی یوتیوب برای Gemini بدون MIME غیرلازم `video/*` ارسال می‌شود (مطابق نمونه رسمی).
- اگر تحلیل مستقیم YouTube URL شکست بخورد، با **تأیید مجوز استفاده**، برنامه از Media Worker محلی فریم‌های واقعی ویدیوی قابل‌دسترسی را استخراج و برای تأیید صحنه به Gemini می‌فرستد. اگر ویدیو قابل‌دریافت نباشد یا Gemini تصویر را تأیید نکند، برش ایجاد نمی‌شود.
- پیام خطا اکنون دسته‌بندی می‌شود (سهمیه، مجوز یا مدل، ورودی لینک). از کلید/پیام خام سرویس در خطا استفاده نمی‌شود.
- روی ویندوز باید `RUN-0934-MEDIA-WORKER.cmd` باز باشد، FFmpeg و yt-dlp نصب باشند، و سایت از دامنه مجاز به localhost متصل باشد.
- **توجه:** دریافت و استفاده از ویدیو باید مجاز باشد. این برنامه محدودیت حق‌نشر، محتوای خصوصی، DRM یا محدودیت دسترسی YouTube را دور نمی‌زند.
- این تغییر محدودیت سهمیهٔ YouTube Data API یا Gemini را رفع نمی‌کند. اجرای واقعی با کلیدهای کاربر و ویدیوهای وب در این محیط قابل تأیید نیست.
