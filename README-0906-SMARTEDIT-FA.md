# RushFinder SmartEdit — نسخه وب 0906

این بسته بر اساس نسخه 0903 وب تهیه شده است. تنها ۴ فایل افزوده/تغییر یافته‌اند:
- `index.html` — اضافه‌شدن یک دکمه «تدوین هوشمند» در منوی سایت و بازشدن صفحه در iframe
- `smart-edit.html` — محیط تدوین چندلایه با پیش‌نمایش، تایم‌لاین و واردکردن پوشه راش
- `smart-edit.js` — تولید چیدمان بر اساس متن، تطبیق **نام فایل‌ها** با واژه‌ها، موسیقی اختصاصی، ترنزیشن، و خروجی محلی
- `api/smart-stock.js` — فقط جست‌وجوی **فهرست ویدئوها** از Pexels؛ بدون آپلود فایل به سرور

## فعال‌کردن جست‌وجوی آنلاین
در Pexels یک API Key تهیه کنید. آن را فقط در Vercel > Project > Settings > Environment Variables با نام `PEXELS_API_KEY` ثبت و پروژه را Redeploy کنید. **کلید را در GitHub، کد HTML یا چت عمومی نگذارید.** اگر کلید تنظیم نشود، تدوین از آرشیو محلی همچنان کار می‌کند.

## اجرای بخش تدوین
پس از انتشار `https://rushfinder.vercel.app/#smart-edit` را باز کنید. در تب «رسانه‌ها»، پوشه راش‌های دستگاه را انتخاب کنید و در تب «تدوین از متن» سناریو را بنویسید. اگر نیاز دارید جست‌وجوی اینترنتی فعال شود، تیک Pexels را بزنید. در حالت آنلاین، برنامه تلاش می‌کند پیشنهاد اول هر جست‌وجو را به‌صورت مستقیم دانلود و به تایم‌لاین وارد کند. اگر سرور فایل CORS را مجاز نکند یا فایل بزرگ باشد، لینک منبع نشان داده می‌شود و لازم است آن را دستی دانلود و وارد کنید.

## محدودیت‌های واقعی
- ابزار هوش مصنوعی بینایی/تشخیص محتوای هر فریم نیست؛ تطبیق محلی از **نام و مسیر فایل** و واژه‌ها انجام می‌شود.
- موسیقی پس‌زمینه از یک ملودی بی‌کلام اختصاصی داخل مرورگر ساخته می‌شود؛ آهنگ تجاری یا کپی‌رایت‌دار استفاده نمی‌شود.
- ساخت نریشن از متن هنوز وجود ندارد؛ کاربر می‌تواند فایل صوتی بدهد یا با میکروفون ضبط کند.
- خروجی به پشتیبانی Chrome از MediaRecorder وابسته است و ممکن است WebM باشد، نه MP4. برای فایل‌های بزرگ زمان و RAM بالا لازم است.
- برای پیشگیری از تصاویر اشتباه، صحنه‌های فاقد راش مرتبط محلی به صورت خودکار با راش نامرتبط پر نمی‌شوند مگر این گزینه را کاربر انتخاب کند.
- فیلم/صدا به Vercel ارسال نمی‌شوند؛ فقط اگر تیک جست‌وجوی آنلاین فعال باشد کلمات جست‌وجو به Pexels ارسال می‌شود. داده‌های رسانه محلی در مرورگر هستند.
- نتایج اینترنتی تصاویر عمومی آرشیوی‌اند، نه لزوماً واقعی/متعلق به خبر؛ قبل از انتشار بررسی مجوز و تطبیق محتوا ضروری است.
- جست‌وجوی Pexels عمومی و دارای سقف استفاده است؛ برای انتشار عمومی پرترافیک باید حفاظت و محدودیت مصرف پایدارتری فعال شود.

## تست و انتشار
فایل‌ها را در ریشه مخزن GitHub جایگزین کنید و Commit/Push کنید. هیچ تغییری در `Start-RushFinder.cmd`، پورت‌ها یا موتور After Effects انجام نشده است.
