# RushFinder V048

اصلاحات این نسخه:
- صفحه تنظیمات کوچک‌تر و فشرده‌تر شده تا در نمایشگر دسکتاپ معمولی بدون اسکرول پایین دیده شود.
- ظاهر تنظیمات به مرجع گرافیکی تاییدشده نزدیک‌تر شده: کارت‌های شیشه‌ای، رنگ‌های مستقل، هاله‌ها، عمق و آیکون‌های گرافیکی.
- اولین نمایش سایت همیشه Light است و فلش/شروع مشکی حذف شده است.
- تعداد نتایج ۱۲ / ۲۴ / ۳۶ واقعاً به API ارسال و در بک‌اند اعمال می‌شود.
- حالت «همه منابع» نیز دقیقاً از همان per_page انتخاب‌شده استفاده می‌کند.
- ذخیره تنظیمات همچنان تنظیمات را اعمال می‌کند و به داشبورد برمی‌گردد.
