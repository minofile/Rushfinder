# RushFinder V032

رفع باگ دکمه «دانلود» در پنجره نمایش آپارات.

مشکل V031:
- دکمه دانلود داخل کارت آپارات کار می‌کرد.
- اما دکمه «دانلود» بالای پنجره نمایش آپارات به `downloadItem` متصل نشده بود.

در V032:
- دکمه دانلود داخل پنجره نمایش آپارات نیز به همان مسیر دانلود مستقیم متصل شد.
- کاربر با زدن دانلود از همان پنجره، بدون رفتن به سایت آپارات، درخواست دانلود RushFinder را اجرا می‌کند.
- سایر بخش‌ها تغییر نکرده‌اند.
