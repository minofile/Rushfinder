# RushFinder V047

نسخه گرافیکی بر اساس ماکاپ تاییدشده:
- صفحه تنظیمات با چیدمان دو ستونه، کارت‌های شیشه‌ای و آیکون‌های رنگی بازطراحی شد.
- هدر تنظیمات دارای المان گرافیکی چرخ‌دنده، اسلایدر و هاله‌های رنگی است.
- بک‌گراند چندلایه آبی/فیروزه‌ای با هاله‌ها و عمق بصری اضافه شد.
- کنترل تاریخ و حالت روشن/تاریک در هدر اصلی و بالای صفحه تنظیمات باقی می‌ماند.
- کارت‌های تنظیمات در مرکز فضای اصلی قرار گرفته‌اند.
- حالت پیش‌فرض برنامه روشن است و از فلش اولیه تیره جلوگیری شده.
- دکمه ذخیره بزرگ و گرادیانی شده و ظاهر کارت‌ها با ماکاپ هماهنگ است.
- منطق جستجو و APIهای پروژه اصلی دست‌نخورده مانده‌اند.
