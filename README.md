# راش‌یاب (RushFinder)

نسخه MVP رابط وب فارسی و RTL برای جستجوی راش ویدیویی.

## امکانات فعلی
- رابط کاملاً فارسی و RTL
- بدون ورود و ثبت‌نام
- جستجو و پیشنهاد موضوع
- فیلتر منبع: Google / YouTube / Vecteezy
- طراحی Responsive برای موبایل و دسکتاپ
- بدون نیاز به Build؛ مناسب GitHub Pages

## اجرا
فایل `index.html` را در مرورگر باز کنید.

## انتشار در GitHub Pages
Repository را بسازید، فایل‌ها را Push کنید و در Settings > Pages، Branch اصلی را برای Deploy انتخاب کنید.

## اتصال جستجوی واقعی
این نسخه رابط MVP است و داده‌ها نمونه هستند. برای جستجوی واقعی باید APIهای رسمی/مجاز هر سرویس در یک Backend یا Serverless Function متصل شوند. کلیدهای API را داخل JavaScript عمومی GitHub Pages قرار ندهید.

## فونت
CSS ابتدا `Yekan` را صدا می‌زند. برای استفاده دقیق از فونت Yekan، فایل فونتی که مجوز استفاده از آن را دارید به پروژه اضافه و با `@font-face` تعریف کنید. در حالت فعلی Vazirmatn به عنوان fallback فارسی بارگذاری می‌شود.
