# RushFinder 0957 – خلوت‌سازی صفحه تدوین و اصلاح کش‌آمدن صفحه

این اصلاحیه بر پایه صفحه 0955 ساخته شده و **فقط دو فایل رابط کاربری** را تغییر می‌دهد: `smart-edit.html` و `hermes-ui.js`.

## دقیقاً چه چیزی حذف شده؟
- عنوان بزرگ «تدوین با Hermes» و دکمه آبی «ارسال درخواست به Hermes» از پنل فعلی مخفی شده‌اند، چون اتصال سیستم همکار هنوز آماده نیست.
- پیام وضعیت سفارش، دکمه واردکردن نتیجه و توضیح بلند پایین پنل از ظاهر کنار رفته‌اند.
- قسمت آزمایشی ساخت موشن‌گرافیک شامل فیلد ۴۵ ثانیه، دکمه «ساخت خودکار و افزودن به تایم‌لاین» و دکمه «دریافت سناریو JSON» از ظاهر حذف شده است. **این دکمه اکنون قابل استفاده نیست.**
- فرم متن و آپلود نریشن همچنان وجود دارد. عنوان زبانه به «متن و نریشن» تغییر کرده است.

## مشکل عکس سوم
- بازکردن «ابزارهای بیشتر: تنظیمات و افکت‌ها» دیگر نباید طول صفحه را افزایش دهد؛ تنظیمات داخل همان ستون راست اسکرول می‌شوند.
- ارتفاع صفحه و ناحیه پیش‌نمایش/تایم‌لاین در نمایشگر دسکتاپ محدود می‌ماند.

## چه چیزی دست‌نخورده؟
APIها، کلیدها، Vercel Functions، Hermes Bridge، فایل‌های تدوین، تایم‌لاین، پیش‌نمایش، تنظیمات رسانه و خروجی ویدیو. چند المان موردنیاز کد قدیمی در بخش کاملاً پنهان نگه داشته شده‌اند تا خطای JavaScript ایجاد نشود.

## نصب
1. محتوای ZIP را در پوشه اصلی Git پروژه RushFinder استخراج کنید و دو فایل هم‌نام را جایگزین کنید.
2. فایل `PUBLISH-0957-CLEAN-EDITOR.cmd` را اجرا کنید.
3. در Vercel آخرین Deployment باید `Ready` باشد. سپس سایت را با `Ctrl+F5` بارگذاری کنید.

**این بسته اتصال Hermes را فعال نمی‌کند**؛ برای ارسال سفارش باید بعداً رابط اختصاصی را بعد از آماده‌شدن Hermes همکار دوباره فعال کنیم.
