# RushFinder 0943 — نسخه وب تدوین هوشمند

## تغییر این نسخه
- در پنل «ساخت موشن‌گرافیک با هوش مصنوعی»، انتخاب‌گر موتور اضافه شده است.
- Claude فعال است و درخواست‌ها همچنان به `/api/claude-motion-plan` ارسال می‌شوند.
- گزینه ChatGPT فقط نمایشی و غیرفعال است؛ تا زمان پیاده‌سازی اتصال OpenAI قابل انتخاب نیست.
- ساخت سناریو و افزودن صحنه‌ها به تایم‌لاین مانند نسخه 0942 انجام می‌شود.
- خروجی نهایی خودکار گرفته نمی‌شود؛ کاربر پس از بازبینی و ویرایش، خودش دکمه خروجی را می‌زند.

## تنظیمات Vercel
در Project Settings → Environment Variables، کلید زیر باید برای Production وجود داشته باشد:

- `ANTHROPIC_API_KEY` — کلید محرمانه Claude

اختیاری:

- `SMARTEDIT_CLAUDE_MODEL` — شناسه مدل Claude؛ در صورت خالی بودن مقدار پیش‌فرض کد استفاده می‌شود.

## انتشار نسخه وب
1. فایل‌های ZIP را در پوشه اصلی مخزن RushFinder جایگزین کنید.
2. در همان پوشه، `PUBLISH-0943-GITHUB.cmd` را اجرا کنید.
3. پس از Push، در Vercel منتظر پایان Deployment بمانید.
4. صفحه `https://دامنه-سایت/smart-edit.html` را با Ctrl+F5 باز کنید.

این نسخه یک انتخاب‌گر واقعی در رابط وب دارد؛ دکمه ChatGPT عمداً غیرفعال است و هنوز API مربوط به آن پیاده‌سازی نشده است.
