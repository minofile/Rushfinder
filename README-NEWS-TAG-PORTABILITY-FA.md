# راه‌اندازی بخش «تگ خبر» RushFinder روی کامپیوترهای دیگر

این بسته نسخه کامل پروژه ارسالی شماست که **فقط فایل‌های راه‌انداز و عیب‌یاب** آن اصلاح شده‌اند. فایل‌های اصلی بخش تگ و پروژه‌های After Effects دست‌نخورده باقی مانده‌اند.

## روش استفاده در ویندوز

۱. **کل ZIP را Extract کنید**؛ فایل CMD را به‌تنهایی کپی نکنید. بهتر است در مسیری مانند `C:\RushFinder` استخراج شود.

۲. `Check-RushFinder.cmd` را اجرا کنید تا پیش‌نیازهای همان سیستم مشخص شوند.

۳. برای ساخت تگ‌های گوینده، نام و سمت، **Adobe After Effects نصب‌شده** و قالب‌ها/تصاویر اصلی لازم‌اند. برای بخش‌های ویدیویی و تگ کانال، **FFmpeg** لازم است؛ اگر نصب نیست، `setup-ffmpeg.ps1` موجود در پروژه را با آگاهی از محتوایش اجرا کنید یا FFmpeg را مستقل نصب کنید.

۴. **Node.js LTS برای ویندوز** باید نصب باشد (`https://nodejs.org/en/download/`). راه دیگر قرار دادن نسخه رسمی `node.exe` ویندوز در مسیر `tools\node\node.exe` است. باینری Node داخل این ZIP قرار داده نشده است.

۵. `Start-RushFinder.cmd` را اجرا کنید؛ اگر سرور اجرا نشود، آخرین خطاها و محل لاگ نشان داده می‌شود. آدرس بازشده `http://127.0.0.1:18827/index.html` است.

۶. اگر خطا دیدید، خروجی `Check-RushFinder.cmd` و فایل‌های `%LOCALAPPDATA%\RushFinder\logs\news-tag-server-stderr.log` را بررسی کنید.

## محدودیت واقعی معماری

موتور تگ فعلی **فقط روی 127.0.0.1 هر دستگاه** اجرا می‌شود. بنابراین موفق‌بودن CMD روی کامپیوتر شما به این معنی نیست که کاربر دیگر در وب‌سایت Vercel بتواند تگ رندر کند. برای هر کاربری که روی سیستم خودش اجرا می‌کند، پیش‌نیازهای بالا لازم است. برای اجرای تگ برای **همه کاربران بدون نصب** باید یک سرور/ماشین ویندوزی با After Effects و FFmpeg راه‌اندازی و API امن احراز هویت‌شده به وب‌سایت متصل شود؛ Vercel به‌تنهایی After Effects اجرا نمی‌کند. این مهاجرت در این بسته انجام نشده است.

## امنیت و محتوا

فایل محلی `vecteezy-worker-secret.local.txt` عمداً از بسته خروجی حذف شد تا یک مقدار محرمانه همراه ZIP توزیع نشود. اگر سرویس دیگری به آن وابسته است، مقدار را فقط روی ماشین مورداعتماد خودتان و به‌شکل محرمانه تنظیم کنید. **این فایل را در GitHub عمومی قرار ندهید.**

## تست‌های انجام‌شده

- وجود قالب‌ها و فایل‌های اصلی بررسی شد.
- نحو JavaScript با Node بررسی می‌شود.
- بسته ZIP از نظر ساختاری کنترل می‌شود.
- اجرای CMD/PowerShell/After Effects روی ویندوز در این محیط قابل آزمایش عملی نیست؛ کارکرد آن روی همه سیستم‌ها تضمین نشده است.
