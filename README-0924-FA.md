# RushFinder 0924 — اتصال YouTube SmartEdit

این بسته از نسخه 0923 تهیه شده است و کلید یوتیوب دوم را بدون ایجاد تابع سروری جدید به تدوینگر وصل می‌کند.

## انتشار

فایل‌های `smart-edit.html`، `smart-youtube.js` و `api/youtube-music.js` را به همان مسیرهای ریشهٔ GitHub منتقل و Commit/Push کنید. سایر فایل‌های سایت دست‌نخورده می‌مانند. بعد از Ready شدن Vercel، اگر متغیر `YOUTUBE_SMARTEDIT_API_KEY` را تازه اضافه کرده‌اید، این انتشار آن را برای تابع در دسترس می‌گذارد.

نام متغیر برای تدوین: `YOUTUBE_SMARTEDIT_API_KEY` در Production به‌صورت Secret. نام متغیر بخش قدیمی موسیقی: `YOUTUBE_API_KEY` دست‌نخورده است. کلیدهای واقعی را هرگز در کد یا GitHub نگذارید.

## نحوه استفاده

در سایت از منوی راست وارد «تدوین» شوید. در تب «نریشن + متن» متن نریشن را وارد و فایل صوتی را انتخاب کنید. روی «جست‌وجو و چیدن راش‌های مرتبط YouTube» بزنید. نتیجه‌ها به‌صورت ارجاع روی یک لایهٔ مستقل تایم‌لاین قرار می‌گیرند و با پخش‌کننده رسمی YouTube بی‌صدا نمایش داده می‌شوند. دکمه «پیش‌نمایش با نریشن» زمان‌بندی تقریبی آن‌ها را پخش می‌کند. می‌توانید ویدئوی پیشنهادی هر جمله را عوض کنید.

## محدودیت مهم

یوتیوب دانلود یا به فایل محلی تبدیل نمی‌شود و از API تنها عنوان، لینک و تصویر کوچک دریافت می‌شود. ویدئوهای یوتیوب در خروجی MP4/وب‌ام رندر نمی‌شوند. برای خروجی ویدئویی با تصاویر، باید فایل‌های دارای مجوز را جداگانه وارد کنید. زمان‌بندی جمله‌ها بر اساس طول متن و مدت فایل نریشن تخمینی است؛ لزوماً تصاویر همان خبر نیستند. بعضی ویدئوها بر حسب محدودیت انتشاردهنده، کشور یا شبکه قابل Embed نیستند. برای استفاده جدی، محدودیت مصرف API و کنترل دسترسی لازم است.
